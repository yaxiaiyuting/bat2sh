## 4. §5.4 归属重判的结论

| 条件 | 重判前（v1.10.0） | **重判后** | 依据 |
| :--- | :--- | :--- | :--- |
| **(a) 所有剩余失败有明确归属** | ✗（C2「无归属」） | **✓** | 本文件 §1/§2：registry 29/29 → 2.x；other 85 条：可做 1 / 2.x 11 文件 / 终态 5 文件（另多设施文件逐条归属）；for 可做 2 / 其余保持诚实 TODO + 归属 |
| **(b) 无「可修但未修」** | ✗（36 翻转未做） | **✓（执行 §3 后）** | 「可做」真集合 = **3 翻转**（for /r、for /f 字符串、net user）；执行后无剩余可做项。原「36」中 **11 为 L4 写类、21 为终态/零翻转**，非「可修未修」 |
| **(c) 指标稳定且无提升空间（degraded ≤ 41）** | ✗（86） | **需修订标准 3** | ≤41 基于错误的 C2 估算（46 文件）；实际可达值需实测 → 见 `docs/v1.11.0-standard-3-revision.md` |

**结论**：

1. **C2 的真实可做子集 = 3 个翻转 + 2 个质量项**，而非 36。
2. 原「36」的构成：**registry 11（L4 写类→2.x）** + **other 17（可做 1 / 2.x 11 / 终态 5）** + **for 7–10（可做 2 / 其余 2.x 或终态）**。
3. **不存在被静默归 2.x 的项**：本文件 §1.2（29 行）与 §2.1（17 行）+ §2.2（10 行）逐条给出归属与依据。
