## 4. 最小复现（实测）

```bat
@echo off
sc config Spooler start= auto
sc stop Spooler
```

**现状产物**：

```bash
# TODO: 手动检查: sc config Spooler start= auto
# TODO: 手动检查: sc stop Spooler
```

**目标产物**：

```bash
# TODO[SC] op=config service="Spooler" params="start=auto": 手动检查: sc config Spooler start= auto
# TODO[SC] op=stop service="Spooler": 手动检查: sc stop Spooler
```

`--fix-todos` 兼容性：`core/api/fixer.py` 的 `_MARKER_RE = #\s*TODO\b` 与 `_extract_original`
（按 `: 手动检查: ` 取值）**对 `# TODO[SC]` 前缀与 `# TODO[REG]` 等价**（实测 fixture `test_api_fixer`）。

| 子项 | 裁定 | 理由 |
| :--- | :--- | :--- |
| goto 回跳 / 块内 | **退回 v2.3+** | 触 053 + 需 CFG 高级；翻转 0（回跳候选 1 但不可安全做） |
