## 2. 完成了什么（逐条）

### Stage A（`a4f6e17`）：`redundant_goto` → 等价 no-op
- `_prescan_goto_regions` 只读预计算 `_redundant_gotos`：整行独立 `goto`、目标为**唯一**已知标签、
  目标位于下一条非空非 `::` 行、目标非 `call` 目标。
- `_convert_goto` 命中且块栈为空、不在函数体内 → 发 no-op 注释（不再报 TODO）。
- **不触碰**块栈发射层 / `_label_line` / A1 热路径。

### Stage B（`e4f1ab8`）：前向 goto **不可达区间** → 显式注释
- 可达性证明：无条件顶层 goto（括号净值 0、唯一前向标签、非 call 目标）且**区间内无任何标签样行**（含 CJK）
  → 除「goto 行 fall-through」（被 goto 阻断）外无路径进入区间 → 区间不可达 → 逐行 `# [不可达]` 注释。
- 保守边界（任一不成立即保留诚实 TODO）：条件 goto / 块内 goto / 重复标签 / 区间含标签样行。
- **不 push/pop 块栈**；被抑制行**显式注释**（非静默蒸发，`_check_silent_drop` 不触发）。

### Stage C（`491ecec`）：归属锁定
- `core/control_flow.py`：`redundant_goto` `convertible=True`；`forward_skip` 记录保守子集实现；
  其余维持 D 档诚实 TODO（**不发明映射**）。
- `tests/test_batch_goto_dispositions.py`（8 条）：逐形态断言处置。

## 5. 是否引入静默错

**否。** 且本版**在实现过程中由仪器捕获并修复了一处「近失静默错」**（主动披露）：

- Stage B 初版用 **ASCII 标签正则**判定「区间内是否有标签」，漏判 CJK 标签；
  语料 `104 瑞星杀毒软件2008批处理版.bat` 的区间含 `:退出`，而源中 `if "%s%"=="6" goto 退出`
  **会跳入该区间**。初版误判为不可达 → 注释掉可达代码（**静默错**）。
- **逐文件产物 diff 捕获**（104 产物意外变化）→ 立即改为**宽松标签判据**（`_LABEL_LIKE_RE`，含 CJK，
  区间内**只要有标签样行即拒绝转换**）→ 104 恢复零变化。
- 证据：修复前后 `measure` 逐文件比对（104 恢复 `无变化`）；新增保守边界测试
  `test_reachable_label_inside_region_blocks_conversion` / `test_call_target_inside_region_blocks_conversion`。

> 该事件证明了「逐文件 diff + wine oracle」两道防线的价值：**没有它们，这类静默错会漏网。**

## 8. 已知限制 / 发现（纪律 4 披露）

1. **`examples/stress_test.sh` 在基线 `5da34eb` 已有遗留漂移**：已提交的 `.sh` 仍含
   `for /f "tokens=1-3 delims=,"` 的 `# TODO`，而当前转换器实际已转换该行（v1.11.0 `for/f` 字符串形式）。
   本版**未**顺手修复该遗留漂移（保持最小改动与可归因）；建议后续单独处理。
2. `examples` 因此**非零漂移**：本版对 `stress_test.sh` 做了**1 处刻意更新**（goto 区间语义），
   已在 §6/§7 披露。测试 `test_examples.py` 本身不做字节比对，仅 `bash -n`。
3. Stage A 的冗余判定只覆盖**整行独立 goto**；`if … (goto X) else (…)`、`cmd & goto X`
   等复合形态仍为 TODO（避免触块发射层）。
4. `031` 的判据计数变化属**报告层**（语法失败 → 降级产物固定），不影响产物。
