### 三.1 `rc0` 位移（定义性，逐文件证据）

`rc0 105→101`（`degraded 86→82`，`strict 19` 不变）**全部落在「交互/无限循环」或源畸形文件**——
状态机**忠实实现**了 cmd 的循环，而无 stdin 沙箱无法满足（v1.8.3 归类为 **S 测量 artifact / 交互无 stdin**）：

| 文件 | rc | 机制 | 判定 |
| :--- | :--- | :--- | :--- |
| `注册表/注册表权限设置.bat` | 0→124 | `:START … set /p … goto START` 菜单循环（无 stdin 即无限） | **定义性**（忠实 cmd） |
| `第三方工具/CSty/高级范例CSty-KeyPrs.bat` | 0→124 | `:loop … set/p … goto loop` 等键循环 | **定义性** |
| `第三方工具/CSty/高级范例Caps-Num.bat` | 0→124 | `:loop` / `goto loop`（**源即无限循环**） | **定义性** |
| `将文件夹变为磁盘.bat` | 0→127 | 源 `pasue`（`pause` 笔误）在 `:err` 分支被忠实执行 | **定义性**（源畸形，v1.8.3 B 类） |

另 5 文件 `rc≠0 → 124/1`（本已失败，非回归）：`一键转移桌面…`、`多功能系统优化设置.cmd`、
`批量重命名.bat`、`获取某路径下的所有文件名.cmd`、`右键菜单 显示隐藏扩展名及文件.bat`——均为交互/菜单脚本。

**非交互、非源畸形的 eligible 文件：rc 零回归。** 无新增静默错（脚本行为忠实于 cmd；`bash -n` 全过）。

> **风险披露**：忠实循环意味着**无 stdin 运行会挂起**（`rc 124`）。这是**语义正确性 vs 非交互可用性**的
> 取舍；已由用户裁定接受（方案 B）。若不接受，可 `cfg_state_machine=False` 整体回退。

## 五、版本号判定

- **判定 = `2.5.0`（minor）**。
- 理由：状态机仅对 **25/151** eligible 文件（含 goto 宿主）改写其 **goto 区段**为 `pc` 分派；
  块内结构化代码、其余 126 文件产物不变；且提供 `cfg_state_machine=False` 整体 opt-out（可一键回退）。
  未构成「整文件状态机化」或「产物不可读」的 3.0.0 级破坏。
- **回退承诺**：不接受该位移者可置 `cfg_state_machine=False`（= v2.4.0 行为）。
