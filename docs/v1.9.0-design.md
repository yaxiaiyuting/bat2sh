## 1. 新口径基线（任务书第五节第 1 步）

### 1.1 口径定义（本文件采用的精确判定）

任务书 §3.1 定义：**rc==0 = 脚本跑通 且 功能完好；含 `# TODO` 的产物不计入 rc==0，单列 `degraded`。**

为可复现，本文件把「功能缺失」判为**并集**：

- **可见标记**：产物中存在以 `# TODO` 开头的行（含 `# TODO:` / `# TODO[REG]`；**不含**头部说明行
  `# 带有 # TODO 标记的行…`）。
- **报告登记 TODO**：`ConvertReport.todo_count > 0`（与 `--fail-on-todo`、GUI 报告同源）。

**为什么取并集**：实测存在 **6 个文件「报告登记了 TODO、但产物里没有 `# TODO` 行」**——
命令被**整行丢弃**（详见 §4）。只按可见标记会把这些**内容丢失**误判为「功能完好」。
并集是 `--fail-on-todo` 的口径，也是「功能缺失」的忠实近似。

> 敏感性：若仅按**可见标记**判定，则为 functional **22** / degraded **80**（`013/023/079` 被误算为完好）。

## 2. 任务 A：053 块栈结构问题 —— 只读评估

**对象**：`将所在目录的BAT文件合并成一个BAT文件，通过 选择 运行其中之一.bat`（52 行，GBK）。

### 2.1 根因（已定位到行）

`for /f` 循环体为 `if A (…) else (if B (…) else (`——**行尾的 `else (` 未闭合**，
其循环体继续到第 31 行的 `))`。

`_convert_if`（`core/batch.py:1550`）在处理行内 `else (` 时，**对「括号未配平」的分支处理不对称**：

- `_close_block_line`（`:1267-1288`）对 `) else (` 未配平的情形**会**`push` 一个
  `await_paren_close=True` 的 else 块，等后续 `)` 闭合；
- 但 `_convert_if`（`:1616-1620`）在同一情形下算得 `close2 = -1` 后，仍执行
  `self._stack.pop()` + 补 `fi` —— **把 else 块提前关掉**。

后果链：
1. else 体（源第 13–30 行）不被认作循环体 → 被输出到**循环之外**；
2. `_convert_for`/`_emit_for_f` 随后**无条件 pop 栈顶**，pop 到了 else 块而非 for 块 →
   块栈整体错位 → `%%i` 逸出（`_loop_vars` 提前移除）；
3. 第 31 行 `))` 落到空栈 →「多余的 ')'，已忽略」。

### 2.2 最小复现（已实跑）

```bat
@echo off
for %%i in (a b) do if %%i==a (echo A ) else (if %%i==b (echo B ) else (
echo body1
echo body2
))
echo after
```

当前产物（错误）：`body1/body2` 在循环外；`# 多余的 ')'，已忽略`；块栈错位。

### 2.3 拟改函数（4 处，均在块栈发射层，**不涉词法层**）

## 4. 新发现（本评估期）：`cmd_todo_hint` 命令被**整行丢弃**（内容丢失，非 TODO）

**触发**：`_convert_simple_inner` 的 handler 分支（`core/batch.py:2516-2520`）：

```python
if first in rules.BATCH_HANDLER_MAP:
    handler = getattr(self, rules.BATCH_HANDLER_MAP[first])
    line = handler(lineno, rest, expanded)
    if line is None:
        return []          # ← 直接丢掉整行
```

`cmd_todo_hint`（`:2675`）登记 `self._todo(...)` 后**返回 `None`**，
而其他分支（`:2593`）会在 `line is None` 时补出 `# TODO: 手动检查: …`。
两条路径不一致 → **命令既未执行、也未留 TODO 标记**，产物里凭空消失。

**为何与本任务强相关**：新口径按「产物含 `# TODO`」判 degraded。若不修，
