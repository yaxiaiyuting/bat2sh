## 三、美化方案（保守；仅标准库）

### 3.1 设计原则

1. **零新依赖**：只用 `os`/`sys`（已有）。不引入 rich/colorama。
2. **颜色是「增强层」，不是「输出层」**：非 TTY / `NO_COLOR` / `--no-color` / CI 下**逐字节等价**
   于当前输出（向后兼容优先于视觉美观，纪律 22）。
3. **不重排报告结构**：`to_text()`/`report_blocks()` 的既有行序与逐行等价不变量**保持**，
   报告扩展以**追加摘要行**方式实现，避免破坏 GUI 共用与 8 条守护测试。
4. **stdout 永不出现 ANSI**：颜色只加在 stderr 的渲染函数内。

### 3.2 色彩基础设施补齐（commit 1）

- 新增互斥参数 `--color` / `--no-color`（`dest="color"`，取值 `always` / `never`；默认 `auto`）。
- `color_enabled(stream, mode="auto")` 扩展（**默认参数 = 旧行为，向后兼容**）：
  - `mode == "never"` → `False`（**优先级最高**，压过 `FORCE_COLOR`/TTY）。
  - `mode == "always"` → `True`（压过 `NO_COLOR`/非 TTY；显式命令行 = 用户意图）。
  - `mode == "auto"` → **原逻辑逐行不变**（`NO_COLOR` > `TERM=dumb` > `FORCE_COLOR` > TTY）。
- 所有 `color_enabled(sys.stderr)` 调用点改为 `color_enabled(sys.stderr, args.color)`。
- 无 `args` 的调用（`_FixPanel` 内部由 `_fix_todos_flow` 传入布尔值）不变。

### 3.3 成功/警告/错误色彩（commit 2）

- 新增 `_diag(level, message)`：把 `bat2sh: …` 诊断按级别着色后写 stderr（`color` 关时原文）。
- 覆盖 `print(f"bat2sh: …", file=sys.stderr)` 的**用户可见诊断**（不覆盖交互 prompt 的问答行，
  避免污染管道/重定向）。
- 级别映射：错误=红、警告（含降级/交互/`--fail-on-todo` 提示）=黄、成功=绿。
- **不变式**：`color=False` 时输出与现状**逐字节相同**（测试用非 TTY 捕获守护）。

### 3.4 报告格式扩展（commit 3）

- **不改** `to_text()`/`report_blocks()`（保持 GUI 共用与守护测试）。
- 在 `_emit_report` 的 `--report` 分支**追加一行摘要**：`render_report_summary(report, color)`：
  - 有错误 → 红：`结论: 转换完成，存在 N 处错误 / N 警告 / N 待人工检查，请人工复核`
  - 有警告或 TODO → 黄：`结论: 转换完成（0 错误 / N 警告 / N 待人工检查）`
  - 干净 → 绿：`结论: 转换完成，无错误 / 警告 / 待人工检查`
- 仍走 stderr，不进 stdout；`--report-json` 不受影响（结构化字段不变）。

### 3.5 批量进度指示（commit 4，若适用）

- 多文件（`len(inputs) > 1`）时状态行前缀 `[i/N] `；单文件不显示（保持既有测试契约）。
- **不引入** per-byte 进度条（单文件无长耗时段，诚实结论）。
- `--fix-todos` 已有面板，不重复造。

### 3.6 文档 + 测试（commit 5）

- README §4.2 参数表补 `--color` / `--no-color`；颜色说明段补优先级。
- 新增 `tests/test_cli_colors.py` 用例：`--no-color` 压过 `FORCE_COLOR`；`--color` 压过管道
  与 `NO_COLOR`；四场景矩阵（TTY 模拟 / `NO_COLOR` / 非 TTY / `--no-color`）全部无 stdout ANSI。

## 四、风险与规避

| 风险 | 规避 |
| :--- | :--- |
| 颜色泄漏到 stdout，破坏 `--print` 脚本 | 只在 stderr 渲染；`test_cli_stdout.py` 4 条守护 |
| 改动 `to_text` 破坏 GUI/测试 | **不改**结构，仅 CLI 层追加摘要行 |
| `--no-color` 与 `FORCE_COLOR` 冲突 | 明确优先级：`--no-color`(never) > `--color`(always) > `auto`(env/TTY) |
| 既有调色板语义改变 | 复用 `_ANSI_COLORS`，不新增/替换色码 |
| 非 TTY 输出漂移 | `color=False` 路径逐字节保持；151 语料回归 + examples 零漂移复核 |
