## 2. 标准 1 修订（本 session 授权项）

**原**：`语法通过 ≥ 150/151（99.3%）；剩余 1 为 B 类源畸形（cmd 亦失败）`。

**修订为标准 1′（原则性表述）**：

> **所有语法失败必须有明确归属（终态 / 2.x），不存在「可修但未修」的语法项。**

**依据**：

1. **估算基础不成立**：「剩余 1 为 B 类源畸形」经实测为 **4 例**（§1 行 1），且其中 **3 例为解析层
   可归因项（2.x）**、1 例为 B 类源畸形（终态）。
2. **原则性表述与标准 3 修订同源**：标准 3 由「≤ 估算值」改为「≤ 实测值 + 剩余全部有归属」；
   标准 1 同样从「≥ 估算阈值」改为「**无无归属项**」。
3. **可测且可追溯**：判据变为「逐条归属表完整」（见 `docs/v1.11.0-1x-closure-final.md` §2.1）。

**标准 1′ 判定**：**✓**（4 例逐条归属：1 终态 + 3 解析层 2.x）。

## 3. 核查中发现的两处「表述过宽」（披露，不静默处理）

> 二者**均非估算错**（来源为仪器），也**均非「无归属」项**（各有明确归属），
> 故**不触发任务书 §六 的暂停条件**；但按纪律 9 强化（标准必须可追溯）与纪律 5（不得静默），
> 在此**显式披露**，供后续裁定是否同步修订表述。

### 3.1 标准 2 第二分句：应加「未诊断」限定

- 原表述「A/B/C/D 分类审计**无**『语法通过但行为错』项」按字面**过宽**：
  A-7.1（`备份服务.bat` 空重定向）、A-7.3（`多功能系统优化设置.cmd` 内容生成多行）等
  **确是「语法通过但行为错」**，且**仍未修**（`v1.8.2-artifact` §12.2 判定 backlog）。
- 但**全部带可见诊断**（TODO 计数 7 / 211，或 rc≠0 响亮失败），故**无「静默」行为错**。
- **准确表述应为**：「分类审计**无未诊断的**行为错」（即缺陷必须可见 + 有归属）。
- **判定**：按准确表述 **✓**（证据见 §1 行 2）。**本 session 不改判**，仅披露。

### 3.2 标准 4 括注：「chcp 类 noop 有意识记录」未实现

- 括注要求 noop 丢弃**有意识记录**（即可审计痕迹）。**实测未实现**：`BATCH_NOOP_MAP`
  显式声明 `chcp/color/title/mode/...` 为 noop，产物**不产生任何注释/警告**（140 行静默）。
- **归属已存在**（非「无归属」）：路线图 §附录 **NEW-2**「`chcp` 等 noop 静默丢弃无审计痕迹」
  → **终态 + 低优先 info**；`v1.8.0` D3 亦记「**非缺陷**」。
- **准确表述应为**：「无丢失；丢弃项**均为 `BATCH_NOOP_MAP` 显式声明的有意 noop**」。
- **判定**：核心分句（误报 0/151）**✓**；括注项**未实现但已归属**。**本 session 不改判**，仅披露。

## 4. 纪律 9 强化条款（落地）

> **纪律 9（强化，v1.11.0 起）**：测量工具与**验收标准**都必须**可复现、可追溯来源**；
> **不可复现的数字与「无来源的标准」均视为无效**。

| 措施 | 落地证据 |
| :--- | :--- |
| 测量仪器固化进仓库 | `tools/corpus-analysis/measure.py`（CLI 化，口径同 `analyze.py`） |
| 仪器确定性 | 三轮全量复跑**逐字段 0 差异**（`docs/v1.11.0-instrument-verify.md` §2） |
| **标准来源可追溯** | 本文 §1 逐条标注「估算 / 仪器 / 定义」并附实测证据 |
| 估算标准一律改为实测或原则表述 | 标准 1（估算→原则）、标准 3（估算→实测 83） |
| 表述过宽者显式披露 | §3（标准 2 第二分句、标准 4 括注） |
