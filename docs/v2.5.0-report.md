## 2. 完成了什么（逐条）

### Stage 1（`779d7d9`）：CFG 基本块 + 流分析（只读图结构）
- `core/cfg_blocks.py`：`BasicBlock` 划分（leader = 首行 / 标签行 / goto 后继行）+ 前驱/后继边 +
  回边循环 `detect_loops` + `FlowAnalysis`（多入口 / 重复标签 / `label_in_block` / missing / dynamic）。
- `tests/test_cfg_blocks.py` **22 条**语义测试。
- **零转换器改动**：不 import `core.batch`，不被默认路径调用。

### Stage 2/3（`6a824fd`）：门控 CFG 标签分派状态机
- `core/cfg_state.py`：**标签分派状态机**（`__bat2sh_pc` + `while/case`）。
  - **子类化** `BatchConverter`，仅覆写 `_prescan` / `_label_line` / `_convert_goto` / `_finish` / `_indent`；
    **原类零改写**（053 的块栈发射层逐字节不动）→ 053 回归面最小。
  - 形态：`backward_loop` → `pc=<臂>; continue`；块内 goto → `continue N`；多入口 → 分派臂；
    `goto :eof` → `exit 0`/`return`；前向跳转 → `pc` 跳转。
  - **保守门控**（`evaluate`）：需同时满足「有 goto→标签边 + 无 missing/dynamic + 无重复标签 +
    无块内标签 + 无 `call :label`」；不命中 → 返回 `None` 回退原路径。
  - **安全自检**：产物结构自检（所有引用臂均已定义，防死循环）+ `bash -n`；失败 → 回退原路径。
- `settings.cfg_state_machine: bool = False`（**默认关闭**）；`batch.convert` 加门控分支（未命中回退）。
- `tests/test_cfg_state.py` **21 条**（门控 + 结构 + **运行时语义**）。

### Stage 4（`bd241ef`）：C4 归属更新
- `core/control_flow.py`：3 形态 `plan`/`notes` 记录 v2.5.0 门控实现；
  **维持 `convertible=False` / `confidence=D` / `integrated=False`**（未激活，不虚报）。

## 5. 是否引入静默错

**否。** 两道保障：

1. **默认路径逐字节不变**（门控默认关闭）→ 结构性排除静默错。
2. **门控版自带失败安全**：`emit` 在「结构自检失败 / `bash -n` 失败 / 转换器报告 syntax 错误」时
   **返回 `None` 回退原路径**（原路径产出可见诚实 TODO，非静默）。实证：`瑞星杀毒软件2008批处理版.bat`
   （eligible）在状态机下 `bash -n` 失败 → **自动回退默认路径**（未产出坏码）。

> **方案 C 已执行（`a73db95`）**：新增 wine 黄金用例 **g07–g12**（for-goto / 回跳循环 / 嵌套
> for-goto `continue 3` / 前跳 / 多入口 / if 块内 goto），以**状态机产物**对照 wine cmd →
> **12/12 MATCH**。→ 目标形态的**代表性语义已被 wine 证伪为正确**。
>
> ### 5.1 `rc0` 定义性位移（激活后实测，逐文件证据）
>
> 激活后 `rc0 105→101`（`strict 19` 不变），4 文件全部为**交互/无限循环或源畸形**——
> 状态机**忠实实现** cmd 循环，无 stdin 沙箱无法满足（v1.8.3 分类 **S 测量 artifact**）：
> `注册表权限设置.bat`(0→124 菜单循环)、`高级范例CSty-KeyPrs.bat`(0→124 等键循环)、
> `高级范例Caps-Num.bat`(0→124 **源即无限循环**)、`将文件夹变为磁盘.bat`(0→127 源 `pasue` 笔误)。
> 另 5 文件 `rc≠0→124/1`（本已失败）。**非交互、非源畸形 eligible 文件 rc 零回归**；
> **无新增静默错**（行为忠实 cmd，`bash -n` 全过）。完整表见 `v2.5.0-breaking-changes.md` §三.1。

## 7. 已知限制 / 发现（纪律 4 披露）

1. **门控默认关闭**：`backward_loop` / `in_block_goto` / 一般 `forward_skip` 的**默认路径仍为诚实 TODO**。
   状态机实现存在且经语义测试，但**未激活**（§10）。
2. **`label_in_block`（97/4）未覆盖**：须标签提升或整块扁平化（编译器级，路线图 15–25 人日）→ 诚实 TODO。
3. **`missing_label` / `dynamic_target`**：无静态安全映射 → 诚实 TODO（纪律 7）。
4. **门控版语义**：`pc=…; continue` 会覆盖 `$?`（cmd 的 goto 亦不保留 errorlevel）；
   `continue N` 依赖块栈循环计数（已测两层嵌套）。
5. **eligible=26，emit 成功 25**：`瑞星…` 因状态机产物 `bash -n` 失败自动回退（失败安全）。
6. **`cfg_state.py` docstring 使用 RST code-block**：仓库既有 `batch.py`/`cfg.py` 同风格长 docstring。
