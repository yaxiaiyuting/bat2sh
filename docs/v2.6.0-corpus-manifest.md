## 三、分类

### 3.1 任务书口径（`pause` 亦计交互）

| 类 | 判据 | 数量 | 占比 |
| :--- | :--- | ---: | ---: |
| **可 oracle** | 无交互 + 无环境依赖 | **8** | 10.1% |
| 交互式 | `set /p` / `pause` / `choice` | 59 | 74.7% |
| 环境依赖 | `reg` / `sc` / `net` / `rasdial` / `.exe` | 1 | 1.3% |
| 混合 | 交互 + 环境依赖 | 11 | 13.9% |

> **对 10% 阈值的判定**：任务书 §十二设「可 oracle < 10% → 暂停报告」。本口径 = **10.1%**（擦线通过）。

### 3.2 精化口径（用于 oracle 抽样；口径偏离披露，纪律 4）

**依据**：`pause` 在 EOF stdin 下**立即返回**（不挂起），真正会挂起的是 `set /p` / `choice` 循环。
故 oracle 抽样把「仅含 `pause`」视为**可 oracle**。

| 类 | 判据 | 数量 | 占比 |
| :--- | :--- | ---: | ---: |
| **可 oracle（精化）** | 无 `set /p`/`choice` + 无环境依赖 | **57** | **72.2%** |
| 硬交互 | `set /p` / `choice` | 17 | 21.5% |
| 环境依赖 | `reg`/`sc`/`net`/`.exe` 等 | 5 | 6.3% |

**结论：两种口径均 ≥ 10% → 不触发暂停，进入验证。**
