## A1 —— `%VAR%` 立即展开冻结语义（独立 commit）

**范围**：`python/bat2sh/core/batch.py`（1 个核心文件，9 处：`_Block` 字段、
`_a1_*` 3 个私有方法、`env_repl`、`_register_assigned`、`_convert_if`×3、`_convert_for`×4、
`_emit_for_f`、`_close_block_line`×3、`_compose`）。

**机制（S2 精确）**：块内用户 `%VAR%` → 占位符 `\x00A1:<blk>:<var>\x00`；
`_register_assigned` 记录同块赋值；`_compose` 末统一解析——仅对「同最外层块内被赋值」的变量
在块头前发射 `__bat2sh_snap_<v>="${v}"` 并改写引用；未命中者还原 `${v}`（活引用）。

### 根因与修复

| 根因 | 修复 | 证据 |
| :--- | :--- | :--- |
| 相邻 `%date:~0,4%%date:~5,2%` 的中缝 `%%` 被误判为 `%%NAME%%` 转义 / `%%x` 循环变量 | 在转义正则**之前**为相邻完整 `%…%` 插入 `_ADJACENT_VAR_SEP` 哨兵（字符集收紧为 `[A-Za-z_~][\w:~,.*+-]*`，避免跨引号/运算符误匹配） | probe：`set /a num3=%num4%%num1:~0,1%/…` 由 TODO→ `${num1:0:1}` 正确转换 |
| ENV_MAP 子串（`%date:~..%`/`%time:~..%`）在哨兵修复后**泄漏字面量** | 新增 `_env_substring_todo` 标志，行级诚实 TODO（不发明映射） | probe：`%date:~0,4%…` → `# TODO`（非字面量泄漏） |
| `%ERRORLEVEL%` 默认 `warn` → TODO（既有 `map` 设施未启用） | **`last_exit_code` 默认 `map`**（显式 `warn` 仍在） | `test_errorlevel_default_uses_rc_capture` |

### 075 —— 文档更正（不改码）

- 事实：块内标签经 `_error_block_line` → `report.errors`（**error 层，非 todo**）；
  产物仍发射 `# TODO: 手动检查: …` 标记（统一检索约定）。
- `--fail-on-todo` 统计 `todo_count + error_count`（`cli.py`）→ **会命中**；
  严格口径经 `# TODO` 标记判定为 degraded → **无静默缺口**。
- 结论：v1.9.1 归因「--fail-on-todo 不会命中」有误（r2 路线图已更正）；
  本版**不做代码改动**（守卫测试 `test_label_in_control_block_is_error` 明确断言该语义）。
