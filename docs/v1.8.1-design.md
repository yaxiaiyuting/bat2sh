## 2. bat 静默错误基准（前置 B）

bat 侧无原生基准（Linux 无 `cmd.exe`），故采用**三仪器组合**，可复现且可校准：

### 2.1 仪器 1：模式扫描（主，可复现）

针对**已归档的静默类**（`docs/real-corpus-report.md` §9 的 X1–X10）维护模式库，
每条含 (a) 正则签名 (b) 最小复现 (c) 观测到的错误行为。

```
X1 @echo off&setlocal 链     → 输出 "off" + 延迟展开失效
X2 !var! 延迟展开泄漏
X3 dir /b *.txt → 引号通配   → 空循环
X4 %var:~n,m% 子串/替换泄漏
X5 数字结尾 + >nul → fd 吞位
X7 dir /a-d 开关泄漏
X8 行尾 \ 触发续行
X9 %random% / 重复 %a% 原样
```

**判定**：脚本**语法通过**（`bash -n` OK）且命中任一签名 → 计为「静默嫌疑」。

### 2.2 仪器 2：可观测副作用（自洽性）

在沙箱内运行；若脚本 **rc==0（“看起来成功”）** 但 stdout/stderr 仍含**未解析的 Windows 语义标记**
（`%VAR%`、`!VAR!`、`nul`、`C:\`、`errorlevel`），则说明它**静默地带着错误语义继续跑**
（而非响亮失败）→ 计为「静默错误」。

### 2.3 仪器 3：人工标注（校准层）

随机抽 **12 个**语法通过脚本人工核对，估计仪器 1/2 的误报率，并报告校正后的区间。
**人工结果不与仪器 1/2 合并进分母**，仅作校准说明。

### 2.4 汇总口径

```
静默错误率 = |仪器1 ∪ 仪器2 命中、且语法通过 的脚本| / |语法通过 的脚本|
```

**环境依赖单列**：运行时失败若归因于「Linux 无对应工具且无合理组合」，记为 `env_dep`，
**不计入语法通过/静默错误的分母**，单独给出占比。

> 不设硬门槛（v1.8.1 任务书明确「不设硬门槛，必须披露」）。

## 3. 结构化映射表设计（硬约束）

### 3.1 位置与单一数据源

- 模块：**`python/bat2sh/mappings/windows_tools.py`**（仓库布局为 `python/`，非 `src/`）。
- `WINDOWS_TOOLS: tuple[ToolMapping, ...]` 为**唯一数据源**；
  转换器/rules 从该表**派生**，不得在多处硬编码同一映射。

### 3.2 条目 schema（每条必填）

```python
@dataclass(frozen=True)
class ToolMapping:
    win: str                      # Windows 命令名（小写）
    linux: str                    # 对应命令/组合（none 时为空串）
    form: str                     # 1:1 | 1:N | N:1 | partial | none
    confidence: str               # A | B | C | D
    output_contract: bool         # 脚本是否依赖其输出格式
    dangerous: bool
    target_exists: str            # yes | no | unknown
    evidence: str                 # 必填！"corpus/<file>:<line>"
    notes: str = ""
```

### 3.3 校验规则（`validate_mappings()`，测试守护）

| # | 规则 | 违反后果 |
| :--- | :--- | :--- |
| R1 | `evidence` 非空且形如 `corpus/<name>:<line>` | **拒绝**（纪律 7：不发明映射） |
| R2 | `form ∈ {1:1,1:N,N:1,partial,none}` | 拒绝 |
| R3 | `confidence ∈ {A,B,C,D}` | 拒绝 |
| R4 | `target_exists ∈ {yes,no,unknown}` | 拒绝 |
| R5 | `confidence == D` ⇒ `form == none` 且 `linux == ""` | 拒绝（诚实：不硬凑组合） |
| R6 | `output_contract is True` ⇒ `notes` 必须含「输出格式」适配说明 | 拒绝（最隐蔽静默错误） |
| R7 | `target_exists == "no"` ⇒ `notes` 必须标注「目标物不存在」 | 拒绝 |
| R8 | `win` 唯一（大小写不敏感） | 拒绝 |

### 3.4 铁律（与任务书一致）

1. 缺 `evidence` 一律拒绝。
2. `confidence: D` 诚实标 `none`（`regsvr32`/`chcp`/COM 类），不硬凑。
3. `output_contract: true` 必须附输出格式适配。
4. `target_exists: no` 必须标注（翻译对了但 Linux 没这服务/进程）。
