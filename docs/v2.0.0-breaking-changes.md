# bat2sh v2.0.0 破坏性变更声明

> 会话：v2.0.0 解析层/词法层硬化。分支 `v2.0.0-parser`；起点 HEAD `88c8384`。
> 依据：`docs/v2.0.0-review.md`（裁定）。**2.x 是 major 版本，允许「修正错误语义」的产物变化。**

## 1. 总则

### 1.1 允许

- **修正错误语义的产物变化**：原产物是**错的**（语法失败 / 明显错误），新产物是对的。
  判据 = 最小复现 + 人工核对 + wine 黄金对照（如适用）。

### 1.2 禁止（硬门）

| # | 禁止项 | 判据 |
| :--- | :--- | :--- |
| 1 | **指标倒退** | `syntax_ok` < 147；`strict` < 19；`degraded` > 83；崩溃/超时 > 0 |
| 2 | **CLI / API 破坏** | CLI 参数、`ConvertSettings`、`core/api/*`、GUI 调用**保持不变** |
| 3 | **引入静默错** | 不得把「安全 TODO」换成「未验证的映射」；未诊断的行为错 = 0 |
| 4 | **触 053 已修路径** | `_prepass`/`_label_line`/`_convert_for`/`_emit_for_f`/`_convert_if`/`_pop_block`/`_close_block_line`/`_Block`/`await_paren_close` 不得改动 |
| 5 | **触 A1 热路径** | `_expand_vars`/`env_repl`/`_a1_*`/`_guard_unset_variable_refs` 不得改动 |

## 2. 本版破坏性变更（逐项）

> 说明：本节记录**预期会改变产物**的项（修正性）。实测差异以 `docs/v2.0.0-report.md` 为准。

### BC-1（P1）`今天访问过的程序文件所在目录.cmd` —— 降级管道行的括号配平

| 项 | 内容 |
| :--- | :--- |
| **变更前** | 第 25 行 `… \| findstr … && (` 被降级为 3 行注释，**丢失开括号登记**；产物尾部出现多余 `)` → `bash -n` 失败 → **整脚本降级为注释**（不可用） |
| **变更后** | 降级注释**登记未闭合 `(`**；注释块引号感知计数括号，配平后重派发尾部 → 产物**语法合法**；被降级的 `&& (` 组体以注释保留（保守，不执行未验证代码） |
| **性质** | **修正错误语义**：从「整脚本不可用」→「可用 + 局部诚实 TODO」 |
| **影响范围** | 该文件（+ 所有「降级行含未闭合 `(`」的语料，实测仅此 1 例；另 1 个在用注释块的文件须零回归） |
| **风险评估** | 语义方向正确（不再产出坏 bash）；不引入静默错（组体为可见注释 TODO） |

### BC-2（P2）`if exist "%VAR:"=%"` —— `%VAR:"=%` 引号剥离

| 项 | 内容 |
| :--- | :--- |
| **变更前** | `if exist "%source_path:"=%" (` 被非贪婪正则切成 `"%source_path:"`，剩 `=%" (` 泄漏 → 产物引号失配 → 整脚本降级 |
| **变更后** | `if exist` token 正则识别 `%…%`（内含 `"` 不作出界），条件正确解析为 `[ -e "${source_path//\"/}" ]` → 语法合法 |
| **性质** | **修正错误语义** |
| **影响范围** | `文件归类整理器.bat`；其它 `if exist` 形态（普通引号、通配符、`compgen -G`）须保持不变 |
| **风险评估** | 低（单点正则）；须回归全部 `if exist` 测试 |

### BC-3（P3a）`if errorlevel` 条件绑定 —— 拒绝结构行

| 项 | 内容 |
| :--- | :--- |
| **变更前** | 上一条发射产物为 `if ! echo …; then` 时，`_take_previous_command` 将其当作「上一条命令」，拼出 `if ! if ! …; then; then` → 语法失败 → 整脚本降级 |
| **变更后** | `_take_previous_command` 拒绝结构行（`if …; then` 等）→ `_errorlevel_condition` 返回 `None` → 回退为 `[ $? -ge N ]` + 可见告警 |
| **性质** | **修正错误语义**（回退路径是项目既有的诚实降级） |
| **影响范围** | `史上最牛X…bat`；其它 `if errorlevel` 内联绑定（`_take_previous_command` 取到真命令时）须保持不变 |
| **风险评估** | 低；若某文件原本正确绑定到真命令，不受影响（仍取到该命令） |

### BC-4（非本版）LF-1 —— 无变更

LF-1 修复（`_convert_for` 头贪婪）**不在本版**（退回 2.x）。无产物变更。
