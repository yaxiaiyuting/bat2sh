## 二、A 类（bat2sh 缺陷）—— **1 个，已修**

| # | 缺陷 | 严重性 | 证据 | 状态 |
| ---: | :--- | :--- | :--- | :--- |
| **A-1** | **CFG 状态机丢弃子转换器报告** → `total_lines`/`todo_count` 恒为 0 | **高**（`--fail-on-todo` 静默失效） | `BuildAll.bat`：产物 5 个 `# TODO`，`report.todo_count=0`，`--fail-on-todo` **退出 0**（应 3） | ✅ **已修**（commit `306ea35`） |

### A-1 详情（v2.5.0 引入的回归）

- **根因**：`cfg_state.emit` 用独立 `_DispatchConverter` 转换，**只取产物、丢弃其 `report`**；
  父 `BatchConverter.convert` 在 gate 命中时**直接 return**，`self.report` 保持空。
- **影响**：
  1. `--fail-on-todo` / `--run` TODO 防护对状态机文件**静默失效**（CI 卡点漏网）。
  2. `report` 显示的 `总行数/已转换行数` 为 0。
  3. **指标少计**：`degraded_todos` 把状态机文件的 TODO 计为 0（老 151 语料 **814 实为 851**）。
- **修复**：`emit` 成功后 `_merge_report(父, 子)`（`total_lines`/计数/`warnings`/`todos`/`errors`）。
- **回归测试**：`tests/test_cfg_state.py::test_state_machine_preserves_report` /
  `test_state_machine_fail_on_todo_predicate`。
- **指标纠正**：老 151 语料 `degraded_todos 814 → 851`（**校正，非倒退**）；
  新语料 `61 → 136`。
