# bat2sh v2.1.0 破坏性变更声明

> 会话：v2.1.0（CFG 只读数据模型 + goto 简单形态 pilot）。分支 `v2.1.0-cfg`；起点 HEAD `d901b5c`。
> 上位条款：`docs/2.x-roadmap-research.md` §5（破坏性变更声明）。
> 本文件在**实现前**给出总则与预期，**实现后**回填实测（§4）。

---

## 1. 总则

| 类别 | 判定 | 说明 |
| :--- | :--- | :--- |
| **修正错误语义的产物变化** | **允许**（须逐项评审 + wine 对照 + 最小复现） | 例：语法失败文件转为可跑、goto TODO 转为正确控制流 |
| **指标倒退** | **禁止** | `strict` 不得因「诚实 TODO 化」下降；`degraded` 不得因回归上升（定义性位移除外，须披露）；崩溃/超时保持 0 |
| **CLI / API 破坏** | **禁止** | `--fail-on-todo`、退出码、`ConvertSettings`、`core/api/*`、GUI 调用保持不变；新增能力须向后兼容 |
| **引入静默错** | **禁止** | 任何把「安全 TODO」换成「未验证映射」的变化 = 破坏性缺陷，回滚即停（纪律 1/13） |
| **触及 053 / A1 路径** | **禁止** | 053：`_prepass`/`_label_line`/`_convert_for`/`_emit_for_f`/`_convert_if`/`_pop_block`/`_close_block_line`/`_Block`/`await_paren_close`；A1：`_expand_vars`/`env_repl`/`_a1_*`/`_guard_unset_variable_refs` |
| **报告契约** | **不变** | `Diagnostic(category, message, original, line)`；`--fail-on-todo` 语义不变 |
| **新增硬依赖** | **禁止** | 不得要求 wine / Windows 组件才能转换（wine 仅测试 oracle） |

## 2. 本版预期（实现前）

**P4 定位为纯只读基础设施**（`core/cfg.py` + `tools/cfg` + `tests/test_cfg.py`）：

- 转换器**不 import** `core/cfg.py` → **产物零变化**；
- 不新增/不改任何诊断；不改 CLI/API；
- 因此**预期破坏性变更 = 无**。

**P5**（`redundant_goto` / 顶层 `forward_skip`）经实测（`docs/v2.1.0-coldstart.md` §4）
**翻转 0 且安全子集零产物影响/高风险** → 显式归 v2.2.0，本版**不实现** → 不引入其破坏性变更。

**B5** 归 v2.2+ → 不实现。
