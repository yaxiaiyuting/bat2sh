## 二、验收标准（原则性表述，纪律 17）

1. **goto 形态覆盖**：C4 台账 **7 主 + 1 辅**全部有明确归属——**已实现**（由可执行测试锁定真实转换）
   或**诚实 TODO**（响亮、非静默、附证据）。**不发明映射**（纪律 7）。
2. **053/A1 不回归**：126 条专项全绿；053 覆盖 5 文件判据/产物零意外变化；A1 七文件 `__bat2sh_snap_*` 不变。
3. **不引入静默错**：无「跑通、无 TODO、行为错」；由 **wine oracle 6/6** + 逐文件产物字节 diff 守护。
4. **指标不倒退**（定义性位移除外）：151 语料 `syntax_ok / rc0 / strict / degraded / crash` 不劣化；
   pytest 只增不减；examples 零字节漂移。
5. **重构策略可回滚**：每 Stage 独立 commit + 独立回滚锚；门控可一键关闭回退。

## 三、风险与最小复现（实现前只读）

| 风险 | 最小复现（预期用于 Stage 验证） |
| --- | --- |
| 回边误判（循环边界错） | `:L\necho a\ngoto L` → 期望 `while`/pc 分派；断言运行输出序列 |
| 块内越块 goto 结构破坏 | `判断分区格式.bat` 的 `for (…) goto type` 同构 fixture |
| bash `for` 内 `continue` 语义错 | `for x in …; do if …; then goto OUT; fi; done\n:OUT` → 须真正跳出 for |
| 多入口标签 | 两处 goto 同一标签 → 分派臂须可从两处进入 |
| 053 块栈回归 | 直接跑 D1（126 条）+ `05x` 语料逐文件 diff |
| A1 冻结回归 | D1 的 `test_batch_var_block_freeze.py` + A1 七文件 snap 计数 |
| 近失静默错（v2.4.0 教训） | **必跑**逐文件产物字节 diff（不可只跑 pytest） |
