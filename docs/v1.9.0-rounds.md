## P1 —— 取消静默丢弃（`d1f6a05`）

**根因**：`_convert_simple_no_pipe` 的 handler 分支 `if line is None: return []`
（自 1.0.0 起）——`cmd_todo_hint` 登记 todo 后 `return None`，整行被丢；
其余分支 `line is None` 会补 `# TODO`，两条路径不一致。

**修复**：① `cmd_todo_hint` 返回 `# TODO: 手动检查: <原行>`；
② `_convert_logical` 增加**丢失检测**：源行未产出且无诊断且非既定 noop → `warn(category="loss")`；
③ `_is_intentional_drop` 逐 `&` 子句判 noop（`@echo off & setlocal …` 不算丢失）。

**证据 / 影响面**：6 文件（`001` 134 条 attrib、`013`、`023`、`072`、`079`、`102`）。
**指标**：churn 15/151，**rc 全部不变**；功能完好 22→19（3 条转入 degraded，诚实化）。
**丢失检测误报**：151 语料 **0**（首版 7 条误报来自 `@echo off & setlocal` 复合行，已收窄）。

## P2 —— 053 块栈根因修复（`61a4b44`）

**根因**：`_convert_if` 对行尾**未配平** `else (` 仍 `pop`+补 `fi`，与 `_close_block_line`
（push `await_paren_close` 块）不对称 → else 体出循环 → `_convert_for`/`_emit_for_f`
无条件 pop 到错误块 → `%%i` 逸出 → `))` 落空栈。

**修复**：`_Block.finish_parent` + `_pop_block` 链式收尾 + `_close_block_line` 支持 `))`
+ `_convert_if` 对称化 + `_convert_for`/`_emit_for_f` 不再盲 pop（共 5 hunk，非词法层）。

**证据**：`将所在目录的BAT…bat:12`；修复后源第 13–30 行全部进循环，`cat %i` → `cat ${i}`。
**指标**：churn 5/151；语法 145→146（`073` 转为可运行）。

## P4 —— B-1/B-2/B-3 判定（`fdf6e4c`）

| 项 | 置信度判定 | 处置 | 结果 |
| :--- | :--- | :--- | :--- |
| **B-1** 盘符全路径不查映射表 | **B** | **修** | `宽带连接.bat` rc 127→0（转诚实 TODO） |
| **B-2** `start` 内层命令不派发 | **B** | **修** | `035 显示隐藏扩展名.bat` rc 127→0（转诚实 TODO） |

| **B-3b** `regedit`/`subst` 被 `cmd_todo_hint` 遮蔽 | D / C | **记录** | P1 后二者均落**显式 TODO**，已一致 |
| **B-3c** `title` 被 `cmd_noop` 遮蔽 | **D（判定）** | **记录，不修**（披露） | 见下 |

**B-3c 偏离说明（纪律 4 主动披露）**：映射表 `title` 为 B（`printf '\033]0;%s\007'`），
按「B → 修」机械读法应发射 ANSI。**本次判定为 D（记录不修）**，理由：
1. `title` 为**控制台窗口修饰**，脚本语义无关，`cmd_noop` 丢弃是 v1.0 起的既定设计；
2. 「修」（发射 OSC 转义）会向**重定向输出/管道**注入终端转义序列，属行为回归风险；
3. 映射条目继续作为「Linux 等价物」的知识记录（与 `ping` 同类），并非失效缺陷。

**指标**：churn 9/151；rc==0(原始) 100→**102**（`035`/`051` 转诚实 TODO），rc≠0 47→**45**；
功能完好 18→16（`116`/`118` 的 `beenotice` 转 TODO）。
