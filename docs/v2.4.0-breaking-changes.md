# bat2sh v2.4.0 破坏性变更声明

> 会话：v2.4.0（goto CFG 高级，硬做授权版）。分支 `v2.4.0-goto-cfg`；HEAD 锁定 `5da34eb`。
> 本文件在**实现前**声明允许/禁止的破坏性变化，实现后逐项回填实测。

---

## 1. 性质

**允许破坏性变更，但只允许「让产物更接近 cmd 语义」的变更。**
本 session 的核心是「把已证等价/已证不可达的 goto 从 TODO 变为真实转换」——**产物必然变化**。
统一口径：**变化的判据不是「是否有 diff」，而是「新产物是否比旧产物更符合 cmd 语义、且无静默错」。**

---

## 2. 允许（Allow）

| # | 允许项 | 说明 | 影响面 |
| --- | --- | --- | --- |
| A1 | `redundant_goto` 从 `# TODO` → 等价 no-op 注释 | 目标即下一条语句；cmd 语义本就等同继续执行 | 预计 5 个语料文件（`31/038/040/077/104`） |
| A2 | `forward_skip` 不可达区间从「原样发射（会在 bash 中执行）」→ **显式注释（不执行）** | 修正一个**语义错误**：原产物让 cmd 中被跳过的代码在 bash 中执行 | 预计 2 个语料文件（`031/071`） |
| A3 | 旧的「死代码会执行」告警文案 → 「已按不可达注释」说明 | 文案随语义修正而更新 | 产物注释文本 |
| A4 | 相应测试断言从「编码现状」改为「cmd 正确语义」 | 纪律 14 | `tests/test_batch_goto_structure.py` 等 |
| A5 | C4 台账 `plan`/`notes` 文本更新 | 只读台账，反映实现状态 | `core/control_flow.py` 文档串 |

## 3. 禁止（Forbid）

| # | 禁止项 | 判据 |

| F1 | **引入静默错**：产物跑通但行为与 cmd 不等价；或源行无诊断地蒸发 | wine 对照 + `_check_silent_drop` |
| F2 | **053 回归**：块栈失同步、`%%i` 逸出、`))` 落空栈、块未闭合告警 | `v2.4.0-053-protection.md` §3 |
| F3 | **A1 回归**：`%VAR%` 冻结语义丢失/新增错误快照 | A1 测试 + `__bat2sh_snap_*` 差异 |
