# bat2sh v2.4.0 破坏性变更声明

> 会话：v2.4.0（goto CFG 高级，硬做授权版）。分支 `v2.4.0-goto-cfg`；HEAD 锁定 `5da34eb`。
> 本文件在**实现前**声明允许/禁止的破坏性变化，实现后逐项回填实测。

---

## 1. 性质

**允许破坏性变更，但只允许「让产物更接近 cmd 语义」的变更。**
本 session 的核心是「把已证等价/已证不可达的 goto 从 TODO 变为真实转换」——**产物必然变化**。
统一口径：**变化的判据不是「是否有 diff」，而是「新产物是否比旧产物更符合 cmd 语义、且无静默错」。**

### 4.1 实现期捕获的「近失静默错」（主动披露）

Stage B 初版用 ASCII 标签正则判定「区间内是否有标签」，漏判 CJK 标签；`104` 的区间含 `:退出`，
而 `if "%s%"=="6" goto 退出` 会跳入 → 初版会注释掉**可达**代码（静默错）。
**逐文件产物 diff 捕获**（104 意外变化）→ 改为宽松标签判据（含 CJK，有标签样行即拒绝）→ 104 恢复零变化。
（详见 `docs/v2.4.0-report.md` §5。）
