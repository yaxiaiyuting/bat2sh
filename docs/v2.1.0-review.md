## 3. 最小复现（全部本 session 实测，可复现）

> 复现命令（只读，输出在 `/tmp/bat2sh-v210/`）：
> ```bash
> python3 -c "import sys;sys.path.insert(0,'python');from bat2sh.core.engine import convert_file;from bat2sh.core.settings import ConvertSettings;print(convert_file('FILE',ConvertSettings(bash_check=False),write=False).text)"
> ```

### 3.1 `redundant_goto`（最小例，语法通过）

```bat
@echo off
goto skip
:skip
echo done
```

- 形态：`goto skip`（第 2 行）→ 目标 `:skip`（第 3 行）即**下一条语句** → 可证 no-op。
- 转换器现状：第 2 行 → `# TODO: 手动检查: goto skip`（+「以下代码原被跳过」注记）。
- **消除后产物**：删除该 TODO 注释即可（语义等价）。
- **实测价值**：语料中**独立行**冗余 goto 集中在 `史上最牛X…bat`（**语法失败** → 最终产物是
  `degraded_script` 整体注释块 → 消除后**产物零影响**）；其余 27 条嵌在复合行（见 §3.2）。

### 3.2 `redundant_goto` 的真实形态（复合行，非独立 no-op）

```bat
:: 瑞星杀毒软件2008批处理版.bat:76
net share | find /i "admin$">nul & if errorlevel 1 (goto 1) else echo 你电脑开启了admin$共享
:1
```

- 「goto 1」的下一语句是 `:1` → 该分支 no-op，但**同一行还有 else 分支**（非 no-op）。
- 消除须**重写整行**（`if/else` + 管道 + errorlevel），而非删一行；触及 `_convert_if` /
  `errorlevel` 绑定 → 风险升、收益 0。

### 3.3 顶层 `forward_skip`（条件 guard，最小例）

```bat
@echo off
if not defined X goto middle
echo A
:middle
echo B
```

- 正确 bash 近似：`if [ -n "${X:-}" ]; then echo "A"; fi; echo "B"`。
- **危险点**：若被跳过区间内含标签、且该标签被**别处跳入**，则区间并非死代码，包裹为 `if` 即**语义错误**：

```bat
@echo off
if not defined X goto middle
echo A
:middle2
echo c2
:middle
echo B
:: 别处：goto middle2   ← 该入口会跳过 echo A，包裹会破坏
```
- **语料实测**：`打开快捷方式指向的目录.bat:7` 的 `if … goto error` 跳过区间含 **`for /f` 块**
  （9–13 行）→ 包裹需块结构发射；且该文件另有 `start` TODO（非 goto）→ **0 翻转**。
