## 4. 关键归属：goto CFG 高级

> **判定：「语义完整但翻转 0」→ 归终态（仅 T1 真实需求触发重评）。**

理由（三条实测）：

1. **翻转 0**：15 个多入口标签文件全部是多设施（`系统优化` 443 TODO）或语法失败（`史上最牛X`）；
   唯一 goto 单桶可翻转文件（`显示所有分区的剩余空间`）**无多入口**、纯被 `_label_line`(053) 阻塞。
2. **成本高**：完整 goto 状态机 15–25 人日（路线图 §1.C4），换 **0** 文件翻转 → 违反纪律 1/17。
3. **前置依赖未解**：须先安全重构 053 已修路径（`_label_line`/块发射），本身是高风险解析层工程。

**触发重评的条件（唯一）**：**T1 出现真实需求**（真实迁移中大量 goto 脚本、且用户明确要求）。
届时从 `core/cfg.py`（只读数据模型，v2.1.0 已就位）+ `tools/cfg` 起步。**不静默归 3.x，也不无条件归终态。**
