## 3. 缺陷：A-1（v2.5.0 报告丢弃）—— **已修**

**现象**：CFG 状态机文件 `report.todo_count`/`total_lines` 恒为 0 → `--fail-on-todo` **静默退出 0**
（应 3）；指标 `degraded_todos` 少计。

**证据**（`BuildAll.bat`）：产物 5 个 `# TODO`，`report` 显示 `总行数:0`、`todo_count:0`、
`--fail-on-todo` 退出 **0**。

**根因**：`cfg_state.emit` 用独立子转换器，`convert()` gate 命中后**直接返回产物、丢弃子报告**。

**修复**：`emit` 成功后 `_merge_report(父报告, 子报告)`。

**影响/纠正**：

| 语料 | v2.5.0 degraded_todos | v2.6.0（修复后） |
| :--- | ---: | ---: |
| 老 151 | 814（**少计**） | **851** |
| 新 79 | 61（少计） | **136** |

> 相对 v2.4.0（900），真实下降为 **49**（非 v2.5.0 报告所称 86；差额 = 被丢弃的子报告 TODO）。

**回归测试**：`test_state_machine_preserves_report` / `test_state_machine_fail_on_todo_predicate`。

## 4. CFG 静默错隔离（纪律 20）

对 79 文件比较 **CFG on vs off**：**13 文件**受状态机影响。逐个 oracle / 归因：

- 无交互 CFG 文件（`modecon` / `汉字横排变竖排` / `random随机数生成器` / `BuildAll` /
  `adb发送到手机` / `生成随机字符串`）：**无状态机引入的静默错**。
  - `random随机数生成器`：wine TIMEOUT = bash-on TIMEOUT（**忠实复现 cmd 无限循环**）；bash-off 错误退出。
  - `adb发送到手机` / `生成随机字符串`：DIFF 在 **on/off 相同** → 预存在（CJK 变量名 / echo-on），非 CFG。
- 7 个交互文件：D 类（挂起，告警覆盖）。

→ **v2.5.0 状态机未在本语料引入新静默错**。完整表见 `docs/v2.6.0-corpus-attribution.md` §四。
