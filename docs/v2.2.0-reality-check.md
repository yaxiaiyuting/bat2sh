## 1. 逐项实测

### A. goto 回跳（`backward_loop` → `while/until`）

| 维度 | 实测 |
| :--- | :--- |
| CFG 语句 / 文件 | **446 / 28** |
| rc==0 degraded 含回跳 | **29 文件** |
| **可翻转文件** | **1** —— `显示所有分区的剩余空间（以MB为单位）.cmd`（2 TODO） |
| 该文件 goto | `goto Main`（**顶层**回跳，消息「goto 控制流无法自动转换」）+ `goto loop`（**函数内**回跳，消息「goto 跨函数跳转无法自动重构」） |
| 宿主集中度 | 高：`系统优化.bat`(443 TODO, 多设施)、`史上最牛X…bat`(3203, 语法失败) 占大头；另有 `文件夹伪装`(93)、`文件备份器V2.3修改版2.cmd`(76)、`瑞星杀毒软件2008`(57) 等均为多设施 |
| 需块结构发射（053） | **是** —— 回跳→循环须在**标签处发射 `while`**、在 goto 处发 `done`，直接触 `_label_line`（053 已修路径清单） |
| 需 CFG 高级 | **是** —— 循环区间识别 + 出口条件（`if not "%num1%"=="" goto loop`）+ 函数内自环 |
| **裁定** | **退回 v2.3+**（触 053 无清晰方案；翻转仅 1） |

**明细（唯一可翻转文件）**：

```bat
:Main                    ← 顶层回跳目标
...                       (for /f + call :loop)
goto Main                ← 需 while true; do … done
:loop                    ← 函数（call :loop）
...
if not "%num1%"=="" goto loop   ← 函数内自环，需 while/until + break
goto :eof
```
