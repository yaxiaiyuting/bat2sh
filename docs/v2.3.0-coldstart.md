## 4. 前提核对

### 4.1 goto CFG 高级（回跳 / 块内）的实测候选有多少？

**rc==0 degraded 且全部 TODO = goto 的文件 = 1 个**（`显示所有分区的剩余空间（以MB为单位）.cmd`，2 TODO）。
其两条 goto 均为 `backward_loop`（`goto Main` 顶层回跳 + `goto loop` 函数内自环）。
转换须**在标签处发射 `while`** → 触 `_label_line`（053 已修路径清单）+ 需 CFG 循环识别。
**块内 goto：rc==0 单桶文件 0。** 详见 `v2.3.0-reality-check.md` §1。

### 4.2 B5 括号跨行累积能否收尾 `史上最牛X`？

**不能（实测）。** 用**定向探针**（`_logical_lines` 对 `for /f` 未闭合单引号物理行做累积）实测：

- 语料 churn = **1 文件**（仅 `史上最牛X`）；
- **语法仍失败** —— 修复第一处缺陷后，暴露**第二处独立缺陷**（生成 15284 附近，`.reg` 生成的 `echo`
  引号/内容失衡，与 `for /f` 无关）。

即：`史上最牛X` 是**多缺陷**文件，B5 单独不足；且 B5 改动触及**解析层核心 `_logical_lines`**（被全部转换共享）。
**B5 的实测价值 = 0（无语法/翻转收益，churn 1 语法失败文件）**。详见 reality-check §2。

### 4.3 注册表写逐键评估——是否全是终态？

**是。** 29 条全部为写类/导出（`reg add/delete` 18、`regedit /s` 5、`reg export` 3、`regini` 1），
Linux **无统一可写注册表**；映射到「对应配置文件」属**语义近似**（违反纪律 7）。
且当前**已输出结构化诚实 TODO**（`# TODO[REG] op=…`，v1.6.0 起）→ **无需改动**。详见 reality-check §3。

**否。** 前置五条全过；无并发写入。但**实测全项翻转 0**（含 goto CFG 高级「语义完整但翻转 0」）
