### 0.2 ⚠️ 数据更正（主动披露，纪律 4/9）

**v1.8.2 发布的文档中「运行 rc==0 = 105」是错的**，正确为 **99**。
原因：`105 = 151 − 46` 把 6 条**语法失败（无产物、不参与运行）**也算进了分母；
正确口径是「145 条语法通过者中 rc==0 者」= **99**（99 + 46 = 145）。

- 受影响文档：`docs/releases/v1.8.2.md`、`docs/releases/v1.8.2-verification.md`、
  `docs/v1.8.2-artifact-classification.md` §14（以及 GitHub Release 正文）。
- 相对 v1.8.1（rc==0 87）的真实变化是 **+12**（非 +18）；rc≠0 为 **58 → 46**（非「~64 → 46」）。
- **本次阶段一严格执行只读**，未改这些文档；建议下阶段以独立 commit 更正（待您裁定）。

## 2. 逐条归因（全 46 条）

### [001] rc=127 `C盘防毒批处理.bat` —— **B 源文件畸形**
- **归因**：源文件字面 `hattrib`（同文件 100+ 行均为 `attrib`）；cmd 亦报错
- **证据**：产物 L196: `hattrib ${SystemRoot:-/}/system32/uanyuan.exe +S +R +H` ｜ stderr: `hattrib: command not found`

### [002] rc=1 `U盘做加密狗.bat` —— **ENV/沙箱**
- **归因**：沙箱无 init/systemd（`systemctl` 无法连接 system bus）
- **证据**：stderr: `System has not been booted with systemd as init system (PID 1). Can't operate.`

### [003] rc=127 `bat解密工具.bat` —— **B 源文件畸形**
- **归因**：源文件装饰性分隔线行（非 echo）；cmd 亦报错
- **证据**：产物 L6: `---------------------------------------------------------------------------------------------` ｜ stderr: `---------------------------------------------------------------------------------------------: command not fou`

### [016] rc=127 `修复系统关联.bat` —— **B 源文件畸形**
- **归因**：源文件 `assoc.bat=batfile` 缺空格；cmd 亦报错
- **证据**：产物 L6: `assoc.bat=batfile` ｜ stderr: `assoc.bat=batfile: command not found`

### [032] rc=2 `右键菜单/右键添加新建BAT文件.bat` —— **ENV/沙箱**
- **归因**：沙箱 ping 需 CAP_NET_RAW（SOCK_RAW 不可用）
- **证据**：stderr: `ping: socktype: SOCK_RAW`

### [033] rc=1 `右键菜单/复制路径.bat` —— **ENV/沙箱**
