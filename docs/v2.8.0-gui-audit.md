## 二、优化方案（**仅限 配色 / 间距 / 图标 / 主题**）

### 2.1 配色统一（Commit 1）

1. **`theme.py` 增加语义色单一来源**（保持既有 hex 数值不变，避免回归）：
   - `PALETTE_HEX`：Base/Text/Highlight 的深/浅 hex 常量（与 `dark_palette`/`light_palette` 同源）。
   - `diff_colors(dark) -> (background, foreground)`：**返回与现状完全相同的值**
     （dark `#232629`/`#eff0f1`；light `#fcfcfc`/`#232629`），供 `build_diff_html` 使用。
   - `status_text_color(level, dark)`：新增 `success`（深/浅分别高对比）并复用
     `report_level_color("error", dark)` 作为失败色。**`report_level_color` 行为不变**（测试守护）。
   - `accent_color(dark)`：highlight（`#3daee9`）。
2. **`dialogs.py`**：`_show_api_test_result` 用 `status_text_color`（颜色按当前控件调色板深浅推导，
   不改构造函数签名）；`build_diff_html` 用 `diff_colors`（输出一致，测试守护）。
3. **`editor.py`**：当前行号改用 `palette().color(Highlight)`（自动随主题；Breeze 为 `#3daee9`）。

### 2.2 间距 / 对齐（Commit 2）

1. **状态栏**：初始计数标签改用 `counts_text(None)`（消除 P4 的措辞/顺序不一致）。
2. **主区容器**：`setSpacing(6)`（与面板默认一致；**只改间距数值，不改结构**）。
3. **面板内 header 行**：统一设置 `setSpacing(6)`（三栏面板 + 运行面板），保持对齐一致。
4. **语义**：不引入全局 QSS（避免覆盖 Breeze 样式、DPI 问题）；仅调 `QLayout` 间距常量。

### 2.3 图标（Commit 3）

1. **文件列表项**：`QIcon.fromTheme(name, self.style().standardIcon(...))` 增加兜底（复用 `_icon` 逻辑）。
2. **主题切换图标**：`weather-clear-night` → `preferences-desktop-theme`（Breeze 有；standardIcon 兜底保留）。
3. **工具栏图标尺寸**：显式 `setIconSize(QSize(22, 22))`（Breeze 工具栏标准；DPI 下 Qt 自动缩放）。

### 2.4 主题应用

- 维持 `setColorScheme` 优先 + 手工调色板兜底（KDE 友好）。
- 手工调色板补齐 `PlaceholderText` 的浅色值（`light_palette` 当前缺，深色已有）——一致性。

### 2.5 明确不做

- 不做：布局重做（三栏/工具栏/面板层级不动）
- 不做：交互流程改动（动作、快捷键、信号连接不动）
- 不做：新功能
- 不做：引入除 PySide6 外的任何依赖
- 不做：全局 QSS 覆盖（会破坏 Breeze 原生观感）

## 三、判据（任务书 §4.3）

**是否「必须重做布局才有效果」？→ 否。**

视觉问题全部落在配色（P1–P3）、一致性（P4）、图标（P5）、间距（P6），可在**现有三栏布局**
上直接优化，**不触碰布局结构、不改变交互**。

→ **继续实现 v2.8.0。**

## 四、硬性约束核对

| 约束 | 方案保证 |
| :--- | :--- |
| KDE Breeze 风格 | 不覆盖 Breeze 样式；复用其调色板/图标主题；仅调少量硬编码色 |
| 不重做布局 | 仅改 `QLayout` 间距数值、图标名、颜色值；结构不变 |
| 功能零回归 | 不触碰信号/动作/快捷键/业务逻辑；仅视觉属性 |
| 测试全绿 | `build_diff_html` 输出保持一致（测试守护）；`report_level_color` 不变 |
| 无新依赖 | 仅 PySide6 + 既有标准库 |
| DPI 兼容 | 不引入像素硬编码（图标 22px 由 Qt 按 DPR 缩放） |

## 五、风险与规避

| 风险 | 规避 |
| :--- | :--- |
| 改色破坏既有测试 | `build_diff_html` 保持旧 hex；`report_level_color` 行为不变；先跑 GUI 测试 |
| 间距改动导致拥挤/松散 | 仅统一到 6px；离屏构造校验不报错；人工核对 |
| 图标名在 Breeze 缺失 | 一律保留 `standardIcon` 兜底 |
| 高 DPI | 不硬编码几何尺寸（除已有 maxWidth 220，DPI 无关）；离屏 + 缩放环境校验 |
| 深浅色对比不足 | 成功/失败色按 dark 分别给高对比值 |
