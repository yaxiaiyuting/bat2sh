## 1. 只读审计（`docs/v2.8.0-gui-audit.md`）

**判据（任务书 §4.3）**：视觉问题全部落在 **配色（P1–P3）/ 一致性（P4）/ 图标（P5）/ 间距（P6）**，
可在现有三栏布局上直接优化，**无需重做布局** → **继续实现**。

审计要点：
- 主题框架（`QStyleHints.setColorScheme` + 手工调色板兜底）**已完整且 KDE 友好**；
- 缺口为**散落的硬编码颜色**与**少量间距/图标不一致**；
- 布局（三栏 `QSplitter` + 工具栏 + 可折叠运行面板）**无结构缺陷**。
