## 1. 只读审计（`docs/v2.8.0-gui-audit.md`）

**判据（任务书 §4.3）**：视觉问题全部落在 **配色（P1–P3）/ 一致性（P4）/ 图标（P5）/ 间距（P6）**，
可在现有三栏布局上直接优化，**无需重做布局** → **继续实现**。

审计要点：
- 主题框架（`QStyleHints.setColorScheme` + 手工调色板兜底）**已完整且 KDE 友好**；

- 布局（三栏 `QSplitter` + 工具栏 + 可折叠运行面板）**无结构缺陷**。

离屏（`QT_QPA_PLATFORM=offscreen`）以 `QT_SCALE_FACTOR=2` 与默认 `1` 分别构造 `MainWindow`、
打开并转换示例脚本：

| 场景 | 结果 |
| :--- | :--- |
| `QT_SCALE_FACTOR=2` | ✅ 无异常；`devicePixelRatio=2.0`；`counts_label` 与报告一致；布局 spacing=6 |
| 默认 `1` | ✅ 无异常 |
| 硬编码几何 | ✅ 无（图标 22 逻辑像素由 Qt 按 DPR 缩放；未引入像素硬编码） |
