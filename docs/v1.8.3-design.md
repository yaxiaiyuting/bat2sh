## 2. 逐条评估

### 2.1 [114] `窗口设置/2.bat` —— A，**建议修**（低风险）

- **根因**：`_guard_unset_variable_refs`（`core/batch.py:598`）在 626–627 行
  **先**把本行赋值并入 `assigned_main`，**再**做替换 → `str1="${str1}${i}"` 的自引用
  被当成「已赋值」，未加 `:-` → `set -u` 下 unbound。
- **拟改函数**：`_guard_unset_variable_refs` `core/batch.py:598`（626–627 两行**调换顺序**：
  先 `_substitute_guarded`，后 `assigned_main |= _collect_line_vars`）。
- **最小复现**：
  ```bat
  @echo off
  setlocal enabledelayedexpansion
  for %%i in (a b) do set str1=!str1!%%i
  echo %str1%
  ```
  当前：`str1="${str1}${i}"`（unbound）；改后：`str1="${str1:-}${i}"`。
- **影响范围（实测）**：151 语料中产物变化 **2–3 个**（`史上最牛X…bat`、`文件备份器V2.3…cmd`）；
  **examples 零漂移**。
- **风险**：**低**（局部顺序调换；`%%i` for 变量守护不受影响）。
- **建议**：**修**。

### 2.2 [085] `显示自己的IP.bat` —— A，**建议退回/需您决策**（中–高）

- **根因（两层）**：
  1. **输出契约**：`ipconfig` → `ip addr`（`cmd_ipconfig` `core/batch.py:2913`），
     但 `find /i "ip address"`（英文关键词）与 Linux `inet` 不匹配 → 循环体不执行；
     Windows 的 `tokens=15` 取位在 Linux 输出中无语义。
  2. **变量未初始化**：`ip` 仅在 `while` 循环体内赋值，循环不执行 → 循环后的
     `echo "${ip}"` unbound（`_guard_unset_variable_refs` 视「全文/前文有赋值」为已保证，**非流程感知**）。
- **拟改函数**：
  - 保险层：`_guard_unset_variable_refs`（`batch.py:598`）改造为流程感知（嵌套块赋值不保证）；
  - 契约层：英文关键词映射（对齐 `_FINDSTR_CJK_MAP` `batch.py:80`）+ `tokens=15` 取位适配。
- **最小复现**：
  ```bat
  @echo off
  for /f "tokens=15" %%i in ('ipconfig ^| find /i "ip address"') do set ip=%%i
  echo %ip%
  ```
  当前 → `echo "${ip}"`（unbound）。
- **影响范围（实测）**：
  - **流程感知改法 → 26/151 产物变化 + `examples/stress_test.sh` 漂移**（**不可接受**）；
  - 契约层需改**关键词/映射结构**（`_FINDSTR_CJK_MAP` 属映射表结构）。
- **风险**：**中–高**。
- **建议**：⚠️ 触发您设定的暂停条件——**「输出契约适配需触碰映射表结构」+ 高 churn**。
  **建议退回 TODO（或降为 D / 下一版）**，本版不硬修。请裁定。

### 2.3 [044] `备份文件/备份服务.bat` —— D，**建议修**（中）

- **根因**：`%FILENAME%` 未赋值 → `_render_redirs`（`core/batch.py:2587`）产出
  `>"${FILENAME:-}"` → 运行期展开为空串 → `>""` 报错。**重定向目标静态不可知**。
- **拟改函数**：`_render_redirs`（`core/batch.py:2587`）——若转换后的目标形如
  `${X:-}`（可能为空），则该重定向属「目标未知」，**整行诚实 TODO**（保守，纪律 1）。
- **最小复现**：`echo hi >"%FILENAME%"` → 当前 `>"${FILENAME:-}"`。
- **影响范围（实测）**：重定向目标为 `${X:-}` 的共 **19 行 / 3 文件**
  （`史上最牛X…bat`、`备份服务.bat`、`系统优化.bat`）。
- **风险**：**中**（重定向发射路径；但改法保守——只把「目标未知」降级为 TODO）。
- **建议**：**修**。

### 2.4 [047] `多功能系统优化设置.cmd` —— D，**建议修或退回，请裁定**（中）

- **根因**：`md "%select%:\Personal\Temp\">nul` → `mkdir -p`（`BATCH_SIMPLE_MAP`）**未做反斜杠转换**，
  产出 `"${select}:\Personal\Temp\"`；结尾 `\"` **转义了收尾引号** → bash 字符串未闭合 →
  后续多行被并成一条命令（xtrace 见单引号内嵌换行）。
- **拟改函数**：`_convert_simple_no_pipe` 的 `BATCH_SIMPLE_MAP` 分支
  （`core/batch.py:2509–2511`）——对 `rest` 施加 `convert_backslashes`（与其它 19 处一致）。
- **最小复现**：
  ```bat
  @echo off
  set select=D
  md "%select%:\Personal\Temp\">nul 2>nul
  ```
  当前 → `mkdir -p "${select}:\Personal\Temp\" >/dev/null 2>/dev/null`。
- **影响范围（实测）**：约 **14 个文件**含「简单映射命令 + 反斜杠语义」。
- **风险**：**中**；且该文件已 745 行 / 210 TODO，整体不可用，单点收益有限。
- **建议**：**修**（改动本身低风险、指向明确，可顺带修 `\` 逃逸类）；若您认为该文件已无救
  → **退回 TODO**。请裁定。

### 2.5 [053] `将所在目录的BAT…合并…bat` —— D，**建议退回 TODO**（高）

- **根因**：`for /f` + 嵌套 `if/else(` 使**块栈失同步**：`set/a a+=1`、`type %%i>>t.txt`
  逸出循环体（`cat %i` 中的 `%i` 为循环变量逸出），并出现「多余的 ')'，已忽略」。
- **拟改函数**：`_convert_for`（`core/batch.py:1903`）、`_emit_for_f`（`:2006`）、
  `_convert_if`（`:1540`）——**块栈（`_Block`/`await_paren_close`）核心**。
- **最小复现**：`for /f %%i in ('dir/b *.bat') do if %%i==a (…) else (if %%i==b (…) else ( … ))`。
- **风险**：**高** —— 与 v1.8.1 的 B1/B1b（块闭合）同域，正是 `%%i` 回归的高危区。
- **建议**：**退回 TODO / backlog**，本版不硬修（纪律 1）。

### 2.6 [062] `批处理生成的CMD命令帮助清单.bat` —— D，**建议退回 TODO（可选小修）**（高）

- **根因（两点）**：
  1. `cmd_cmd`（`core/batch.py:3310`）正则 `^/c\s+` 要求 `/c` 紧随 `cmd`；
     源为 `cmd /q /c "…"` → 不匹配 → 走 `/k` 分支 → 产出**裸 `bash`**（参数丢失）。
  2. 运行期 `unexpected EOF while looking for matching '`（未闭合引号/命令替换）——
     需进一步定位，涉及引号-替换路径。
- **拟改函数**：①`cmd_cmd`（`:3310`，正则放宽为 `^(?:/[a-z]+\s+)*/c\s+(.*)$`）；
  ②未闭合引号另需隔离（`_logical_lines`/引号配对）。
- **最小复现**：`cmd /q /c "b/?"` → 当前 `bash`。
- **风险**：①**低**（局部正则）；②**高**（引号/命令替换）。
- **建议**：**退回 TODO**（整体）；若您同意，可**仅做 ①**（`cmd /q /c` 参数保留）作为
  低风险子项，②留 backlog。请裁定。
