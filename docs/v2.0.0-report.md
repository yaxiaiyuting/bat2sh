2. **自我审阅与裁定**（`v2.0.0-review.md`）：范围/风险/最小复现/止损/退路/替代/验收；
   裁定 = **P1 收窄后实现 / P2 实现 / P3a 实现 / P3b（LF-1）退回 2.x**；
   **实现后回填**记录 P1 两次止损与收窄成功（§9）。
3. **破坏性变更声明**（`v2.0.0-breaking-changes.md`）：总则 + 逐项 + **实测回填 + 规格冲突披露**。
4. **只读诊断（实现前，纪律 2/9）**：三处根因 + 最小复现（`/tmp/opencode/`，未入仓）：
   - P1 = `_pipeline_todo` 不像 `_manual_block_line` 那样登记未闭合 `(`；
   - P2 = `_parse_condition` 的 `if exist` 引号正则非贪婪，未识别 `%VAR:"=%`；
   - P3a = `_take_previous_command` 未拒绝 `if …; then` 结构行。
   - P3b = `_convert_for:2092` 贪婪 `\((.*)\)`（触 053 路径 → 退回）。
5. **P2 实现**（commit `b5b1447`）：`if exist` token 正则改为 `%…%` 敏感。
6. **P3a 实现**（commit `6dd20ce`）：`_take_previous_command` 改用 `_is_structural_line`。
7. **P1 收窄实现**（commit `2d0b6a6`）：新增独立 `pcomment` 块类型 + 引号感知括号扫描 + 尾部重派发；
   **既有 `comment` 块零改动**（避免载荷性回归）。
8. **回归测试**（commit `31057c0`）：`tests/test_v2_parser_hardening.py` 7 条。
9. **发布**：bump → `2.0.0`；`release-preflight.sh` 通过；tag 打在 bump commit；push；tag 上 CI；
   GitHub Release（latest）；`PKGBUILD`/`.SRCINFO` 同步 + `makepkg` 验证；本机安装验证。
10. **文档**：coldstart / review / breaking-changes / release notes / 本报告。
