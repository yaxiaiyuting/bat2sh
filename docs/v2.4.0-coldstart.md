## 二、用自己的话复述

### 2.1 goto CFG 高级是什么

cmd 的 `goto` 是**任意跳转**：可以前跳、回跳、跳出/跳入控制块、目标动态求值。bash 是**结构化**语言
（`if/fi`、`for/done`、函数、`break/continue`），没有「跳到任意行」的原语。因此把 goto 译对，
本质上是**先重建控制流图（CFG）**——标签在哪、每条 goto 指向哪、方向如何、是否块内、几处跳入——
再决定该 goto 能否映射为某个结构化原语。

`goto CFG 高级` 特指：**多入口 / 多出口的块结构**（例如一段代码被多处 `goto` 跳入、或跳入点不在块首），
以及**回跳→循环、块内 goto→break/continue** 这类需要「循环区间 / 支配关系 / 可达性」判断的形态。
它不是「把某一类 goto 字面替换掉」，而是要一个**按 CFG 决策的转换策略**。

bat2sh 现状：`core/control_flow.py`（C4，只读形态台账）+ `core/cfg.py`（v2.1.0，只读数据模型：
标签表 + goto 边）已就位，但 **`integrated=False`，都不驱动转换**。唯一已实现的 goto 形态是
`goto :eof`（→ `exit 0` / `return`）。
