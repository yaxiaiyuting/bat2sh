# bat2sh v1.8.1 静默错误逐条归因 + 环境依赖拆细

> 对象：v1.8.1 报告中「静默错误 61/145 = 42.1%」与「环境依赖 35/151 = 23.2%」两项。
> 方法：只读重扫 + 逐条人工定位（最小复现）。**结论：原 42.1% 主要是仪器缺陷造成的误报，
> 真实静默错误为 3/145 = 2.1%；原 23.2% 的「环境依赖」中约六成是转换产物被误分类。**

---

## 1. 方法学缺陷（原 42.1% 的成因）

原「仪器 1（模式扫描）」扫描的是**源文件**（`X1 @echo off&setlocal`、`X5 \d>nul`、
`X9 一行两个 %var%` 等）。这些模式大量出现在**正常且已正确转换**的源码里：

| 原模式 | 误报原因 | 例子 |
| :--- | :--- | :--- |
| `X5 \d>nul` | 匹配了正常的 `2>nul`（v1.3 起即正确转 `/dev/null`），并非「末位数字被吞」 | 一键转移桌面…bat:50 |
| `X9 一行两个 %var%` | 任何含两个 `%变量%` 的行都命中，与「重复 `%a%` 未展开」缺陷无关 | `if not "%tmppf%"=="%partition%:\"` |
| `X8 行尾 \` | 匹配源码行尾反斜杠，而非转换产物行尾续行 | 定时备份…bat:4 |
| `X1/X2/X4/X7` | v1.3/v1.4 修复后源码命中≠产物泄漏 | — |

**修正**：改为扫描**转换产物**（`script.sh`）的**非注释行**，查找真正残留的 Windows 语义标记：
`%VAR%`、`!VAR!`、`%~x`、`>nul`。

| 口径 | 命中文件 |
| :--- | ---: |
| 原（扫源码） | 61 |
| 修正（扫产物） | **6** |

## 2. 逐条归因（6 个命中文件）

| # | 文件 | 命中 | 归因 | 判定依据 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | `lockcmd.bat` | `echo "…%password%…" >>lockcmd.bat` | **A 内容生成上下文（非 bug）** | 该行是在**写出另一个 .bat**，`%password%` 必须保持字面量才是正确语义 |
| 2 | `一键转移桌面-收藏夹-文档多用户版.bat` | `echo "pause>nul" >>reset.bat` | **A 内容生成上下文（非 bug）** | 同上：`pause>nul` 是要写进生成脚本的字面文本 |
| 3 | `将所在目录的BAT文件合并成一个BAT文件…bat` | `echo "if %gowhere%==1 …" >>小节.txt` | **A 内容生成上下文（非 bug）** | 同上 |
| 4 | `系统优化.bat` | `b=$(( %a%${2:-} ))`、`echo "Text"="%FORCE_OFFSCREEN_TEXT%"` | **B 真转错（部分）** | `$(( %a% ))` 是子程序内变量未展开；`"Text"="…"` 是写 .reg 的内容生成（该行非 bug） |
| 5 | `第三方工具/wselect-双击选择文件（夹）/原版.bat` | `bash "%temp%/temp.sh"` | **B 真转错** | `%temp%` 未展开（该文件使用了非标准形态，见 §4） |

## 4. 环境依赖 23.2% 拆细

原口径把「运行期 `command not found`」整体记为 env_dep。逐条核对后发现**约六成其实是转换产物**。

### 4.1 实为转换 artifact（应修，非 env）

| 运行期错误 | 证据 | 实质 |
| :--- | :--- | :--- |
| `hattrib: command not found` | `C盘防毒批处理.bat:196` | `attrib %systemroot%\…` 被反斜杠/变量处理拼接成 `hattrib` |
| `assoc.bat=batfile: command not found` | `修复系统关联.bat:6` | `assoc .bat=batfile` 无空格变体未识别（带空格变体已正确 TODO） |
| `:1: command not found` | `判断分区格式.bat:6` | `for /f` + `set var=%%j` 产物残留 |
| `c:windowssystem32rasdial` | `宽带连接.bat:6` | `%windir%\system32\rasdial` 变量未展开 + 反斜杠未转换 |
| `[[bat]]@echo: command not found` | `生成包含…网页.bat:6` | `@echo [[bat]]` 行内链处理 |

## 5. 结论

1. **静默错误率 42.1% 系仪器缺陷所致**；修正为扫描产物后为 **6 个命中文件**，其中**真实转错 3 个（2.1%）**。
2. 已据归因修复 **2 类真实缺陷**（相邻变量、`set /a` 取模）+ 补 **2 条映射**（`title`/`msg`）。
3. **原「环境依赖 23.2%」中约六成是转换 artifact**，已逐条列出证据并归入 backlog，而非当作「无对应」放过。
4. 已补 **tag 前 CI 模拟**（`scripts/release-preflight.sh`），防止再次出现「本地绿、tag 后红」。
