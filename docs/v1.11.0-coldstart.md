## 2. 用自己的话复述

### 2.1 C2 是什么

**C2 = 路线图 §2.1 归入 v1.9.4 的「L2 单命令/单构造映射扩容」批**，即：把 86 个 degraded 文件中
**属于 L2 层（一条命令或一个构造 → 一个 Linux 等价物）** 的 `# TODO` 转成真实 bash 代码，从而把
这些文件从 `degraded`（rc==0 但含 TODO）翻成**功能完好**。它**不含** `sc→systemctl`（C7，169 TODO，
宿主 `135 系统优化.bat` 被 goto 阻塞 → 移入 v2.0）。

任务书把它拆为三类小设施（路线图 §3.4 的设施 ROI 表）：

| 类 | 路线图声称（TODO / 涉及文件 / **单设施翻转**） | 内容 |
| :--- | :--- | :--- |
| **for 变体** | 32 / 22 / **10** | `for /r`、`for /f`（含选项/字符串/两段管道）、`for /l`、`for /d` 等 |
| **registry** | 29 / 20 / **11** | v1.6.0 已有结构化只读键表（`registry_map.py`），扩展示例 |
| **other** | 76 / 32 / **15** | **异构杂项，路线图未给出定义**（任务书亦注「待 session 归类」） |

**C2 的正当性论证**（closure §2.1 末行）：它「不需 CFG、不触块栈核心、不触 A1 热路径、
file-flip ROI 高（36 单设施翻转）、多数有 evidence」——**故无法推给 2.x，是 1.x 收尾的阻断项**。
