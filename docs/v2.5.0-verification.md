## 一、回滚通道（三层 + 优先级 `CLI > 环境变量 > 配置文件`）

逃生通道（任一即可整体回退到 v2.4.0 的「goto 诚实 TODO」行为）：

| 层 | 开关 | 说明 |
| --- | --- | --- |
| CLI | `--no-cfg-state` | 但 `--cfg-state` 可显式重新开启 |
| 环境变量 | `BAT2SH_CFG_STATE=0` | 空值 / `0` / `false` / `no` / `off` 视为关闭 |
| 配置文件 | `settings.json` 的 `"cfg_state_machine": false` | GUI 与 CLI 共用 |

### 1.1 实测（固定 fixture `@echo off / :Top / echo loop / goto Top`，`--print`）

判据：产物含 `__bat2sh_pc` → `STATE-MACHINE`；含 `# TODO: 手动检查: goto Top` → `TODO-FALLBACK`。

| # | 场景 | 期望 | **实测** |
| ---: | :--- | :--- | :--- |
| 1 | 默认（无 env / 无配置） | STATE-MACHINE | ✅ **STATE-MACHINE** |
| 2 | CLI `--no-cfg-state` | TODO-FALLBACK | ✅ **TODO-FALLBACK** |
| 3 | env `BAT2SH_CFG_STATE=0` | TODO-FALLBACK | ✅ **TODO-FALLBACK** |
| 4 | 配置文件 `cfg_state_machine=false` | TODO-FALLBACK | ✅ **TODO-FALLBACK** |
| 5 | env=0 **+** CLI `--cfg-state` | STATE-MACHINE（CLI 胜） | ✅ **STATE-MACHINE** |
| 6 | env=1 **+** CLI `--no-cfg-state` | TODO-FALLBACK（CLI 胜） | ✅ **TODO-FALLBACK** |
| 7 | 配置=false **+** env=1 | STATE-MACHINE（env 胜 file） | ✅ **STATE-MACHINE** |

**结论：三层均可用，优先级 `CLI > env > file` 实测成立。**

> 复现：`PYTHONPATH=python python -m bat2sh --cli f.bat --print [--no-cfg-state|--cfg-state]`
> （env: `BAT2SH_CFG_STATE=0/1`；file: `XDG_CONFIG_HOME=<dir>` 下的 `bat2sh/settings.json`）

## 二、交互式循环告警（非阻断）

**背景**：接受定义性 `rc0` 位移（`docs/v2.5.0-breaking-changes.md` §三.1）后，
对「含运行时输入语句的循环」增加**非阻断**告警，提示无 stdin 环境会挂起。

**实现**：`core/cfg_state.py::_warn_interactive_loops` —— 对每个回边循环的区间
（`analyze_flow.loops`），若含 `set/p`、`pause`、`choice` → 输出 `report.warnings`
（`category="control_flow"`）。**不改变产物、不阻断转换**。

### 2.1 实测

| 文件 | 类型 | 期望 | **实测** |
| :--- | :--- | :--- | :--- |
| `注册表/注册表权限设置.bat` | `:START … set/p … Goto Start` 菜单循环 | 告警 1 | ✅ `警告数量: 1` ｜ `第 3 行: 循环 :start 依赖运行时输入（交互式）；无 stdin 环境会挂起` |
| `合并文本/合并文本.bat` | 非交互前跳 | 告警 0 | ✅ `0` |

命令：`PYTHONPATH=python python -m bat2sh --cli <f> --print --report`
