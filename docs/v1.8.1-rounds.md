## Round 1 —— 块结构 `)` 粘连 + 透传防线

**诊断**：语法失败 14 例中，5 例首错为孤立 `)`；根因是多行 `if (...)` 的收尾 `)` 与该行末语句
粘连（`call :index)`），而 `_convert_if` 为未闭合 `(` 开的块**不跟踪括号深度**，导致 `)` 未被消费。

**修复**：
- `_Block` 增 `await_paren_close`；`_convert_if` 未闭合 `(` 分支置位。
- 新增 `_paren_close_split()`：扫描引号外的配对 `)`，拆出 (块内文本, 块后文本)，
  复用 `_close_block_line` 处理 `) else` / `) else if` / 后续重定向。
- 未知命令（`_convert_simple_no_pipe`）与 `BATCH_POSIX_KEEP` 透传前增加 `_passthrough_unsafe()`：
  引号外含 `(`/`)`/反引号 → 降级为诚实 TODO（不再产出非法 bash）。

**证据**：`corpus/系统优化.bat:16`（`call :index)`）、`corpus/确认bat后运行.bat:6-7`、
`corpus/按软件分类建立文件夹.cmd:81`。

## Round 2 —— 二进制载荷与说明文本

**诊断**：`运行剪贴板中的bat.bat` 含**嵌入的二进制载荷**，GBK 解码后成为乱码并被当命令发射；
`按软件分类建立文件夹.cmd` 含大段中文**说明文本**（非命令），同样被当命令。

**修复**：
- `_looks_binary()`：含控制字符，或拉丁补充区字母 ≥4 且多于 CJK → 注释。
- `_looks_like_free_text()`：首 token 含 CJK 且整行 CJK ≥2 → 注释（`echo 中文` 不受影响，首 token 是 ASCII）。

**证据**：`corpus/运行剪贴板中的bat.bat`、`corpus/按软件分类建立文件夹.cmd:11`。

## Round 3 —— `for` 块的同源缺陷

**诊断**：`for %%i in (...) do (` 的收尾 `)` 同样粘连（`ping 127.1 -n 1>nul)`），
因 `_convert_for` 的未闭合分支同样未置 `await_paren_close`。

**修复**：`_convert_for` 未闭合分支置位 `await_paren_close`（与 Round 1 同机制）。
**证据**：`corpus/系统优化.bat:3270`。

## Round 4 —— keep 类命令的透传缺口

**诊断**：`code` 属 `rules.BATCH_POSIX_KEEP`，走免检透传，故 Round 1 的防线未覆盖，
文本行 `code by …(…)` 仍产生语法错误。

**修复**：把 `_passthrough_unsafe()` 同样施加于 `BATCH_POSIX_KEEP` 分支。
**证据**：`corpus/按软件分类建立文件夹.cmd:43`。

## Round 5 —— 结构化映射表接入（本版硬约束交付）

**诊断**：语料反复出现 Windows 专有命令（`regsvr32`/`rundll32`/`mshta`/`wmic`/`devcon`…），
当前落到「未知命令」警告后**原样透传**或产出坏命令，运行期崩溃。

**修复**：新增 `python/bat2sh/mappings/windows_tools.py`（12 条，**全部含 `corpus/<file>:<line>` 证据**），
`validate_mappings()` 落实 8 条校验；并接入转换器：
- `confidence: D` → 诚实 TODO（不再执行坏命令）
- `form: 1:1` → 采用目标命令
- 其余（partial）→ 输出「建议 + 置信度 + 语义不完全等价」的 TODO

**效果**：运行 rc==0 由 79 → **87**（崩溃类命令变为可见 TODO），语法率不变。

## 收敛判定

| 条件 | 状态 |
| :--- | :--- |
| 连续 2 轮无新增可修项 | 未达成（每轮仍有可修项，但边际递减） |
| 达 8 轮上限 | 未达（本版 5 轮） |
| 连续 2 轮指标无提升 | 未达成（Round 3/4/5 仍有提升） |

**结论**：主体收敛于 **5 轮**。剩余 6 例语法失败与 23 例转换可归因运行失败，根因属
**多结构深度嵌套**（`for /f` + `if` + 管道 TODO 的块栈失同步）、**引号跨行未闭合**、
**超长单文件（8000+ 行）** 等，单轮收益低且回归风险高，**按纪律记入 backlog**（见 release notes 已知限制），
不在本 patch 内继续扩大范围。
