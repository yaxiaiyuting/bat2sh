## 3. 用自己的话复述

### 3.1 v2.0.0 的范围（不复述任务书）

v2.0.0 是 2.x 的**第一个版本**，只做**解析层/词法层基座硬化**——即「让转换器在遇到
括号、引号、嵌套控制结构时产出**语法合法**的 bash」这件事。它**不做** goto 语义转换、
不做名称映射、不做注册表映射。它的产出形态是：修掉若干**具体机制**（不新增功能），
使得语料里**因解析/词法缺陷而整体降级（bash -n 失败）**的文件变成语法通过。

本质：v1.x 是「能力扩张 + 诚实化」，v2.0.0 是「**地基补强**」——把 1.x 期间被反复
标为「2.x（解析层）」的欠债先还掉，为 v2.1.0 的 CFG 提供可靠前提。
