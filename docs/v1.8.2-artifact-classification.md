## 1. 仪器与方法（纪律 9：仪器先验证）

度量脚本 `/tmp/v182/run_corpus.py`（**只读**，不在仓库内）：

1. 遍历语料 `.bat`/`.cmd`（151），`convert_file(..., ConvertSettings(bash_check=False))`；
2. `core.syntax.bash_syntax_error()` 取原始口径语法结论；
3. 语法通过者写入独立 workdir（含按产物推断的 dummy fixture），用
   `docs/sandbox-audit.md` 配方沙箱运行：
   `bwrap --unshare-all --die-with-parent` + 只读 `/usr`、`/etc` + `HOME`→tmpfs +
   30s 超时 + `ulimit -c 0; ulimit -f 10240`（后者沿用 `analyze.py` 既有做法，仅降低磁盘风险）；
4. 采集 `rc`/`stderr`/`stdout`，正则提取 `script.sh: line N: <token>: command not found`；
5. 对 `rc≠0` 追加 **relaxed 复跑**（`strict_mode=False`）区分 `set -e` 早退；
6. 对 stderr 为空的用例追加 **`bash -x` xtrace** 定位根因。
