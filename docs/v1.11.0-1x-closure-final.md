## 4. 裁定

### 4.1 任务书三条件 → **全部达成**

(a) ✓ /(b) ✓ /(c) ✓（(c) 按修订标准 3）。即：**1.x 的「可做项已做尽、剩余项均有归属」这一实质目标达成。**

### 4.2 但路线图 §4 六标准**整体未全绿**（标准 1 ✗）

- 标准 1 要求 `≥150/151`；实测 **147/151**。其 4 例剩余**均有归属**（§2.1），
  其中 3 例为**解析层（2.x）**、1 例为**B 类源畸形（终态）**。
- **本文件不单方面宣布「1.x 完成」**——因为任务书 §3 的收尾判据（§4 六标准）要求**同时成立**，
  而标准 1 未达；且修订标准 1 **超出本 session 授权范围**（任务书仅授权修订标准 3）。

### 4.3 提请裁定（二选一）

| 选项 | 内容 | 影响 |
| :--- | :--- | :--- |
| **① 修订标准 1（推荐）** | 改为「语法通过 ≥ **147**（147/151），剩余 4 例全部有归属：1 B 类源畸形（终态）+ 3 解析层（2.x）；无 1.x 可修项」 | 与标准 3 的修订同理（原阈值基于不可达假设）；修订后 **六标准全 ✓ → 宣布 1.x 收尾** |

> 无论选哪项：**本项目已无「可修而未修」的 1.x 项**；差异仅在「是否把解析层 3 项计入 1.x 门槛」。
