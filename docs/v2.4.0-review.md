### 1.2 不做（显式诚实 TODO + 证据）

| 形态 | 量 | 不做的理由（实测/代码） |
| --- | ---: | --- |
| `backward_loop`（回跳→循环） | 446/28 | 唯一 goto 单桶文件 `显示所有分区…cmd` 的 2 个 TODO = `goto Main`（顶层回跳）**+** `goto loop`（函数内自环）；即使实现顶层回跳，函数内自环仍 TODO → **翻转仍 0**；且须在**标签处发射 `while`** → 触 `_label_line`（053 域）。 |

> 按纪律 1（保守 TODO 优于激进转换）与三条底线（禁静默错），**本 session 不做**，
> 给显式归属与可复现证据。**这不是「无能为力」，而是「有证据的取舍」。**

## 2. 目标

**语义完整性（goto 形态全覆盖归属）**，不是翻转数：

1. C4 台账 **7 主形态 + 1 辅形态**，每形态有明确归属（**实现** / **诚实 TODO + 证据**）。
2. 可证安全子集（S1/S2）从 TODO → 真实转换，且**行为与 cmd 等价**（可被 wine 对照）。
3. **不引入静默错**：被跳过的不可达区间必须**显式注释**（非静默蒸发，`_check_silent_drop` 不触发）。
4. **053/A1 不回归**。

## 8. 验收标准（原则性，v2.0.0 教训；**不预设翻转 ≥N**）

1. **goto 形态覆盖**：C4 台账 7 主 + 1 辅，每形态有明确归属（实现 / 诚实 TODO）。
2. **不引入静默错**：产物无「丢行且无诊断」；不可达区间显式注释；wine harness **不下降**。
3. **053 不回归**：053 专项测试全绿；053 覆盖 5 文件判据变化均有解释。
4. **A1 不回归**：A1 测试全绿；`__bat2sh_snap_*` 语义不变。
5. **指标不倒退**（定义性位移除外）：syntax 不降、rc0 不降、崩溃 0。
6. **语义完整性目标达成**：S1/S2 落地 + 其余专属诚实 TODO。
