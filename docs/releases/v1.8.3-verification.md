## 2. 主体功能实跑（安装版）：4 修复 + 1 降级

输入 `demo_v183.bat`（覆盖 114 / 044 / 047 / 062① / 085 降级）：

```bat

setlocal enabledelayedexpansion
set str1=!str1!x
```
