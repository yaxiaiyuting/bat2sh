## 版本号选择理由

`1.10.0a1`（PEP 440 alpha）：本版引入**两个新子系统**（名称映射、输出契约），
按 semver 属 minor 级新机制 → 目标版本 1.10.0；但因 (a) 仅交付框架 + 首批条目、
(b) 收益为「诚实化」而非文件翻转、(c) 后续还有 Session B（C4 控制流）与 Session C（词法层），
故先发 **alpha 预览**。**不进 AUR 主分支**（`pkgver=1.10.0a1` 会被 pacman 视为比 `1.10.0` 旧；
如需预发布包须另立 `bat2sh-pre`）。

## New features

### 1. B1 —— 名称映射子系统（`mappings/windows_names.py`）

**问题**：既有两张映射表都回答不了「同一个东西在另一边叫什么名字」——
`windows_tools.py` 覆盖**命令**，`registry_map.py` 覆盖**注册表键路径**；
`%ProgramFiles%` 这类 Windows 专有环境变量此前被当作「未知用户变量」，
静默译成 `${ProgramFiles:-}`（**运行期空串 → 静默错**，无 TODO）。

**本版**新增第三张结构化表（`NameMapping`，`kind ∈ {env_var, path_root, service}`）：

- `evidence` 必填且指向真实语料（纪律 7：不发明映射）；
  `validate_name_mappings()` 在测试中守护（D 档不得硬凑、`form=none` 须注「无对应物」、
  `integrated=False` 须注 backlog、service 须指明 systemd unit 等）。
- **降级策略**：无依据的 Linux 名 → **行级诚实 TODO**（`form=none`）；
  `integrated=False` → 仅登记、不驱动转换。

**首批条目（C3 路径/环境；不含 `sc→systemctl`，C7 已后移 v2.0）**：

| 名称 | 处置 | evidence |
| :--- | :--- | :--- |
| `%ProgramFiles%` | **诚实 TODO**（修复 `${ProgramFiles:-}` 静默空串） | `corpus/史上最牛X…bat:9933` |
| `%AllUsersProfile%` | → `/usr/share`（与既有 `BATCH_ENV_MAP["PROGRAMDATA"]` 一致，非发明） | `corpus/快速清理垃圾文件安装修改版/快速清理垃圾文件.bat:15` |
| 盘符（`C:\`、`D:\`…） | **仅登记**（`integrated=False`） | `corpus/注册表/导出注册表的键值2.bat:1` |
| UNC（`\\host\share`） | **仅登记**（`integrated=False`） | `corpus/注册表/设注册表某个键的键值为变量2.bat:3` |

**为什么盘符/UNC 只登记不集成**：诚实 TODO 化实测会触及 **35 个语料文件**、
其中 **6 个当前功能完好** → 会让 strict 由 16 掉到 10；超出 B1 首批边界。数值见
`docs/session-b1b2-review.md` §2.2。

### 2. B2 —— 输出契约子系统（`mappings/output_contracts.py`）

**问题**：`ipconfig → ip addr` 命令翻译是对的，但输出形态不同；
`windows_tools.ToolMapping.output_contract` 从 v1.8.1 起就存在，却只被 `notes` 里
「输出格式」四个字约束着，**不驱动任何行为**。

**本版**把它升级为结构化契约 `OutputContract(command, linux_command, shape, keywords,
evidence, integrated, notes)`，并加**交叉强制**：
`output_contract=true` 的命令**必须**有契约记录（当前 `ping`/`help`，已补登记）。

**首批契约 5 条**：`ipconfig`（`shape=differs`；中文关键词与既有 `_FINDSTR_CJK_MAP` 由测试锁定防漂移）、
`dxdiag`/`perfmon`（`shape=none`）、`ping`/`help`（仅登记）。

**诚实化集成**：裸 `dxdiag` / `perfmon`（无 `.exe`）此前是「泛化 warn + 原样透传 →
运行期 `command not found`」，现改为**结构化诚实 TODO**。带 `.exe` 的形态与
`ipconfig`/`ping`/`help`/`for /f` 既有行为**保持不变**。

## 已知限制（诚实披露）

1. **headline 指标未提升**：本版预期并实测**文件翻转 0**（路线图 §3.4：`path` 设施
   0 单设施翻转；`ipconfig`/`dxdiag`/`perfmon` 命中文件已被 goto/终态/语法失败阻塞）。
   任务书草案的「rc==0 提升、degraded 下降」在本 scope 内**不可达**，已重述为可测标准
   （`docs/session-b1b2-review.md` §6）。
2. **B2 不做解析级输出适配**（路线图 §1.B 的 1.x 红线）：`085 显示自己的IP.bat`
   （唯一可能翻转的 ipconfig 解析文件）**本版不翻转**，留 2.x。
3. **B1 盘符 / UNC 只登记不集成**（净损 6 strict，见上）。
4. **`if`/`for` 头部条件**中的 `%ProgramFiles%` 不转为 TODO：改头部会触碰**块栈配平**
   （止损域）；语料中此类仅 5 行、全在已 rc≠0 的 `077`。
5. `%ProgramFiles(x86)%` 等别名**未登记**：语料 0 次出现，**缺 evidence**（纪律 7 拒绝）。
6. 服务名（`service`）kind 已预留但**未落条目**：1.x 无 `sc→systemctl` 宿主（C7/v2.0）。
