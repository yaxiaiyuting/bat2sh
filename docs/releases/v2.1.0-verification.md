## 5. P4 实跑（CFG 只读数据模型）

源（`/tmp/bat2sh-v210-verify/verify.bat`）：

```bat
@echo off
goto skip
:skip
echo hello
goto :eof
if "%1"=="" goto done
echo body
:done
```

命令与结果：

```text
$ PYTHONPATH=python python3 -m bat2sh --cli verify.bat -o verify.sh
[已写出] verify.bat -> verify.sh | 转换 4 行 | 错误 0 | 警告 0 | TODO 2    # ← P4 零转换改动：goto 仍为诚实 TODO
$ bash -n verify.sh && echo SYNTAX OK
SYNTAX OK
```

`core/cfg.py` 对该源的分类（证明数据模型可用）：

```text
L2 goto skip -> redundant_goto (dir=forward, redundant=True)
L5 goto eof  -> eof_exit       (dir=none)
L6 goto done -> forward_skip   (dir=forward, conditional=True)
summary: labels=2, edges=3, by_shape={redundant_goto:1, eof_exit:1, forward_skip:1}
validate: []   # 无问题
```

`tools/cfg/cfg_report.py`（语料 151）：

```text
标签位置 = 781；goto 边 = 1583
7/7 主形态与 C4 台账一致（93/551/446/457/27/8/1）
逐文件 validate_cfg 问题 = 0
```

**结论**：P4 数据模型端到端可用；转换产物**零变化**（goto 仍为诚实 TODO，P5 显式归 v2.2.0）。
