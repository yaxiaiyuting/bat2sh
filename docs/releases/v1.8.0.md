## bat2sh v1.8.0

> 主体裁定：**PS 块结构加固 + 首错收敛 + 廉价替代根治遗留项 1**（选项 3）。
> B1 动态追踪经真实语料实测可挽回 ≈ 0%，不做；asyncio 流式层重构的目标已被廉价替代覆盖，
> 不按裁定表执行。依据见 `docs/v1.8.0-roi.md`。

### New features

- **取消在途请求即时生效（关闭 v1.7.0 遗留项 1）**
  - 新增 `CancelAwareTransport`：登记在途响应，取消时对底层 socket 执行
    `shutdown(SHUT_RDWR)`，直接打断阻塞读。GUI「停止」/ CLI `Ctrl+C` 从**最坏等一个空闲超时
    （默认 30s）**变为 **< 1s**（本地原型实测 0.0002s）。
  - 被取消的任务标记为 **`skipped`**（而非 `failed`），取消期间**不写盘**。
  - 取消**不误判为网络错误、不触发重试**（新增 `TransportCancelledError` /
    `ProviderCancelledError`，明确不在 `RETRYABLE_ERRORS`）。
  - socket 句柄获取采用**分层策略**（`resp.fp.raw._sock` → `socket.fromfd`），
    两者皆失败时**退化为协作式取消**并告警（不崩溃）。
  - 集成点：`parallel.run_parallel`（`KeyboardInterrupt`）、CLI、GUI `_request_stop`。
  - **硬约束**：取消**必须**用 `shutdown`，**绝不**能用 `close()`/`response.close()`
    （它们无法打断阻塞读）；该约束由显式断言测试守护（`tests/test_api_cancel.py`）。
  - chunk 间 **30s 空闲超时**与 **`enable_thinking` 降级**语义保持不变。

### Fixes（PS 转换管线：7 类发射缺陷，均有真实语料证据）

| ID | 缺陷 | 修复 |
| :--- | :--- | :--- |
| D1 | `try` 块内 `if/elseif` 开链整段丢失（孤立 `else`/`fi`） | `elseif` 块栈 pop 责任唯一化，消除重复 pop 在外层块内的失同步 |
| D2 | 独立字符串语句未转 `echo`（被当命令执行，rc 127） | 整条字符串字面量 → `echo`；含不可转换子表达式时退诚实 TODO |
| D3 | 函数调用未转换（赋值 RHS `x="Func"` 静默错误；条件退占位） | 赋值转 `x=$(Func)`；条件转 `if Func "$x"; then`（退出码判定） |
| D4 | 路径/开关透传（`-like` 含空格模式 bash 语法错误；`Resolve-Path` 带空格路径截断） | `-like` 空白**转义**（不得加引号：引号会关闭通配）；`Resolve-Path` 支持整段引用路径 |
| D5 | 未定义变量在 `set -u` 下 unbound（PS 中未定义即空） | 仅顶层直线赋值视为必定已赋值（`${x}`），其余保守 `${x:-}` |
| D6 | `+=` 复合赋值丢失基值（覆盖而非追加） | 字符串追加转 `name+=`；纯数字 RHS 转算术 `name=$(( … + N ))` |
| D7 | `Get-ChildItem -attributes Directory/!Directory` 过滤语义丢失（两者同一 glob） | 分别转 `find -maxdepth 1 -type d` / `-type f`；不可靠组合退回 glob + 告警 |

### 口径说明

自 v1.8.0 起，「语法通过率」的**默认口径为原始转换口径**（不启用「失败降级为注释」）；
降级口径仅作历史对照保留（定义见 `docs/v1.8.0-design.md` §1.2）。

**本次为「重跑」，未沿用任何归档口径**（本版触碰转换管线，归档论证失效）：

| 指标 | 数值 | 说明 |
| :--- | :--- | :--- |
| 语料 | **60 个独立脚本**（CC0，fleschutz/PowerShell） | `tests/fixtures/real-corpus/` |
| **语法通过率（原始口径）** | **56/60 = 93.3%** | v1.7.0 同口径基线 **75.0%**（+18.3pp） |
| 语法通过率（降级口径） | 60/60 = 100% | 历史对照：降级产物计入通过 |
| 转换崩溃类 | **0** | 无非语法类错误 |
| 转换可归因运行时失败 | **9/60**（v1.8.0 前为 20/60） | pwsh 原始 rc=0 而产物失败 |
| **静默错误率（严格口径）** | **14/19 = 73.7%** | 见下方「PS 状态」——**与 bat 的 18.5% 不可比** |

> **发布判定（三档规则）**：原始口径 ≥ 93% → **可发布**，实际值 93.3% 已在本文显著标注。

### PS 状态

- **PowerShell 侧仍为实验性支持**（延续 v1.3 起的定位）。本版把 PS 侧从
  「15/60 语法失败整体降级、真实可用产出打折」提升到 **93.3% 原始口径语法通过**，
  但**语义等价远未达成**。
- **静默错误率 14/19 = 73.7%**（严格口径：产物 `bash -n` 通过且沙箱 rc==0，
  但可见行为与原始 pwsh 不一致）。该数字**不可与 bat 语料归档的 18.5% 直接比较**——
  后者使用 bat 侧「模式扫描 + 最小复现」口径，本数字使用 PS 侧「运行时行为对照」口径，
  更严格。剩余偏离集中在**原理性缺失（D 档）**：对象模型 / `.Count` / `.NET` 静态调用 /
  `[DateTime]` 算术 / 外部命令格式算子（`-f`），以及环境类（缺兄弟脚本）。
- 复现：`python3 tools/corpus-analysis/ps_silent_check.py --pwsh <portable-pwsh>`
  （只读；缺省不带 `--pwsh` 时仅做 bash 侧统计）。

### 已知限制

1. **PS 侧仍有 4/60 原始口径语法失败**（未纳入本版 7 类范围，已记录、排期 2.x）：
   - `cd-recycle-bin.ps1`、`cd-trash.ps1`：函数内 `param()` 声明发射残留（`] param()`）。
   - `check-apps.ps1`：`foreach` 循环头损坏（`for app in ${apps}) { if (…; do`）。
   - `check-drives.ps1`：PowerShell `-f` 格式化算子未转换（`'{0:N0}KB' -f (…)`）。
   - 处理方式：默认降级为注释（never emit broken bash），不会产出坏 bash。
2. **PS 静默错误率 73.7%**（严格口径，见「PS 状态」）；含对象模型等原理性缺失，
   产物定位仍是「高级草稿」，必须人工复核。
3. **残留「新发现但未修复」的发射缺陷（排期 2.x，1.x 专注 bat）**：
   cmdlet 命名参数泄漏（`Resolve-Path -Path`）、`~` 未展开、`[Type]` cast 残留、
   `.Count` 插值、`for` 循环头、兄弟脚本依赖（环境）、算术/交互输入。
4. **取消的退化路径**：若某环境无法取得 socket 句柄（分层获取全部失败），
   取消退化为协作式取消（最坏等一个空闲超时）并打印告警；不会崩溃。
5. **`max_concurrency` 归属未调整**：仍在 `api.json`；本版未扩展到非 API 场景，
   归属评估顺延（ROI 报告遗留项 2）。
6. **D5 的保守取舍**：为保证不出现 unbound，分支/块内赋值一律发射 `${x:-}`，
   因而在少数场景**削弱了 `set -u` 的变量拼写保护**（行为等价，诊断性下降）。
