对照验证点：

| 项 | 修复前（v1.8.1） | 修复后（v1.8.2） |
| :--- | :--- | :--- |

| A-4a `%path%` | `cd "${PATH:-}"`（误指 Linux PATH） | `cd "${path}"` |
| A-2b `rd … /q/s` | `rmdir "…" "/q/s"` | `rm -rf "…"` |
| A-4b `set /a a=%a%+1` | `a=$(( ${a}+1 ))`（set -u unbound） | `a=$(( ${a:-0}+1 ))` |
| A-6 `set s!w!=` | `s__w_=`（静默错误） | 诚实 `# TODO` |
| 映射 D `regsvr32` | 原样透传执行 | 诚实 `# TODO` |
| A-2a `date/t` | 发射 `date/t` → `command not found` | 归入 `date` handler → 报告 TODO（见 §5 观察） |

**降级兜底验证**：另用含独立 `call :sub)`（块外粘连 `)`）的输入测试，产物**整体降级为注释**

## 5. 观察（已知限制，如实记录）

1. **`cmd_todo_hint` 类命令（`date`/`attrib`/`path` 等）在产物中不落 `# TODO` 注释**，
   仅记入报告 `todos` 层（`--report` / `--fail-on-todo` 可见）。A-2a 使 `date/t` 进入该路径后，
   产物不再含坏命令，但也不含注释行。**属既有行为**，记入 backlog（未在本版扩大改动面）。
2. 块外独立 `call :sub)` 会触发整体降级（安全兜底），非本版目标；`call` + 块闭合的组合
   已有 v1.8.1 B1/B1b 覆盖。
3. `//`、`\/` 外观残留见 release notes「已知限制」第 3 条。
