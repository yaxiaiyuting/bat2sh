## bat2sh v2.0.0

> **性质**：`2.0.0` **major**。2.x 的**共同前置**——解析层/词法层基座硬化。
> **本版有真实转换改动**（2 个语料文件由「语法失败」变为「语法通过」），且**零文件变差**。
> **2.x 定位声明（关键）**：
> **2.x 是「完整语义支持」版本，不是「指标翻转」版本。** goto / `sc` 的 TODO 量不代表可翻转量——
> 大多落在多设施宿主或 Linux 无对应项。**评估 2.x 请以「语义正确性 + 可用性」为主，不以翻转数为唯一标尺。**
> **AUR**：本版**不进 AUR**（AUR 上不存在 `bat2sh` 包，需先注册 + 配置 SSH key）；
> `PKGBUILD`/`.SRCINFO` 完成**仓库侧同步 + 本地 `makepkg` 验证**。

## 4. 重要披露（纪律 4/13/15）

1. **原定「语法失败 4→1」未达（实测 2）**：原假设 P1/P2/P3 各修一文件，但 `史上最牛X`
   在修掉嵌 `if` 后仍暴露**多物理行 `for /f` 泄漏**与 `echo` 引号问题（属 B5/解析层重写），
   故不在 v2.0.0 scope。**未强凑**。
2. **degraded +2 是定义性位移**：`measure.py` 的 degraded 口径不含语法失败文件；修好语法失败
   必然使文件从 unusable 桶移入 degraded 桶。**「语法失败 4→1」与「degraded ≤83」在该口径下互斥。**
3. **P1 第一版实现触发止损并已回滚说明**：通用 `comment` 块改动会使 `批量重命名`（rc 0→2）与
   `文件备份器`（TODO +40）回归——既有注释块机制是**载荷性**的；最终采用**独立 `pcomment` 块**（零回归）。
