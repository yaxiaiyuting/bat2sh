# bat2sh v1.10.0 发布说明（正式版 · 1.x 功能冻结）

> **性质**：`1.10.0` **正式版**，是 **1.x 线的功能冻结版（feature freeze）**。
> ⚠️ **收尾判定：未达成**——经独立评估（`docs/v1.10.0-1x-closure.md`），1.x 仍有
> **可修而未修**的 C2 小设施批（`for`/`registry`/`other` 等；路线图 §3.4 记 **36 单设施翻转**），
> 故本版**不宣布「1.x 完成」**，只宣布「1.x 转换能力冻结」。
> 本版把三个 pre-release 分支（`v1.10.0a1` / `v1.10.0b1` / `v1.10.0rc1`）合并进 `main`，
> 交付四个**只读子系统/台账**：**B1 名称映射**、**B2 输出契约**、**C4 goto 控制流台账**、
> **C(lex) 词法层残余额账**。
> **本版零转换改动**（合并后转换产物与 `v1.10.0rc1` **逐字节相同**）；价值在**基础设施 + 台账固化**，
> 而非指标提升。本文**如实披露**这一点，不用「指标提升」包装。

---

## 1. 本版做了什么（三分支合并）

本版 = `main ← session-b1b2 ← session-c4 ← session-lex` 三支合并（**累积/堆叠**关系；`--no-ff` 保留分支历史）。

| 支 | 对应 pre-release | 内容 | 旧 tag |
| :--- | :--- | :--- | :--- |
| `session-b1b2` | `v1.10.0a1` | **B1 名称映射** `mappings/windows_names.py` + **B2 输出契约** `mappings/output_contracts.py` | `90af605` |
| `session-c4` | `v1.10.0b1` | **C4 goto 控制流台账** `core/control_flow.py` + CI 触发修正 | `8fdae5f` |
| `session-lex` | `v1.10.0rc1` | **词法层残余额账** `core/lexical_residuals.py` | `20b1585` |

### 1.1 B1 名称映射子系统（`mappings/windows_names.py`）

- 与命令表、注册表键表并列的**第三张结构化表**：同一事物在另一边的**名字**
  （`kind ∈ {env_var, path_root, service}`），带 `evidence` / 置信度 / `integrated`。
- 降级策略：无依据的名字 → **行级诚实 TODO**（`form=none`），**不发明映射**（纪律 7）。
- 首批：`%ProgramFiles%`（→ 诚实 TODO，修复静默 `${ProgramFiles:-}` 空串）、
  `%AllUsersProfile%`（→ `/usr/share`）、盘符/UNC（**仅登记**，churn 实测 35 文件/净损 6 strict → backlog）。

### 1.2 B2 输出契约子系统（`mappings/output_contracts.py`）

- 把 `ToolMapping.output_contract` 从「装饰性标记」升级为**结构化契约 + 交叉强制**
  （`output_contract=true` 必须有契约记录），首批 5 条（`ipconfig`/`dxdiag`/`perfmon`/`ping`/`help`）。
- **1.x 红线**：不做解析级输出适配（路线图 §1.B）；只做「登记 + 校验 + 诚实化」。
- 消费：裸 `dxdiag`/`perfmon` 由「静默透传 → command not found」改为**结构化诚实 TODO**。

### 1.3 C4 goto 控制流形态台账（`core/control_flow.py`）

- 把 cmd `goto`（任意跳转）的**形态**固化为第四张只读表（7 主形态 + 1 辅形态），
  带 `evidence`、置信度、`plan`（v2.0 CFG 方案）、`convertible`。
- 实测：goto 语句 **1583**；转换器口径 goto TODO **1362 / 39 文件**（degraded 内 252/22）。
- **不做任何语义转换**（`convertible=False` 除已实现的 `goto :eof`）：唯一阻塞 = goto 的
  degraded 仅 3，翻转收益 ≈ 2/86 → 归 **v2.0**（15–25 人日，风险最高）。

### 1.4 词法层残余额账（`core/lexical_residuals.py`）

- 053（块栈）/ A1（`%VAR%` 冻结）修复后仍存的 **4 条 degraded 残余**，固化为第五张只读表（4 条 / 3 机制）。
- **实测证伪任务书标签**：仅 2 条是块栈/头切分歧义（LF-1：044/135 `_convert_for` 头正则贪婪），
  另 2 条是**守卫误报**（LF-2：059 引号内/nested-`cmd` 字面 `%%X`；LF-3：138 `%VAR:~n,m%` 子串盲区）。
- 三条机制**均无文件翻转收益**，且分别落在**块栈核心**与**A1 热路径** → 只固化不实现。

## 3. 诚实披露（重要）

1. **本版零转换改动、指标持平**：合并三分支后的产物与 `v1.10.0rc1` **逐字节相同**，
   `rc==0` / `degraded` / strict **全部持平**。**本版不声称任何指标提升**。
2. **本版价值 = 基础设施 + 台账固化**：四个只读子系统把「1.x 无法在范围内解决的问题」
   变成**可校验、可复现、带 evidence 的代码台账**，为 2.x 直接提供施工图与实验台。
3. **「rc==0 提升 / degraded 下降」在本 scope 内不可达**（三支报告均已预判并披露）：
   goto（TODO 多、翻转 0）、名称映射（盘符/UNC 净损 strict）、输出契约（1.x 红线不做解析级适配）、
   词法层残余（无文件翻转）——**修任一项都不翻转文件，且部分会净损**。已如实报告，不硬凑。
4. **AUR**：本版为正式版，`PKGBUILD` / `.SRCINFO` 已同步 `1.10.0`；
   **AUR 远端推送未执行**（本机无 AUR 凭据/无 SSH 私钥，且 AUR 上不存在 `bat2sh` 包）——
   见 `docs/v1.10.0-report.md`「AUR 事实核对」。

## 4. 1.x 状态总结（收尾判定：**未达成**）

> ⚠️ 本节与 `docs/v1.10.0-1x-closure.md`（独立评估）一致，**以该文件为准**。
> 早先草案曾写「所有剩余失败均有明确归属、不存在可修但未修」——经核（路线图 §2.1/§3.4/§4）
> **该说法不成立**，已更正。

- **不满足路线图 §4「接近完美」6 条验收**：标准 1（语法 ≥150）当前 147；标准 3
  （degraded ≤ 41 且剩余全属阻塞/终态）当前 **86**——路线图明记差距为「C2/C3（v1.9.4）+ C1」。
- **阻断项 = C2 小设施批**（路线图 §2.1 归 **v1.9.4**「文件翻转主力批」，**从未执行**）：
  `for` 变体 / `registry` 读映射 / `other` 异构杂项 / `attrib` / `office` / 单命令 / `start` / 管道，
  合计 **~77 TODO**，**36 个单设施翻转（严格子集 21）**。这些**不需 CFG、不触块栈核心、不触 A1 热路径**，
  无法用「v2.0/终态」辩护。
- 其余项归属明确：goto（~250 TODO）与 `sc`（169）→ **v2.0**；`regsvr32`/COM、第三方 exe、
  L4 对象 → **终态**；LF-1/2/3、B2 解析级、062/A9 → **2.x**。

一句话：**`151` 语料 / 语法 `147` / 功能完好 `16` / degraded `86` / rc≠0 `45` 均稳定**，
但 **1.x 未到终点**——C2 是其上界（46 翻转）所在，详见收尾文档 §4。

## 5. 已知限制

1. **PS（PowerShell）侧仍为实验性「高级草稿」**，对象模型 / `.NET` 静态调用 / 注册表 / 远程会话
   为原理性缺失（D 档），bash 无等价物；**PS 解冻触发条件见收尾文档 §2.x**。
2. **goto 无语义转换**：`_convert_goto` 仅实现 `goto :eof`；其余仍为诚实 TODO（v2.0 CFG）。
3. **无解析级输出适配**：`ipconfig`→`ip addr` 等输出形态差异仅登记契约，不解析改写（1.x 红线）。
4. **`%ProgramFiles%` 等**为诚实 TODO（无证据的 Linux 对应物不硬凑）；`if`/`for` **头部条件**中的
   Windows 专有 env_var 不转 TODO（改头部会触碰块栈配平，属 2.x 解析层）。
5. **词法层 4 条残余未修**（044/135/059/138），修复草案已备但均无文件翻转收益、且触及核心路径。
6. **examples 未刷新**：本版零转换改动，故 `examples/*.sh` 保持原状（零字节漂移）。
