## 5. 转换实跑（覆盖本版 4 条新映射）

源（`/tmp/v111/verify.bat`）：

```bat
@echo off
for /r %%i in (.) do echo %%i
net user 123 /delete
attrib +r "f.txt"
```

`python3 -m bat2sh --cli /tmp/v111/verify.bat --print` 输出：

```bash
#!/usr/bin/env bash
# 由 bat2sh 自动转换生成，源文件: verify.bat
set -euo pipefail

while IFS= read -r i; do
    echo "${i:-}"
done < <(find . -type d)
if id -u 123 >/dev/null 2>&1; then userdel 123; fi
if [ -e "f.txt" ]; then chmod -w "f.txt"; fi
```

| 映射 | 验证 |
| :--- | :--- |
| `for /r` → `find` 循环 | ✅ `done < <(find . -type d)` |
| `net user /delete` → 幂等 `userdel` | ✅ `if id -u 123 …; then userdel 123; fi` |
| `attrib +r` → `chmod -w`（带守卫） | ✅ `if [ -e "f.txt" ]; then chmod -w "f.txt"; fi` |
