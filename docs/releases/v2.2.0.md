## 2. 本版做了什么

### 2.1 `sc` 结构化诚实 TODO（`cmd_sc`，新）

| 项 | 内容 |
| :--- | :--- |
| 解析 | `sc <action> [service] [params]` → `# TODO[SC] op=… service="…" params="…": 手动检查: <原命令>` |
| 纪律 7 | **只解析、不映射**：绝不把 Windows 服务名（`AeLookupSvc`/`Alerter`/`RpcSs`…）硬凑为 systemd unit |
| 回退 | 未知/畸形 `sc`（`sc`、`sc /?`）→ **回退**现有通用诚实 TODO（不崩、不丢行） |
| 兼容 | 与 `--fix-todos` 扫描器兼容（`# TODO[SC]` 与 `# TODO[REG]` 同等可扫描、category=`service`） |
| 覆盖 | 远端 `sc \\host query X`、`sc query state= all`、`sc description X "…"` 等 |

**实测 churn**：转换产物**仅 `系统优化.bat` 1 个文件**变化（**169 行**，纯 tag 插入，原命令逐字未变）；
`备份服务.bat` 的 sc 在管道内 → 未变；其余 149 文件逐字节一致。

### 2.2 显式归属（纪律 16，非静默）

goto 高级（回跳/块内）、P5、注册表写映射、B5、`service` 名称表（91 条全 `form=none`）
均有**实测依据 + 明确归属**（`docs/v2.2.0-reality-check.md`）；无「可修但未修」。

### 2.3 测试

- 新增 `tests/test_batch_sc.py`（**12 条**，断言语义）。
- pytest **1436 → 1448**（0 failed）。
