## Fixes

### 1. A1 —— `%VAR%` 立即展开冻结语义丢失（**最高优先级，静默错**）

**缺陷**：cmd 的 `%VAR%` 在**块解析时冻结一次**，`!VAR!` 在**执行时取值**。
bat2sh 把两者都译成运行时活引用 `${VAR}` → `%VAR%` 冻结语义丢失（跑通、行为错、无 TODO）。

**wine 对照证据**（`tools/oracle/`，本版落盘）：

| 用例 | 构造 | wine cmd（正确） | bat2sh v1.9.1 | bat2sh v1.9.2 |
| :--- | :--- | :--- | :--- | :--- |
| g05 | `set v=1` + `for %%i in (a b) do (set v=2 & echo i=%v%)` | `i=1 i=1` | `i=2 i=2` ❌ | **`i=1 i=1` ✅** |
| g04 | 同上但 `!v!` | `d=2 d=2` | `d=2 d=2` | `d=2 d=2`（不变） |

**实现（S2 精确）**：块内用户 `%VAR%` → 占位符；`_register_assigned` 记录同块赋值；
`_compose` 合成期统一解析——仅对「**同最外层块内被赋值**」的变量在块头前发射
`__bat2sh_snap_<v>="${v}"` 并改写引用；其余还原 `${v}`（活引用）。块外逐行保持活引用；
`!VAR!` 不变。冻结时机 = **最外层块入口**（嵌套同源）。

**收益**：消除唯一系统性静默错；黄金对照 **6/6 MATCH**（g05 由 DIFF→MATCH）。

### 2. L1 归零 —— 相邻 `%…%%…%` 展开修复 + `%ERRORLEVEL%` 默认映射

- **相邻百分号误判**：`%date:~0,4%%date:~5,2%` 的中缝 `%%` 被误判为 `%%NAME%%` 转义 /
  `%%x` 循环变量 → 现于转义正则**之前**为相邻完整 `%…%` 插入哨兵（字符集收紧，避免跨引号误匹配）。
  用户变量子串（`%num1:~0,1%` 等）恢复正常转换。
- **ENV_MAP 子串**（`%date:~..%`/`%time:~..%`）：改**行级诚实 TODO**（不发明区域格式映射，
  避免字面量泄漏）。
- **`%ERRORLEVEL%` 默认 `map`**：`last_exit_code` 默认 `warn → map`，默认发射
  `__bat2sh_rc=$?` 捕获 + **警告**（不再 TODO）。显式 `--last-exit-code warn` 仍生成 TODO。

**L1 结果**：38 → **0**（errorlevel 25→0；「逸出」13→4，剩余 4 条为真块失同步/内层 cmd 边角，
**重分类为 L3b**，见「已知限制」）。

## 已知限制

1. **A1 覆盖范围**：`for` / `for /f` / `if` / `else` 块；**顶层独立 `( … )` group 块**与
   **`call` 重解析**（cmd 会再次展开 `%VAR%`）为 **2.x backlog**。
2. **4 条「逸出」残留**（`044`/`135` 的 `%%j`/`%%s` 逸出、`059` 生成文本内 `%%i`、
   `138` 的 `%%%%`+`%~1`）：真块失同步 / 内层 cmd 边角 → **L3b（控制流），2.x**。
3. **`%date:~..%`/`%time:~..%`** 对映射变量做子串：依赖 Windows 区域格式，静态不等价 →
   诚实 TODO（不发明映射）。
4. **`last_exit_code` 默认改为 `map`**（语义默认变更）：脚本引用 `%ERRORLEVEL%` 时默认发射
   `__bat2sh_rc=$?` 捕获 + 警告；如需旧行为用 `--last-exit-code warn`。
5. `//`、`\/` 外观残留（Windows 盘符/UNC）延续。
6. `regsvr32`/COM、WMI、第三方 Windows exe 等仍为**终态**诚实 TODO（见路线图）。
