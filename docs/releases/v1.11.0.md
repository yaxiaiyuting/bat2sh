## bat2sh v1.11.0

> **性质**：`1.11.0` **minor**。本版执行 1.x 收尾的最后一类实质修复——**C2 小设施批的收窄子集**，
> 并交付 **C2 归属重判**（逐条）与 **路线图 §4 标准 3 修订**。
> **本版有真实转换改动**（3 个文件翻转），但**量化目标是修订后的标准 3（`degraded ≤ 83`）**，
> 而非原路线图的 `≤41`——后者经实测证伪（基于不可复现的「46 个 1.x 可解文件」估算）。
> **AUR**：本版**不进 AUR**（AUR 上不存在 `bat2sh` 包，需先注册 + 配置 SSH key）；
> `PKGBUILD`/`.SRCINFO` 完成**仓库侧同步 + 本地 `makepkg` 验证**。

## 1. 本版做了什么

### 1.1 C2 可做映射（4 条，另有 3 条 hint 纠错）

| # | 映射 | 档位 | 说明 | corpus 翻转 |
| :--- | :--- | :---: | :--- | :--- |
| 1 | `for /r [root] %%v in (.) do C` → `while IFS= read -r v; do C; done < <(find <root> -type d)` | A | 递归枚举目录；**复用 `for /f` 的 while-read 块机制**，不改块栈核心 | `以文件夹名为名建立文本文件.cmd` |
| 2 | `for /f <opts> %%v in ("<字符串>") do C` → `… done <<< "<字符串>"` | B | cmd 字符串形式；`tokens`/`delims` 复用既有切分；`""` = 字面引号；`skip=N` → `tail -n +N+1` | `注册表/reg转bat.bat` |
| 3 | `net user <name> /delete` → `if id -u <name> >/dev/null 2>&1; then userdel <name>; fi` | A | **幂等**（用户不存在=已完成，与 `rm -f` 同精神）；缺权限仍非零退出（不吞错）；用户名限定 `[A-Za-z0-9._-]+` | `删除用户.bat` |
| 4 | `attrib ±r <path…>` → 带存在性守卫的 `chmod ∓w` | B | 仅只读位；`+s`/`+h`/`+a` Linux 无属性位对应 → 保持诚实 TODO | 0（质量项） |

**hint 纠错（3 条，纯报告文案）**：`net`（原「请改用 systemctl/ss」对用户管理**语义错误** →
「网络 ip/ss；用户 useradd/userdel；服务 systemctl；共享手工配置」）、
`attrib`（原「请改用 chmod 调整文件属性」对 `+h/+s/+a` 误导 → 明确只读位与 `.` 前缀）、
`fsutil`（→ `lsblk/df/blkid`）。

**保守约束（未实现项一律保持诚实 TODO，纪律 1）**：`for /r` 仅 `in (.)`；根路径不得含空白/
通配/引号/反引号；`for /f` 字符串含字面 `$`/反引号/转义引号不转换；`at`→`systemd-run`、
`rasdial`→`nmcli`、`FTP`→`lftp`（均为置信度 **C**，语义近似）**不实现**。

### 1.2 C2 归属重判（核心产出：`docs/v1.11.0-reclassification.md`）

原「36 单设施翻转」经逐条重判后：

| 类 | 原声称 | **重判结果** |
| :--- | :--- | :--- |
| `registry` | 29 TODO / 11 单设施翻转 | **精确吻合**，但构成为 **26 写 + 3 导出** → **全部 L4 → 2.x**（无只读探针） |
| `other` | 76 TODO / 15 单设施 | **85 条 / 17 单设施**：可做 **1**、2.x **11 文件**、**终态 5 文件**（另有 10 条多设施文件） |
| `for` | 32 / 10 单设施 | **30 / 7 单设施**：可做 **2**、其余 2.x/终态 |
| **可做真集合** | — | **3 翻转 + 1 质量项**（已全部执行） |

**纠正**：`office` 桶（`启动OFFICE.bat` 12 条）实为 **`%ProgramFiles%` B1 诚实 TODO**（非 office 命令映射）；
裸 `office`/`mstsc`/`notepad` 命令当前是「原样发射 + warning」，**不产生 TODO** → 非翻转路径。

### 1.3 路线图 §4 标准 3 修订（`docs/v1.11.0-standard-3-revision.md`）

- **原**：`degraded ≤ 41`（= 86 − 45，基于「46 个 1.x 可解文件」）。
- **问题**：该 46 **不可复现**——`v1.9.1-attribution.md` §2.1「最高层 L1/L2 = 14+32 = 46」用**同文件表 A** 重算 = **25**，且重算「L1 层文件数 = 0」与 §2.1「L1=14」自相矛盾。
- **新**：**`degraded ≤ 83`**（= 86 − 3 个实测可做翻转），且剩余 83 个**全部有明确归属**（无「本可做而未做」）。

| 文件 | 机制 | 归属 |
| :--- | :--- | :--- |
| `运行剪贴板中的bat.bat` | 源含原始二进制/混淆字节 | B 类源畸形（终态） |
