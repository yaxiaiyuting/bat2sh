## bat2sh v2.7.0

> **性质**：`2.7.0` **minor**。CLI 输出美化：**补齐 `--color` / `--no-color` 显式开关**、
> **诊断消息分级着色**、**报告追加「结论」摘要行**、**多文件批量进度前缀 `[i/N]`**。
> **约束全部满足**：仅标准库 / TTY 检测 / `NO_COLOR` / `--no-color` / 向后兼容 / CI 兼容。
> **AUR**：本版**不进 AUR**。

---

## 1. 本版做了什么

| 项 | 说明 |
| :--- | :--- |
| `--color` / `--no-color` | **新增互斥开关**（`dest=color`，默认 `auto`）。`--no-color` 恒关（压过 `FORCE_COLOR`/TTY）；`--color` 恒开（压过 `NO_COLOR`/非 TTY） |
| 诊断分级着色 | 错误红 / 警告黄 / 成功绿：文件不存在、不支持类型、读取失败、执行拒绝、API 配置、修复摘要、写盘等 |
| 报告结论摘要 | `--report` 末尾追加一行「结论」（错误红 / 警告黄 / 干净绿），`to_text()` 结构不变 |
| 批量进度指示 | 多文件时状态行加 `[i/N]` 前缀；单文件不显示 |
| 色彩矩阵 | TTY（模拟）/ `NO_COLOR` / 非 TTY / `--no-color` 四场景：**stdout 永不含 ANSI** |

> **主动披露（纪律 4）**：色彩**基础设施**（`color_enabled` / `_paint` / `render_report_text` /
> `NO_COLOR` / `FORCE_COLOR`）自 v1.x（`862c278`）**已存在**；v2.7.0 的真实增量是
> **补齐硬约束 `--no-color` + 扩大着色覆盖面 + 报告摘要 + 批量指示**，非「从零搭建」。
> 详见 `docs/v2.7.0-cli-audit.md`。

## 4. 兼容性

- **CLI 输出无破坏**：着色仅在 TTY 或显式 `--color`/`FORCE_COLOR` 下生效；否则与 v2.6.0
  **逐字节相同**。
- **退出码不变**：本版不改任何退出码语义。
- **`--report-json` 结构不变**：新增仅为 `--report` 纯文本的一行摘要。
- **GUI 不受影响**：`to_text()` / `report_blocks()` 结构未动。
