> **性质**：`2.5.0` **minor**。**CFG 标签分派状态机默认开启**（goto 任意跳转 → `while/case $pc`）。

## 0. ⚠️ 重要：定义性位移（显著披露，非倒退）

> **`rc0 105 → 101`（−4）不是功能倒退，是修正。** 详见
> `docs/v2.5.0-breaking-changes.md` §三.1。

**4 个文件的旧 `rc0` 是「假通过」**：旧转换器把 goto 当 TODO → **循环从未关闭** → 程序跑到末尾
`exit 0`；新转换器**忠实转换 goto** → 循环真的执行 → sandbox **无 stdin** → 挂起 → timeout `124`/`127`。
**新行为与 cmd 一致；旧行为是 bug。**

| 文件 | 旧 rc | 新 rc | 机制 |
| :--- | ---: | ---: | :--- |
| `注册表/注册表权限设置.bat` | 0 | 124 | `:START … set/p … Goto Start` 菜单循环（无输入即无限） |
| `第三方工具/CSty/高级范例CSty-KeyPrs.bat` | 0 | 124 | `:loop … set/p … goto loop` 等键循环 |
| `第三方工具/CSty/高级范例Caps-Num.bat` | 0 | 124 | `:loop` / `goto loop`（**源即无限循环**） |
| `将文件夹变为磁盘.bat` | 0 | 127 | 源 `pasue`（`pause` 笔误）在 `:err` 分支被忠实执行 |

**sandbox 口径 vs 真实使用口径**：
- **sandbox**：无 stdin → 交互式文件挂起（`rc 124`）。
- **真实使用**：有 stdin → 等待用户输入（正常 bat 行为）。

另 5 文件 `rc≠0 → 124/1`（本已失败，非回归）；**非交互、非源畸形文件 rc 零回归**；`strict 19` 不变。

**新增非阻断告警**：含运行时输入语句（`set/p`·`pause`·`choice`）的循环 → 转换时输出
`循环 :X 依赖运行时输入（交互式）；无 stdin 环境会挂起`（**不阻断转换**）。实测见
`docs/v2.5.0-verification.md` §二。

## 1. 逃生通道（回滚到 v2.4.0 行为）

优先级 **CLI > 环境变量 > 配置文件**（三层实测可用，见 `docs/v2.5.0-verification.md` §一）：

| 层 | 开关 |
| :--- | :--- |
| CLI | `--no-cfg-state`（`--cfg-state` 可显式重开） |

| 配置文件 | `settings.json` 的 `"cfg_state_machine": false` |

关闭后 = **v2.4.0 的 goto 诚实 TODO 行为**（不丢功能，仅恢复保守 TODO）。

## 2. 性质与目标

| 项 | 内容 |
| :--- | :--- |
| 目标 | **语义完整性**：goto 任意跳转真实转换（非翻转数） |

| 版本理由 | goto 语义转换能力（minor）；非 3.0.0（仅 25/151 文件改 goto 区段，且可 opt-out） |

## 7. 残余风险 / 已知限制（如实披露）

1. **25 文件的组合/边界交互未逐文件 oracle**：仅代表性形态（g07–g12）经 wine 证伪；
   复杂宿主（如 `多功能系统优化设置.cmd` 49 标签边）无逐文件语义对照。
2. **`label_in_block`（97/4）未覆盖**：须标签提升/整块扁平化（编译器级）→ 诚实 TODO。
3. **`missing_label` / `dynamic_target`**：无静态安全映射 → 诚实 TODO。
4. **交互式/无限循环忠实化**：无 stdin 运行会挂起（已加非阻断告警；可用逃生通道回退）。
5. `rc0` 定义性位移可能影响以 `rc0` 为门槛的自动化（见 §0）。
