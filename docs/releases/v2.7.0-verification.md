## 二、本机安装验证

### 2.1 偏离披露（纪律 4）：`pacman -U` 被**无关进程**阻塞

- 构建：`makepkg -f` → `bat2sh-2.7.0-1-any.pkg.tar.zst`（**222802 B**；
  sha256 `43a0e5b98c2aaa4e1e5dbb3eee0a85ef8bbbd961f97e602e34ed8811a3e3d8dd`）。
- `pacman -U` 失败：`无法锁定数据库：/var/lib/pacman/db.lck`。
- 根因：**与本会话无关**的进程 `pacman -U …/portable-1:20.2-1-x86_64.pkg.tar.zst`（PID `87079`，
  02:01 起）持有锁。**未删除锁 / 未杀进程**（避免破坏他人事务）。
- **等价替代验证**（不改动系统状态）：① 解包构建产物到临时根运行；② `install.sh --prefix`
  到临时前缀运行启动器。二者均验证**同一份发布源码**的安装形态。
