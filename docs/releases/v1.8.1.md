## bat2sh v1.8.1

> 新语料实测（`~/下载/非常批处理/`，151 个 2008–2014 中文 bat/cmd）+ 5 轮迭代修发射缺陷
> + 结构化 Windows 命令映射表扩展。沙箱边界见 `docs/sandbox-audit.md`，多轮记录见
> `docs/v1.8.1-rounds.md`。

### 版本号选择理由（patch 还是 minor）

**本版为 patch（1.8.1）**，依据 `docs/v1.8.1-design.md` §0 的判定规则：

- 主体是**发射缺陷修复**（5 类行级/块结构缺陷），属 bugfix；
- 新增映射 **12 条**，未超过「> 20 条即升 minor」的阈值，且未引入新的映射子系统语义
  （表结构 + 校验规则即新语义，但规模小且向后兼容）；
- 既有 `rules.py` 映射**未迁移**，无破坏性变更。

若后续把既有规则整体迁入结构化表，应升 minor（记入 backlog）。

### 静默错误率（如实，不设硬门槛）

采用 `docs/v1.8.1-design.md` §2 的三仪器组合：

- 仪器 1（模式扫描，X1–X10）：**61 个**语法通过脚本命中；
- 仪器 2（沙箱 rc==0 但 stdout 含未解析 Windows 标记）：**2 个**；
- 并集 **61/145 = 42.1%**。

> 该数字**显著高于** v1.4.1 归档（bat-master 18.5%），原因是：本语料为 2008–2014 年
> **系统优化/恶搞/工具合集**类脚本（含大量注册表、`attrib`、`%random%`、延迟展开、二进制载荷），
> 静默类构造密度远高于 bat-master 的日常脚本；且本次同时启用了仪器 2。
> **不设硬门槛**（任务书明确「必须披露」），仅如实记录。

### 已知限制

1. **静默错误率 42.1%**（bat，模式扫描口径）——本语料为高静默密度的老工具合集；
   产物仍是「高级草稿」，必须人工复核。
2. **环境依赖占比 23.2%**：脚本依赖 Windows 专有工具（`rundll32`/`regedit`/`wmic`/`devcon`/
   `mshta`/`netsh`…）或沙箱限制（`ping` 需 `CAP_NET_RAW`），**非转换缺陷**，单列不修。
3. **6 例语法失败仍在**（多结构深度嵌套），默认降级为注释，**绝不产出坏 bash**。
4. **结构化表仅覆盖新增 12 条**；既有 `rules.py` 映射未迁移（避免大范围重构），
   迁移列为 backlog。
5. **`partial`/`C` 类映射只给建议、不自动采用**（保守 TODO 优于激进转换）。
6. 危险脚本（16 个）在沙箱内运行；沙箱边界见 `docs/sandbox-audit.md`（审计通过）。
