## bat2sh v1.3.0

### New features
- ConvertReport 增加 errors 层，CLI/GUI 三色显示（错误红/警告黄/成功绿）
- findstr 中文模式映射（IPv4 地址→inet 等）+ 多词 OR 拆分 + 多 /c: 全保留
- for /f 内两段管道直译（17 条同构缺口）

### Fixes（自 v1.2.3 起）
- PS 侧语法层：CmdletBinding 属性透传、`; then` 吞掉、`$((` 管道、
  `[[ ]]` 命令条件、空体块占位（D1-D4 + 空体）
- PS 路径补齐 bash -n 后置校验与降级
- bat 侧：for/f 文件读取容错、未定义 call 目标、
  unbound 顺序感知、findstr /r、`@echo off&setlocal` 链、
  `!var!` 未启用防护、`dir /b` 通配引号、子串语法全覆盖、
  basename 转义、`&` 链段 exit 崩溃

### 真实语料覆盖率
- **bat**（54 个真实脚本交叉验证）：
  - 语法转换率 98.1%（53/54）
  - 完全无问题 83.3%（45/54）
  - 静默错误率 16.7%
- **ps1**（12 个真实脚本）：
  - 语法通过（首错前移）
  - 语义未就绪，**实验性支持**

### 已知限制
- **PowerShell 侧为实验性**：语法层修复完成，不再产生语法错误输出；
  但 PowerShell 对象模型（CIM/.NET 方法/管道对象）在 Linux 无对应，
  转换结果需人工重写才能运行。
- bat 侧剩余缺陷（X5/X7/X8/X9 + X2 谱系 3 例）：详见 docs/real-corpus-report.md
- PS 侧剩余 8 类首错：归 v1.4

### v1.4 方向
