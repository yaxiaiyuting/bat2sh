## 3. 新发现的缺陷 + 修复（A-1）

> **CFG 状态机丢弃子转换器报告**（v2.5.0 引入）。

- **现象**：状态机文件 `report.todo_count` / `total_lines` 恒为 0 →
  **`--fail-on-todo` 静默退出 0**（应 3，CI 卡点漏网）；`degraded_todos` 指标少计。
- **证据**：`BuildAll.bat` 产物含 5 个 `# TODO`，报告 `总行数:0` / `todo_count:0` / `--fail-on-todo` 退出 0。
- **修复**：`emit` 成功后合并子报告（`total_lines` / 计数 / `warnings` / `todos` / `errors`）。
- **指标纠正**（**校正，非倒退**）：

| 语料 | v2.5.0 degraded_todos | **v2.6.0** |
| :--- | ---: | ---: |
| 老 151 | 814（少计） | **851** |
| 新 79 | 61（少计） | **136** |

- **回归测试**：`tests/test_cfg_state.py` 新增 2 条。

## 6. 残余风险（如实披露）

1. **交互式 / 无限循环忠实化**：无 stdin 运行会挂起（非阻断告警已覆盖；逃生通道可回退）。
2. **回归 backlog（本版不修）**：
   - **P-1**：CJK 变量名 `%目标路径%` 未展开（字面残留 → 静默错）；须专项 + A1 防护。
   - **P-2**：延迟展开 `!` 语义差异（词法层）。
   - 二者 **CFG-independent**（on/off 相同），非本版范围。
3. **`label_in_block`（97/4）** 仍为诚实 TODO（须扁平化）。
4. 新语料「可 oracle」任务书口径仅 **10.1%**（擦线）——交互脚本占比高，自动化验证覆盖有限。
