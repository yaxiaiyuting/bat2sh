## 2. 主体功能实跑（安装版）：块结构修复 + 结构化映射表

输入 `demo.bat`（含 `if (...) (...) call :sub)` 粘连、`regsvr32`、`taskkill`）：

```bat
@echo off
if "%x%"=="1" (
  echo ok
  call :sub)
regsvr32 /u /s zipfldr.dll
taskkill /f /im explorer.exe
goto :eof
:sub
echo sub
exit /b
```

`bat2sh --cli demo.bat --print` 实测输出：

```bash
set -euo pipefail

label_sub() {
    echo "sub"
    return $?
}
if [ "${x:-}" = 1 ]; then
    echo "ok"
    label_sub
fi
# TODO: 手动检查: regsvr32 /u /s zipfldr.dll
pkill -f "explorer"
exit 0
```

`bash -n`：**通过（SYNTAX_OK）**。

对照验证点：
- **B1**：`call :sub)` 的粘连 `)` 已被正确识别为块闭合，产出 `label_sub` + `fi`（v1.8.0 会产出孤立 `)` 并整体降级）。
- **映射表 D 类**：`regsvr32` → **诚实 TODO**（`confidence: D`, `form: none`，不再原样执行）。
- **既有映射**：`taskkill /f /im explorer.exe` → `pkill -f "explorer"`。

## 4. CI 时序披露

| commit | 内容 | CI |
| --- | --- | --- |
| `9138b11` | bump to v1.8.1（**tag 指向此提交**） | ❌ 失败 |
| `c968fe7` | PKGBUILD/.SRCINFO 同步 | ❌ 失败 |
| `f35c3c1` | 修 CI：外部语料缺失时 skip | ✅ **全绿** |

失败原因：`test_real_corpus_block_forms` 依赖外部语料 `~/下载/非常批处理/`（未入仓），
CI 无该目录 → `StopIteration`。修复方式：语料缺失时 `pytest.skip`。

**影响**：仅测试代码；tag 的源码 tarball 在 AUR/PKGBUILD 安装路径下**不运行 pytest**，
对用户安装与运行无影响。严格遵守「tag 打在 bump commit 上、不对已发布 tag force-push」，
故保留 tag 指向 `9138b11`，并在此如实披露。
