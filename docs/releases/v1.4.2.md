## bat2sh v1.4.2

### Fixes（批处理转换器，全部来自 v1.4.1 沙箱体检 §10，均含 bwrap 沙箱运行验证）
- **for /f 包装引号剥离**（016- wmic查找文件.bat）：`for /f %%a in ('"cmd|filter|sort"')` 这类
  cmd /c 包装引号，之前整串被当单个命令名执行（`No such file or directory`）。
  触发条件收紧为三条件同时成立：整体双引号包装 + 剥离后可切分 ≥2 段管道 + 至少一段是已知命令；
  剥离后交给既有管道逻辑（2 段正常转换、≥3 段 TODO）。`"路径" "参数"` 类不误伤。
- **`set/a`、`set/p` 无空格归一化**（046-汉字横排变竖排---转置.bat）：`set/a Ye-=1` 之前
  原样透传为命令（`set/a: No such file or directory`，斜杠被当路径）→ 现归一化为
  `set /a` / `set /p` 并复用既有 handler。
- **循环变量 `%~dpn` / `%~dpnx` 保留路径**（055-重命名.bat）：之前生成 `$(basename ...)`
  丢弃目录部分，`dir /s` 递归场景指向错误目录 → 现分别映射为 `${var%.*}`（路径+主名）/
  `${var}`（完整路径）；语料波及 11 处 / 5 文件。无 n/x 的 `%~dpi` 等保持现状（backlog）。

  `%~dpi` 等无 n/x 修饰符（C2）
