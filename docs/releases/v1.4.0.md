## bat2sh v1.4.0

### New features
- **API 修复 TODO（实验性，CLI + GUI）**
  - CLI：`bat2sh --fix-todos <文件>`，逐条为 `# TODO` 获取修复建议
  - GUI：工具栏"API 修复 TODO"（列表 / payload 预览 / diff / 应用或跳过）+ 设置页 API 区块
  - Provider：OpenAI 兼容（OpenAI / Ollama / vLLM / LM Studio），错误分类 + 有限退避重试，仅标准库实现
  - 隐私：每次发送前原样展示将离开本机的内容并逐条确认（不记忆、无"全部同意"）；`--yes`/`--force` 不可绕过；非 TTY 直接拒绝
  - 安全：建议必须通过整脚本 `bash -n`；diff 确认后应用；失败保留原 TODO；全部结束后一次性写盘；中断即丢弃；API key 不进日志/异常/报告
- **配置系统**：优先级 CLI > 环境变量 > `~/.config/bat2sh/api.json`（原子写 + `0600`）；不内置任何服务商默认，缺失即报错（退出码 `6`）
- 真实语料 fixtures 纳入测试（CC0 / fleschutz-PowerShell 60 脚本）：转换管线不崩溃 + "never emit broken bash" 硬门槛

### Fixes（自 v1.3.0 起）
- `color_enabled` 容忍 `TERM` 未设置（GUI 从 .desktop 启动崩溃）
- GUI 模式不再向终端泄漏输出（诊断重定向到 `~/.local/state/bat2sh/gui.log`）
- GUI"转换并运行"支持中断/输入/超时，关闭窗口时询问并终止进程组
- `cls` 转换结果容忍 `TERM` 未设置（无终端时 `clear` 不再报错）

### 真实语料覆盖率（v1.4 体检）
- **bat**（54 个真实脚本交叉验证）：语法转换率 **98.1%**（53/54）、崩溃 **0**
- **PowerShell CC0 语料**（664 个脚本，fleschutz/PowerShell 全量只读体检）：
  - 崩溃 **0**；`bash -n` 通过 **498（75.0%）**、整体降级 166（25.0%）；TODO 共 5536
  - PS 侧仍为**实验性**：对象模型 / CIM / .NET 在 Linux 无对应，整体降级是保护性行为

### 已知限制
- PowerShell 侧仍为实验性支持（语义未就绪；不计入 95% 语法门槛的正式达标范围）
- API 修复为实验性：LLM 建议可能"语法正确、语义错误"；`bash -n` 只是硬下限，产品文案与 CLI 汇总均声明"仍需人工复核"
- API 修复仅覆盖 M1（整行）/M3（行尾）/M4（行内）三类标记；M2 管道整块与整体降级需人工处理
