> **性质**：`2.4.0` **minor**。目标 = **语义完整性（goto 形态全覆盖归属）**，**不是翻转数**。

## 3. 新增/修正行为

1. **冗余 goto → no-op**：`goto :X` 且 `:X` 紧随其后（整行独立、顶层、唯一标签、非 `call` 目标）
   → 发 `# goto X（冗余跳转…）`，不再报 TODO（cmd 语义：goto 不改 errorlevel）。
2. **前向跳转不可达区间 → 显式注释**：无条件顶层 goto 且区间内无标签样行（含 CJK）→
   区间不可达，逐行 `# [不可达] <原文>`；旧产物会让 cmd 中被跳过的代码在 bash 中执行。
3. **保守边界**：条件 goto / 块内 goto / 重复标签 / 区间含标签样行 → **不转换**，保留响亮诚实 TODO。

## 6. 引入静默错？—— 否（含一次「近失」主动披露）

Stage B 初版用 ASCII 标签正则判区间可达性，**漏判 CJK 标签**，在 `104` 上会注释掉可达代码（静默错）。
**逐文件产物 diff 立即捕获**，改为宽松标签判据（区间内有**任何**标签样行即拒绝）后恢复零变化。
详见 `docs/v2.4.0-report.md` §5。

## 7. 破坏性变更 / 已知限制

**破坏性变更**（详见 `docs/v2.4.0-breaking-changes.md`）：
- 前向跳转不可达区间：原样发射（bash 会执行）→ **显式注释（不执行）**——**语义修正**。
- `examples/stress_test.sh` 的 goto 区间按新语义更新（**最小改动 2+/3−**）。
- 死代码告警测试改为 **cmd 语义断言**（纪律 14）。

**版本号**：本版为 `2.4.0`（非 `3.0.0`）——变化仅命中 2 个语料文件（其中一个语法失败）
+ 1 个示例；且为「由错到对」的**修正**，非 API/语义契约破坏。

**已知限制**：
- 完整 goto CFG 状态机（多入口/多出口）**未实现**（须重构块发射，触 053；翻转 0）。
- `examples/stress_test.sh` **在基线已有遗留漂移**（`for /f "tokens=1-3"` 行），本版未顺手修复（保持可归因）。
