## bat2sh v1.4.1

### New features
- **GUI：API 设置页新增"测试连接"按钮**
  - 用当前填写的 `base_url` / `model` / `api_key` 发送一次最小请求（`say ok`）
  - `QThread` 后台执行，固定 **10 秒**超时（测试专用，不占用生产 timeout），不阻塞界面
  - 成功 → 绿勾 + 延迟毫秒（响应内容截断进 tooltip，key 已脱敏）；失败 → 红叉 + 错误分类
    （配置 / 认证 / 限流 / 服务端 / 超时 / 网络 / 格式 / 请求）
  - 改动任一 API 字段后自动清除上一次结果，避免过期状态误导；缺少必填项时本地即报错，不发请求

### Fixes（批处理转换器，均来自真实语料 + bwrap 沙箱运行验证）
- **`rem` 标点变体**：`REM.--`、`rem.(c)` 之前被当作未知命令原样输出 → 现按注释转换
- **`goto` 变体**：`goto:eof`（无空格）、`&` 串联中的 `goto` 之前被原样输出 → 现正确转为
  `exit 0` / 函数内 `return`；无空格 `goto:label` 也可识别
- **`call:label`（无空格）**：之前整行被静默丢弃（脚本逻辑静默缺失）→ 现生成函数调用；
  `call` 无法解析时改为 TODO，不再静默丢行
- **`cd.` / `cd..` / `chdir.`**：之前原样输出为未知命令 → 现转 `cd "."` / `cd ".."`（保留重定向）
- **`pause...........` 等点号变体**：之前原样输出 → 现按 `pause` 处理
- **`dir` 属性开关**：`/a-d`、`/a:d`、`/o:n` 等之前被当作路径传给 `ls`
  （`ls: cannot access '/a-d'`）→ 现识别为开关并告警忽略；`/b` + `/s` 组合保留递归（`ls -1R`）
- **`<nul set /p=文本`（无变量名）**：之前被误当成变量赋值（生成 `_p="文本"`）或原样输出
  → 现转 `printf '%s' "文本"`（无换行打印惯用法，保留输出重定向）；非 `<nul` 形式因等待
  输入语义无法确定，按最保守策略输出 TODO
- **`robocopy` 开关**：`/MIR`、`/E` 等之前被当作路径传给 `rsync`（`link_stat "/MIR" failed`），
  且 `rsync -a src dst` 会把源目录**嵌套**进目标，与 robocopy"复制目录内容"语义不符
  → `/MIR` → `--delete`；输出类开关安全忽略；源/目标补尾斜杠；未知开关与文件筛选形式 → TODO

### 真实语料体检（v1.4.1）
- 语料：bat-master(54) + windows-batch-script(24) + common_powershell_scripts(13) + 下载目录用户脚本(22)
  = **114 个文件**，全部经 `bwrap --unshare-all`（无网络、不挂载真实 HOME/etc/var/root）运行
- 转换：成功 95 / 整体降级 19（PowerShell 为主）
- 沙箱运行：**完全可用 54（v1.4.0 基线 48）**；"转换通过但运行失败" 39（基线 45）
- 本轮 4 个修复让 6 个脚本从失败变为完全可用（call-1、随机数、发邮件、`cd.`、`pause`、随机字符串）

### Backlog（本轮未修，附理由）
- **PowerShell 结构性缺陷**：`}` 与 `else` 之间夹注释导致 `else` 失联；`elseif` 条件 TODO 后
  产生悬空 `elif`；`-split` / `-join` / `.Members()` / `Add-Type` 等表达式残留 → 现状由
  "never emit broken bash" 整体降级保护，重构块结构关联逻辑风险高，列入 backlog
- 环境类失败（非转换器问题）：`ping` 原始套接字被沙箱用户命名空间限制；`adb` / `powercfg`
  未安装；`curl` 网络被沙箱阻断

### 已知限制
- PowerShell 侧仍为实验性支持（语义未就绪）
- API 修复建议仍需人工复核；`bash -n` 只是硬下限
