# bat2sh v2.8.0 发布说明 —— GUI 视觉优化（KDE Breeze）

> **性质**：`2.8.0` **minor**。PySide6 图形界面的**视觉优化**：**配色统一 / 间距对齐 / 图标一致性**。
> **定位**：**视觉优化，不是布局重做** —— 三栏布局、工具栏、面板层级、交互流程均**未改动**。
> **约束**：KDE Breeze 风格 / 不重做布局 / 功能零回归 / 测试全绿 / **无新依赖**（仅 PySide6） / 高 DPI 兼容。
> **AUR**：本版**不进 AUR**。

---

## 1. 优化内容（逐条）

### 1.1 配色统一

| 项 | 之前 | 之后 |
| :--- | :--- | :--- |
| 差异预览 HTML 背景/前景 | `dialogs.py` 内硬编码 4 个 hex（与调色板重复） | `theme.diff_colors(dark)` **单一来源**，与 `dark_palette`/`light_palette` 同源（**输出值不变**） |
| 「测试连接」成功/失败色 | 硬编码 `#43a047` / `#e53935`（Material 色，深浅不分） | `theme.status_text_color`（按控件调色板深浅分别取高对比绿/红） |
| 编辑器当前行号 | 硬编码蓝 `#6fb3ff`（不随主题） | `palette(Highlight)`（Breeze `#3daee9`，随主题自动适配） |
| 浅色调色板占位符色 | 未设置 | 补齐 `PlaceholderText`（与深色一致） |

> `report_level_color`（报告行级别色）行为**完全不变**（测试守护）。

### 1.2 间距 / 对齐

| 项 | 之前 | 之后 |
| :--- | :--- | :--- |
| 主区容器间距 | `spacing=4` | `spacing=6`（与面板默认一致） |
| 三栏面板 + 运行面板 | 依赖样式默认 | 统一 `PANEL_SPACING=6`（竖排 + header/按钮/输入行） |
| 状态栏计数初始文案 | `"警告 0 · 错误 0 · 已转换 0/0"`（措辞/顺序与更新不一致、缺 TODO） | `counts_text(None)` = `"错误 0 · 警告 0 · TODO 0 · 已转换 0/0"`（统一） |

### 1.3 图标

| 项 | 之前 | 之后 |
| :--- | :--- | :--- |
| 主题切换动作图标 | `weather-clear-night`（语义错误） | `preferences-desktop-theme`（Breeze 存在） |
| 文件列表项图标 | `QIcon.fromTheme(...)`（无兜底，缺图标则空白） | `_icon(...)` 增加 `standardIcon` 兜底 |
| 工具栏图标尺寸 | 样式默认 | 显式 `22×22`（Breeze 标准；Qt 按 DPR 缩放） |

## 2. 保留了什么

- **布局结构**：三栏 `QSplitter`、工具栏、面板层级、可折叠运行面板 —— **原样保留**。
- **交互流程**：动作、快捷键、信号连接、拖拽、运行控制 —— **未改动**。
- **功能**：转换 / 保存 / 批量 / 运行 / 差异 / 报告 / API 修复 TODO / 设置 / 预设 —— **全部保留**。
- **主题机制**：`QStyleHints.setColorScheme` 优先 + 手工调色板兜底（KDE/Wayland 友好）—— 不变。
- **语法高亮配色**：按可读性设计的深/浅色字典 —— 不变。

---

## 3. 无新依赖声明

**本版未引入任何新依赖**；改动仅涉及 PySide6 + Python 标准库。`pyproject.toml` 依赖未变
（`dependencies = ["PySide6>=6.5"]`）。
