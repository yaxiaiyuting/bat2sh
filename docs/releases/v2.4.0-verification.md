## 5. 安装与实跑（goto 语义）

```text

```

smoke 用例（`/tmp/v240_smoke.bat`）：

```bat
@echo off
echo before
goto :SKIP
echo 这行不会执行
:SKIP
echo after
goto :END
:END
echo done
```

| 检查 | 结果 |
| :--- | :--- |
| `bat2sh --cli v240_smoke.bat -o v240_smoke.sh` | `转换 3 行 \| 错误 0 \| 警告 0 \| TODO 0` |
| 前向跳转区间 | `# goto SKIP（前向跳转…）` + `# [不可达] echo 这行不会执行`（不执行） |
| 冗余 goto | `# goto END（冗余跳转…）`（等价 no-op） |
| `bash v240_smoke.sh` 运行输出 | `before` / `after` / `done`（**`这行不会执行` 未输出**，符合 cmd 语义） |
