## 五、偏离与不确定（主动披露）

| # | 项 | 说明 |
| :-- | :--- | :--- |
| 1 | **触发任务书暂停条件"LF-only 检测影响既有测试"** | 影响面为 **3 个快照 + 2 个 fixture 助手**：`test_examples.py`（hello 0→1、deploy 1→2）、`test_stress_no_crash.py`（冻结清单 +1）、`test_cli.py` / `test_cli_colors.py`（`.bat` fixture 改 CRLF 写出）。**判定为非回归并继续**：受影响的全是"快照/夹具"，原因是 `examples/*.bat` 与那两个 CLI fixture **本身就是 LF-only**（新告警对它们是真话）；产物零变化（§二）已独立证明无功能性回归。**未静默改测试**：每处都留了引用实测依据的注释。 |
| 2 | 任务书给的 XML 形式在本机不成立 | `<clock offset='time' adjustment='set'><time>…` 在 libvirt 12.7.0 的 RNG schema 里**不存在**；改用 `offset='absolute' start='<epoch>'`（libvirt ≥ 8.4.0）。见 `vm-time-fix.md` §2.2 |
| 3 | **只改 XML 固定不了时间** | 实测：过去日期被 Windows 拒绝（4 次冷启动都起在 2026-09-26，且两次相差 16.8 s ⇒ 不可复现）；未来日期被逐字采纳。因此新增"每轮 QGA 设 + 读回验证"，**并在文档里说明 XML 只是启动锚点** |
| 4 | `start` 检测做成**警告**而非任务书设想的 TODO | 理由：Linux 侧没有 Windows 文件系统，任何"检查目标是否存在"都是假检查；TODO 会改变 CLI 退出码与批量报告口径（超范围副作用）。产物与既有 TODO 路径均未变（有测试守护） |
| 5 | **推送了 6 个既有本地研究 commit** | `origin/main` 原停在 `4c7076c`，本地 `main` 已领先 6 个研究 commit（`f6d7848`…`85cde68`）。发布必须 push `main`，这 6 个 commit 随之进入远端与 tag 祖先链。**未改写历史、未强推** |
| 6 | 安装验证期间遇到**并发系统升级** | `pacman -Syu`（经 `yay`）正在运行时 `pacman -U` 被拒（`db.lck`）。**没有删锁**：等到升级结束（约 30 s）再安装；其间先用"解包直跑"验证发布产物（§4.2） |
| 7 | `examples/stress_test.sh` 既有漂移 | 见 §二末：42 字符差异，**先于本 session**，未修 |
| 8 | 未重跑 16 样本批量采集 | 时间固定设施本轮只做了 1 个真实样本端到端（`results/timefix/s04.json`）+ 域 XML/QGA 验证；全量 v4 指纹留待下次采集 |
