## bat2sh v1.6.0

### New features

- **PS 块结构统一加固（A 阶段）**
  - 未注册的大括号开启符不再原样泄漏：`_convert_statement` / `_emit_assignment` 对净开启的 `{` / `@{`
    统一压入注释容器（正文注释 + 大括号平衡），未来新构造不再造成块栈失同步。
  - `begin` / `process` / `end`（含 `clean` / `dynamicparam`）生命周期块保留结构（透明 `group` 块），
    正文照常转换，并警告 PS 管道阶段语义在 bash 无等价物。
  - `try/catch/finally`：多臂或带类型 catch 整体注释降级（不再伪造不可达的 `if/else`）；
    `catch` / `finally` / `else` / `elseif` 写在**独立行**时也正确派发（此前会原样泄漏）。
  - 赋值内 `switch` 走统一块栈；RHS 类型转换（`[version]` 等）剥离并警告。
  - 哈希表字面量收集器：扁平标量 → `declare -A name=( [k]=v … )`（实测运行语义正确），
    嵌套 / 复杂值 → 整段注释降级。

- **注册表智能映射（B 阶段）**
  - 读类映射 16 条（仅字面量键 + 只读操作）：重启检测（P0）、系统版本（P2）、硬件信息（P3）、
    安装检测（P4）、文件关联（P5）。目标依次为发行版重启探针、`/etc/os-release`、
    `/sys/class/dmi/id/*`、包管理器查询、`xdg-mime`。
  - 写类（`reg add/delete/import`、`Set/New/Remove-ItemProperty`、注册表路径上的 `New/Remove-Item`、
    COM `WScript.Shell`、`.NET Microsoft.Win32.Registry`）统一输出**结构化 TODO**
    `# TODO[REG] op=… key="…" value="…": 手动检查: <原命令>`，供 `--fix-todos` / API 处理。
  - 注册表路径不再被误译为文件操作（`ls -la "HKLM:/…"`、`rm -r`、`touch`、`[[ -e ]]`）。
  - cmd `reg` 行不再静默丢弃（此前整行从生成脚本消失）。
  - 拒绝（无证据不发明）：服务名 → systemd unit、`.reg` 生成 / 导入、PSProvider、动态键路径。

### Fixes

- CLI 专用参数隐含 `--cli`：`--print` / `--report-json` / `-o` 等不再误启 GUI
  （无显示环境下不再挂起）；无参数或仅位置脚本路径仍启动 GUI。
- 测试盲区补全：独立行 `catch` 形态从 0 覆盖 → 有覆盖
  （同行 `} catch {` 11 处 vs 独立行 0 处）。
