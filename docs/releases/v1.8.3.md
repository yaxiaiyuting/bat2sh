## bat2sh v1.8.3

> 阶段一：把 v1.8.2 剩余的 46 条 rc≠0 逐条归因（A/B/C/D/S/ENV）。
> 阶段二：按裁定修 4 条、退回 3 条、并把 2 条**静默错**降级为诚实 TODO。
> 归因见 `docs/v1.8.3-attribution.md`；方案与评估见 `docs/v1.8.3-design.md`；逐轮记录见 `docs/v1.8.3-rounds.md`。

### ⚠️ v1.8.2 数据更正（重要）

v1.8.2 发布时报告的 **`rc==0 = 105` 是错误口径**（`105 = 151 − 46`，把 6 条**语法失败**、
无产物者也算进分母）。正确为 **145 条语法通过者中 rc==0 = 99**。
evaluated 更正已随 `docs/releases/v1.8.2.md` 的 **Errata** 小节 + GitHub Release 正文同步
（commit `dff62af`）。**本版所有 rc 指标一律以 145 为分母。**

### 版本号选择理由（patch 还是 minor）

**patch（1.8.3）**：形态为发射缺陷修复 + 静默错降级；新增映射 **0 条**；
触及转换模块 **1 个**（`core/batch.py`）；无 >2 条词法层重构；无破坏性变更。

### 静默错降级（2 条，纪律 1 的落地）

退回 ≠ 放任。按 `docs/v1.8.3-design.md` §5 检查，以下两条为「语法通过、行为错」的**静默错**，
本版**降级为诚实 TODO**（独立 commit `3a61460`）：

| 条目 | 降级前（静默错） | 降级后 |
| :--- | :--- | :--- |
| 085 | `done < <(ip addr \| grep -F -i "ip address")` —— 过滤器**永不匹配**，循环空转 | `# TODO: 手动检查: for /f …` |
| 053 | `cat %i >>小节.txt` —— 循环变量 `%%i` **逸出**，坏命令 | `# TODO: 手动检查: type %%i>>t.txt` |

**收窄（防止过度降级）**：085 仅命中 `for /f` 内层 `ipconfig` + 英文标签 “ip address”，
**不触碰** `_FINDSTR_CJK_MAP` 覆盖的 `findstr "IPv4"`；053 仅在**无活动循环**时降级，
**不触碰**循环内「tokens 未声明」的 warn-only 情形。
