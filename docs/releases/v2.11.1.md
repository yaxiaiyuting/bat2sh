## bat2sh v2.11.1

> **性质**：patch。修掉 v2.11.0 登记的已知限制 **L1**（`%%~n` / `%~n0` 顺序倒置），
> 并交付两项**只读研究**：一次五类别安全审查、一轮 21 样本真机 oracle 扩样。
> **本版不修任何安全缺陷** —— 审查与 oracle 确认的高危项全部**留待下一版**，理由见下。

### Fixes

#### `%%~n` / `%~n0` 顺序倒置 ⇒ 含点祖先路径截错（原 L1）

`_modifier`（`batch.py:1250`）把 `%%~n` 映射为 `basename "${v%.*}"` ——
**先从整串最后一个点剥扩展名、再取末段**，顺序倒置。

触发条件（本版收紧为充要条件）：**`basename(v)` 自身不含点，且某个祖先路径段含点**。

```bat
@echo off
for /r %%i in (.) do @echo %%~ni
```

在 `.../my.project/samples` 下运行：修复前输出 `my`/`my`，本版输出 `samples`/`sub`。
缺陷**完全静默**（`rc=0`、stderr 空、无 `# TODO`、`bash -n` 通过）。

- 修复：`:1250`（`%%~n`）+ `:1265`（`%~n0`），共 **2 行**产品代码；
- **6 条实现串断言改写为真跑语义断言**（其中 1 条原先把缺陷表达式钉死）；
- 新增 `tests/test_batch_tilde_n_dotted_path.py`（6 条，含**无点路径对照**）；
  **该文件在修复前实测 4 条红** ⇒ 非空转。

未一并修（缺 cmd 真机指纹，按「不发明映射」保留）：`%%~x`（`:1252`）、`%%~dpn`（`:1244`）。

### 安全审查（只读，**结论：本版不修**）

5 个只读 subagent 并行审查（`del` 120 例 / `for`+删除 76 例 / 移动复制 / 路径处理 / 其他），
主 session 去重、裁定并**独立复现**。详见 `research/security-audit.md` 与 5 份分类报告。

**11 条高危去重后归约为 7 个根因**，其中 4 个能造成**静默数据销毁或任意命令执行**：

| 根因 | 最小复现 | 后果 |
| :--- | :--- | :--- |
| **R1** 字面 `$` / `$()` / 反引号被当活语法 | `del "a$(touch PWNED).txt"` | **任意命令执行**（4 个 subagent 独立报出） |
| **R2** 路径 token 回退产出未引号 / 活 glob | `rd /s /q \\?\C:\data` | 删掉 bat 从未提及的目录 |
| **R3** `%WINDIR%` → `/` 再拼 `\*` | `del /s /q %WINDIR%\*` | `rm -rf "/"/*`（**不受** preserve-root 保护） |
| **R4** `errorlevel` 条件被拼进 `\|\| true` 守卫 | `findstr … ` + `if errorlevel 1 del keep.txt` | **条件恒真 ⇒ 无条件误删** |
| **R5** `for /r` 的 `find "$PWD"` 首值 = CWD 自身 | `for /r %%i in (.) do rd /s /q "%%i"` | **删掉整棵工作树含运行中的脚本** |

**主 session 独立复现 3/3，零误报**（`$()` 执行、`errorlevel` 恒真误删、`for /r` 自删整树）。

**为何不修**：命中既定暂停条件「高危且修复复杂」——
修复面横跨 **9 个**核心函数；R1/R2 属「转义责任散落」的**设计级**改动；
R1 的修复**必然触 A1 热路径**（要区分"展开插入的 `$`"与"源里字面的 `$`"）；
R3 的正确映射属**产品决策**。已在 `research/security-audit.md` §6.3 给出优先级 backlog。

### oracle 扩样本（21 样本，真机差分）

W = 真机 Windows（QEMU/QGA），L = 产物 bwrap 沙箱。详见 `research/behavior-tracking/oracle-result-v2.md`。

**结果：一致 6 · 可归因 4 · 不可归因 11。** 其中**真机确认 4 高危 + 4 中危**（同样**本版不修**）：

| 样本 | 现象 | 后果 |
| :--- | :--- | :--- |
| `w1` | `findstr` 命中、`if errorlevel 1` 却仍删 | **静默数据丢失**（W 保住 `keep.txt`，L 删掉） |
| `w2` | `echo x > log?.txt` | cmd 报错不动；L **静默覆盖 `log1.txt`** |
| `w3` | 字面 `$(echo INJECTED)` | W 写字面量（18 B）；L **执行**（9 B） |
| `w14` | `for /r … rd /s /q "%%i"` | cmd 因「文件正在使用」**一项未删**；L **删掉正在运行的脚本** |
| `w5` | `del /s` | L **不递归** ⇒ 子目录文件残留 |
| `w6` | `set /a size=%n%*1024` | L 语法错 + `set -e` ⇒ **整个脚本中止** |

**正面结果**：`w4`（含点祖先 + `%%~ni`）**一致** ⇒ 本次 `%%~n` 修复**通过真机差分验证**。
`v1`/`v5` 由 v2.11.0 前的「不可归因」转为**一致**，`v3`/`v4` 转为可归因 ⇒ v2.11.0 修复未回退。

⚠️ **不要把 11/21 读作"缺陷率 52%"**：21 个样本中 **8 个是定向构造**的确认性实验。
**在真实语料 A 类（4 个未经挑选的样本）上没有发现新的高危缺陷。**
另外，语料的 A 类（可归因）样本**只有 4 个**，因此任务书原定的「20 个样本」在原标准下**不可达**——
本版改为「真实 9 + 仓库 4 + 定向构造 8」，并**显式标注每个样本的归因等级**。
