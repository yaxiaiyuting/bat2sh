## bat2sh v2.1.0

> **性质**：`2.1.0` **minor**。2.x 的 **goto 语义转换前置基础设施**——CFG 只读数据模型。
> **本版为零转换改动**（纯新增只读设施）：151 语料产物**逐字节不变**，指标全部持平。
> **P5（goto 简单形态 pilot）未落地**：经**实测**（非估算）证伪其翻转收益（详见 §1.2 / §4），
> 显式归 **v2.2.0**（纪律 16，非静默）。
> **2.x 定位声明（关键，同 v2.0.0）**：
> **2.x 是「完整语义支持」版本，不是「指标翻转」版本。** goto / `sc` 的 TODO 量不代表可翻转量——
> 大多落在多设施宿主或 Linux 无对应项。**评估 2.x 请以「语义正确性 + 可用性」为主，不以翻转数为唯一标尺。**
> **验收标准用原则性表述，禁止估算**（v2.0.0 的「语法 4→1」与本次路线图的「翻转 ≈3–4」均为估算错；
> 本版据此**不预设任何翻转数字**）。
> **AUR**：本版**不进 AUR**（同 v2.0.0）；`PKGBUILD`/`.SRCINFO` 完成**仓库侧同步 + 本地 `makepkg` 验证**。

## 1. 本版做了什么

### 1.1 P4：CFG 只读数据模型（新子系统）

| 项 | 内容 |
| :--- | :--- |
| `python/bat2sh/core/cfg.py` | **标签位置表**（`:label` → 行号/下标/块内/入边计数）+ **goto→标签边**（源、目标、目标类型、方向、块内、条件、冗余、C4 形态键）；`validate_cfg()` 守护 |
| 只读纪律 | **不 import `core.batch`、不被转换器调用** → 对产物**零影响**；`ast` 测试守护 |
| 形态口径 | 复用 C4 台账 `classify_goto`（7 个互斥主形态），不新增形态 |
| `tools/cfg/cfg_report.py` + `README.md` | 只读报告：复现 CFG 统计并与 C4 台账逐项交叉核对 |
| `tests/test_cfg.py` | **24 条**回归测试（不依赖外部语料，CI 可跑） |

**实测（151 语料）**：标签位置 **781**；goto 边 **1583**；形态分布 **7/7 与 C4 台账一致**
（`eof_exit 93/20`、`forward_skip 551/26`、`backward_loop 446/28`、`in_block_goto 457/8`、
`redundant_goto 27/5`、`missing_label 8/2`、`dynamic_target 1/1`）；
逐文件 `validate_cfg` **0 问题**；`logical_lines` 与 `batch._logical_lines` **逐行一致**。

### 1.2 P5：goto 简单形态 pilot —— **未落地，显式归 v2.2.0**

任务书把 v2.1.0 定位为「2.x 第一次真实 goto 转换」，范围 = `redundant_goto` + 顶层 `forward_skip`，
路线图估算**翻转 ≈3–4**。**实测证伪**（`docs/v2.1.0-coldstart.md` §4.2）：

| P5 形态 | 台账（语句/文件） | 可证安全子集实测 | 文件翻转 |
| :--- | ---: | :--- | ---: |
| `redundant_goto` | 27 / 5 | 独立行 no-op 集中于 `史上最牛X…bat`（**语法失败** → 产物整体降级 → 消除后**零产物影响**）；其余嵌在 `if/else`、管道 `& if` 复合行，需**行级重写** | **0** |
| 顶层 `forward_skip` | 551 / 26 | 无任何宿主是 goto-only degraded 文件；转换需把被跳过区间包进 `if`（**块结构发射**，053 同域）；置信度 D（目标可被**多处跳入**） | **0** |

- 路线图点名的「翻转 ≈3–4」文件（`合并文本`×3 + `显示所有分区的剩余空间`）真实阻塞为
  **`for /f` 选项 / 块内 goto / 回跳**——**均不在 P5 形态内**。
- 全语料「所有 TODO 均为 goto 转换类」的 rc==0 degraded 文件**仅 1 个**
  （`显示所有分区的剩余空间.cmd`，其 goto 全为 `backward_loop`，属 v2.2）。
- 裁定：按任务书裁定表「P5 触及 053/A1 无清晰方案 / P5 无候选 → **只交 P4**」，
  且**保守 TODO 优于激进转换**（纪律 1）与**不硬凑**（纪律 13）→ **P5 退回 v2.2.0**。

## 4. 重要披露（纪律 4/13/17）

1. **路线图估算「翻转 ≈3–4」被实测证伪为 0**：与 v2.0.0「语法 4→1」同类（估算错）。
   本版**不预设翻转数字**，用原则性验收（P4 零漂移 + 指标不倒退 + 053/A1 未触 + changes ≤5 模块）。
2. **P5 未落地 = 显式归属（纪律 16）**，非静默跳过：退回 v2.2.0 并给出实测依据（§1.2）。
3. **起点 HEAD 偏离**：任务书记 `a227908`，实测 `main` = `d901b5c`（+1 docs-only commit，代码零差异）——
   以 `d901b5c` 为分支起点（= `origin/main`）。
4. **必读文档缺失**：任务书 §三.4 的 `docs/v2.0.0-acceptance-revision.md` 不存在；
   以 `PROJECT-OVERVIEW.md` 纪律 17 + `v1.11.0-standards-revision.md` 为准。
5. **版本号判断（§9.1 降级讨论）**：任务书建议「P5 翻转 <1 且 P4 纯只读 → 考虑降 v2.0.1」。
   本 session 判断**保留 2.1.0**：新增 `core/cfg.py` 为**公开只读子系统**（含工具 + 测试），
   属 **minor feature**（沿用 v1.10.0 交付四个只读子系统仍为 minor 的先例）；`2.0.1` 语义为补丁
   （仅缺陷修复），会误述本版性质。**如实披露该判断。**

## 5. 已知限制

- **goto 简单形态未转换**：`redundant_goto` / 顶层 `forward_skip` 仍为诚实 TODO（v2.2.0）。
- **CFG 为括号净值近似**（非转换器 `_Block` 块栈）：`LabelPosition.in_block` 为扫描器口径；
  C4 台账 `label_in_block=97/4` 为转换器口径（`report.errors`），两者口径不同、不可互套。
- **重复标签**：解析目标取最后一次出现（与 C4 台账一致）；cmd 真机语义未断言（v2.2 决策点）。
- `史上最牛X…bat` 仍语法失败（B5/解析层，v2.2+）；LF-1 未修。
- 2.x 需求驱动启动条件（T1/T2/T3）不变。
