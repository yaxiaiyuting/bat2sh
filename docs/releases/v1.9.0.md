## bat2sh v1.9.0

> 本版主题：**取消静默丢弃** + **053 块栈根因修复** + **环境依赖映射扩展**。
> 设计/评估见 `docs/v1.9.0-design.md`；逐项指标见 `docs/v1.9.0-rounds.md`。

---

## ⚠️ 口径说明（务必先读）

**rc==0 采用严格定义（本版起）**：

> **rc==0 = 脚本跑通 且 功能完好。含 `# TODO` 标记的产物不计入 rc==0，单列 `degraded`。**

理由：若 rc==0 只表示「能跑通」，它就退化成 `bash -n`，失去区分度。rc==0 的价值在于
区分「功能完好」与「功能缺失」。

**本版「功能完好」由 22 降至 16、「degraded」由 80 升至 86——这不是退步，而是把「假 rc==0」
纠正为「真 degraded」。** 6 条迁移全部有语料证据：

| 文件 | 迁移 | 真相 |
| :--- | :--- | :--- |
| `013 为Administrator改名.bat` / `023 删除用户.bat` / `079 文件夹变磁盘.bat` | 完好→degraded | 指令**整行蒸发**（本版 P1 修复，现落为显式 TODO） |
| `049 定时关机.cmd` | 完好→degraded | `at` 计划任务 → C 档「建议 + TODO」 |
| `116` / `118` BeeNotice | 完好→degraded | `BeeNotice.exe` → D 档诚实 TODO |

即：v1.8.3 制度下 `013/023/079` **指令已消失却仍被计为「功能完好」**——这正是本版要修的静默错。

## 版本号选择理由（minor 还是 patch）

**minor（1.9.0）**：修复触及块栈核心（`_convert_if`/`_convert_for`/`_emit_for_f`/`_pop_block`/
`_close_block_line`）；新增映射 **10 条**；新增丢失检测机制；新增 `_Block.finish_parent` 语义。
转换模块触及 1 个（`core/batch.py`），映射表 1 个（`mappings/windows_tools.py`）；
映射新增 < 20 条；无破坏性 CLI/配置变更。

## Fixes（4 项）

### 1. 取消静默丢弃：`cmd_todo_hint` 命令整行蒸发（**最高优先级**）

- **缺陷**：`cmd_todo_hint`（`wmic`/`subst`/`net`/`attrib`/…）登记 TODO 后 `return None`，
  被派发分支 `if line is None: return []` **整行丢弃**——命令既不执行也不留标记。
  **自 1.0.0 起存在**。实测 6 文件：`001`（134 条 attrib）、`013`、`023`、`072`、`079`、`102`；
  其中 `013/023/079` 产物近似空脚本。
- **修复**：`cmd_todo_hint` 返回 `# TODO: 手动检查: <原行>`；
  `_convert_logical` 新增**丢失检测**（源行未产出且无诊断且非既定 noop → `warn(category="loss")`）。
- **证据**：`013 为Administrator改名.bat:1`、`079 文件夹变磁盘.bat:1`。

### 2. 053 块栈失同步根因修复

- **缺陷**：`for /f` + 嵌套 `if/else(` 中，行尾**未配平**的 `else (` 被 `_convert_if` 提前闭合
  （与对称的 `_close_block_line` 不一致）→ else 体出循环 → `%%i` 逸出 → `))` 落空栈。
- **修复**：`_Block.finish_parent` + `_pop_block` 链式收尾父块；`_close_block_line` 支持
  行内连续 `)`；`_convert_if` 对未配平 `else (` 保留 `await_paren_close` 块；
  `_convert_for`/`_emit_for_f` 不再无条件 pop（5 hunk，**非词法层**）。
- **证据**：`将所在目录的BAT文件合并成一个BAT文件，通过 选择 运行其中之一.bat:12`。
  修复后源第 13–30 行全部进入循环体，`cat %i` → `cat ${i}`。

### 3. 环境依赖映射扩展 10 条

映射表 27 → **37** 条（每条附真实语料 `evidence`，`validate_mappings()` 通过）：

| 档 | 条目 |
| :--- | :--- |
| B | `tree`（需另装 tree 包；`/F` 与 `-f` 语义不同） |
| C（建议 + TODO） | `tskill`→pkill、`at`→systemd-run、`arp`→ip neigh、`help`→man（`output_contract`） |
| D（诚实拒绝 none） | `ipseccmd`、`netsh`、`explorer`、`beenotice`、`chkntfs` |

### 4. B 类应用层缺陷判定（B-1/B-2 修，B-3 记录）

| 项 | 判定 | 结果 |
| :--- | :--- | :--- |
| **B-1** 盘符全路径（`c:\windows\system32\rasdial`）不查映射表 | **B → 修** | `宽带连接.bat` rc 127→0（转诚实 TODO） |
| **B-2** `start` 内层命令不派发（`START /WAIT REGEDIT`） | **B → 修** | `035 显示隐藏扩展名.bat` rc 127→0 |
| **B-3** 映射被 handler 遮蔽 | **记录** | `ping` 由专用 handler 实现；`regedit`/`subst` 经修复 1 后已落显式 TODO；`title` 判 D 不修（发射 ANSI OSC 会向重定向输出注入转义序列，属回归风险） |

> `title` 的处置为**对「B → 修」机械读法的主动偏离**，理由见 `docs/v1.9.0-rounds.md`。

## 已知限制

1. **062② 未修**（退回 backlog）：未闭合引号/命令替换路径为**响亮失败**（rc≠0 + stderr 可见），
   本版确认无静默错。
2. **`title` 仍按 noop 丢弃**（B-3c 判定）：终端标题设置未自动发射，避免向重定向输出注入 ANSI 转义。
3. **`013/023/079` 的指令仍是 TODO**：本版只保证「不再静默蒸发」，未发明 `Wmic`/`net user`/`subst`
   的 Linux 等价物（纪律 7）。
4. **循环体赋值不保证的 `set -u` 缺口**（`008`/`053`/`073` 暴露）：属 085 同域「流程感知 guard」，
   v1.8.3 已因 26/151 churn 否决，本版维持。
5. `//`、`\/` 外观残留（Windows 盘符/UNC）延续。
6. 6 例语法失败仍**整体安全降级为注释**，绝不输出坏 bash。
7. `rules.py` 既有映射仍未迁入结构化表（backlog）。
