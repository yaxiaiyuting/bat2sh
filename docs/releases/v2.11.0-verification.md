### 4.1 安装包冒烟：三缺陷最小复现

```bash
bat2sh --cli -q -o f1.sh f1.bat   # type "%W%\f.txt"
bat2sh --cli -q -o f2.sh f2.bat   # for /d %%i in (aa,bb,cc) do md %%i
bat2sh --cli -q -o f3.sh f3.bat   # for /r %%i in (.) do (cd.>"%%i\%%~ni.txt")
```

| 复现 | 产物（安装包生成的） | 判定 |
| :--- | :--- | :--- |
| F1 | `cat "${W}/f.txt"` | ✅（修复前 `cat "${W}\f.txt"`） |
| F2 | `for i in aa bb cc; do` | ✅（修复前 `for i in aa bb cc/*/;`） |
| F3 | `cd "." >"${i:-}/$(basename "${i%.*}").txt"` + `done < <(find "$PWD" -type d)` | ✅（修复前 `\\$(…)` + `find .`） |

### 4.2 **安装包**口径重跑 oracle（最强证据）

用 `--bat2sh` **不覆盖**（即 PATH 上的 `/usr/bin/bat2sh`）重采 L 侧，
与 W 侧（真机）对比，写入 `results/oracle/L-v2110-installed/`：

| 样本 | 分类 | 生效规则 → D |
| :--- | :--- | :--- |
| V1 | ✅ 一致 | — |
| V2 | 🟡 可归因 | N11 → D3 |
| V3 | 🟡 可归因 | N10 → D2 |
| V4 | 🟡 可归因 | N10+N15 → D2/D15 |
| V5 | ✅ 一致 | — |

```
一致 2 / 可归因 3 / 不可归因 0     ← 与工作树口径完全一致
```

指纹的 `harness.convert_tool` 记为 **`/usr/bin/bat2sh` [bat2sh 2.11.0]** ——
证明用的确实是**发布出去的安装包**，而不是工作树。

## 六、偏离与已知限制（主动披露）

| # | 项 | 说明 |
| :-: | :--- | :--- |
| **D1** | **commit 顺序**偏离任务书 | 实做 F1→F2→**F5**→F3（任务书为 F1→F2→F3→F5）。理由：F5 是 F3 的**使能**修复，且其通用写法完全覆盖 F3-a 的窄修；按原序 commit 4 必须回退 commit 3 的代码。见 `p0-diagnosis.md` §12.2 |
| **D2** | **范围扩大**（G2 裁定） | 一并修 F5（`\` 后接变量展开，14 文件 / 48 处）。初版候选写在 `_expand_vars` 会漂移 17/155，改为落在 `convert_backslashes` 后降至 13/155 |
| **D3** | **4 条测试断言重写** | `tests/test_batch_for_r.py` 的 4 条断言原本编码**实现细节**（相对路径、字面命令串），按纪律 9 改为语义断言（`realpath` 归一 + 真跑） |
| **D4** | **oracle 工具修正 3 处** | `collect_linux.py --bat2sh`（**首次重跑得到的是"未修复"结果**——它调的是系统已装的 v2.10.0）、`compare.py` 的 N15/D15、归因改为最小规则集。详见 `p0-result.md` §3.2 |
| **D5** | 限制 L1 | `%%~n` 的通用表达式未加固：父目录某段含点时会截错（比修复前严格更好，未根除） |
| **D6** | 限制 L2 | `for /r` 的 `%%i` 由相对变**绝对**（向 cmd 靠拢；依赖其文本形态的脚本会受影响，故取 minor） |
| **D7** | 限制 L3/L4 | `\` 后接变量仍有 3 处可执行残留（均为**有意排除**）；F4/盘符行为对用户**无告警**（是否加告警属产品决策） |
| **D8** | 限制 L5 | oracle 覆盖边界未变（A 类仅 4/151）。**本轮只证明"这 5 个样本上缺陷已消除"，不能外推整体正确率** |
| **D9** | 新登记 F6 | `_convert_path_token` 的通配符回退可产出**未加引号的 glob**；本版通过排除 `\\?\` 前缀规避，底层脆弱性仍在 |
| **D10** | D15 规则的判别力代价 | N15 会掩盖"本该写到工作根之外、却以其它形态落进工作根"的写入（仅限首段恰为 `X:` 的路径）；报告逐条打印其"掩盖了什么" |
