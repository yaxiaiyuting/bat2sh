## bat2sh v1.10.0b1

> **性质说明**：这是 **1.10.0 的第二个预览版（beta）**，交付 **C4 goto 控制流子系统**
> 的**收窄版**——即**控制流形态台账 + 分类器 + 校验器 + 只读报告**（第四张结构化表）。

> **固化为可校验的代码与证据**，为 v2.0 的 CFG/状态机铺路。
> 设计与裁定见 `docs/session-c4-coldstart.md`、`docs/session-c4-review.md`、
> `docs/session-c4-design.md`；会话报告见 `docs/session-c4-report.md`。

> ⚠️ **pre-release 也是发布**：tag 打在 bump commit 上、CI 全绿确认、release notes 完整，
> 与正式版同流程（v1.8.1 教训适用）。

## 版本号选择理由

`1.10.0b1`（PEP 440 beta）：本版新增一个**子系统**（控制流形态台账），按 semver 属 minor；
但 (a) **不做语义转换**（CFG 留 v2.0）、(b) 收益为**研究固化**而非文件翻转、
(c) 后续还有 Session C（词法层）→ 1.10.0 正式版，故为 **beta 预览**（较 alpha 更接近定稿）。
**不进 AUR 主分支**（`PKGBUILD`/`.SRCINFO` 停留 1.9.2；如需预发布包须另立 `bat2sh-pre`）。

## New features

### 1. C4 —— goto 控制流形态台账（`python/bat2sh/core/control_flow.py`）

**问题**：cmd 的 `goto` 是**任意跳转**（前跳/回跳/跳出/跳入控制块/动态目标），bash 无对应物；
要译对必须先做**控制流图（CFG）**分析。路线图把 C4 评为 1.x **单点最大（~250 TODO）、
风险最高**，明确归 **v2.0**（`docs/v1.x-roadmap-research.md` §1.C4/F1）。

**本版**不实现转换，而是新增与「命令表 / 名称表 / 输出契约表」并列的**第四张表**：

- `ControlFlowPattern` 台账：7 个**互斥主形态** + 1 个辅形态，每条含
  `direction`/`location`/`conditionality`/`target_kind`/`confidence`/`integrated`/
  `convertible`/`plan`/**`evidence`（真实语料 `文件:行`）**。
- `classify_goto()`：纯函数、互斥分类（动态目标 → `:eof` → 缺标签 → 块内 → 冗余 → 回跳 → 前跳）。
- `summarize_goto_lines()`：`echo`/`rem` 感知、CJK 标签感知的扫描器。
- `validate_control_flow_patterns()`：**纪律 7**（`evidence` 必填且格式为 `文件:行`）、
  置信度光谱、`integrated=True` 仅限已实现项、D 档不得 `convertible`。
- `tools/c4/control_flow_report.py`：只读报告，复现台账计数（8/8 OK）并给转换器口径统计。

**实测分布（151 语料）**：goto 语句 **1583**；前跳 `forward_skip` 551/26、
回跳 `backward_loop` 446/28、块内 `in_block_goto` 457/8、`goto :eof` 93/20（**已实现**）、
冗余 27/5、缺标签 8/2、动态目标 1/1；辅：块内标签 97/4（error 层）。
**转换器口径**：goto TODO **1362/39 文件**，其中 degraded 内 **252/22 文件**。

原 CI 仅触发 `push main` 与 PR，**分支/tag push 不触发**（v1.10.0a1 只能靠草稿 PR 取得覆盖）。

## 已知限制（诚实披露）

1. **不做任何 goto 语义转换**：本版**零转换改动**，`_convert_goto` 等路径逐字节不变。
   goto 的静态翻译（CFG → `while`/函数/状态机）为 **v2.0**；路线图评 15–25 人日、风险最高。
2. **翻转收益极低**：唯一阻塞=goto 的 degraded 文件仅 **3**（`合并文本`×3，其一实为
   `for /f` 选项问题）→ 即便实现 CFG，**文件翻转 ≈ 2/86**。这是路线图「TODO 数与翻转数
   严重不成比例」的又一实例，**不硬凑提升**。
3. **4 条「真块失同步」未碰**（`044`/`059`/`135`/`138`）：属块栈/词法层残余（非 goto），
   触及 053 同域且无清晰方案 → 维持现状（纪律 1）。
4. **动态目标 / 缺标签 / 块内 goto** 属终态或 v2.0：维持诚实 TODO。
5. **任务书两处前提偏差**（已披露）：053 于 **v1.9.0**（非 v1.9.2）修复；
   v1.9.2 剩余 4 条残余是**块结构失同步**（非 goto 靶子）。
6. 台账 `in_block` 为**括号净值近似**（非块栈）；`missing_label` 仅计字面标签。
