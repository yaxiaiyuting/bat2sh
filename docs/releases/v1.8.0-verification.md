## 2. 主体功能实跑：取消在途请求 < 1s（pty 驱动，安装版）

场景：本地 OpenAI 兼容 SSE mock 在**首个 chunk 后 stall 60s**（不访问外网）；
`--fix-todos` 交互用 `pty.fork` 驱动（子进程为会话首进程，故 `Ctrl+C` 作为 SIGINT 送达）。
在流式已收到 `echo "partial"`（确为在途）后发送 `Ctrl+C`。

命令：

```bash
bat2sh --cli /tmp/bat2sh-v180-e2e/demo.bat --fix-todos \
  --api-base http://127.0.0.1:<mock-port>/v1 --api-model mock --api-timeout 30
```

实测输出（已去 ANSI）：

```text
bat2sh: 发送 1 条到 http://127.0.0.1:43713/v1？[y/N] y
bat2sh: 并发 3（--max-concurrency 可调）

#1 第7行 running
#1 第7行 running | echo "partial"
^C
#1 第7行 skipped：已取消

bat2sh: 已中断，未写盘（本次会话修改已丢弃）
```

| 指标 | 实测 | 契约 |
| --- | --- | --- |
| **Ctrl+C → 进程退出** | **0.0151 s** | < 1s ✅ |
| 在途任务状态 | `skipped：已取消` | skipped（非 failed）✅ |
| 是否写盘 | `demo_sh_written=False` | 取消期间不写盘 ✅ |
| 退出码 | `1` | 中断退出码 ✅ |

> 对照 v1.7.0：同一场景下最坏需等**一个空闲超时（默认 30s）**；v1.8.0 为 0.0151s。

## 3. 主体功能实跑：PS 发射缺陷修复（安装版）

输入（`try { if/elseif/else } catch` + 裸字符串输出）：

```powershell
try {
    if ($x) { $a = 1 } elseif ($y) { $a = 2 } else { $a = 3 }
} catch { $a = 0 }
$path = "/tmp"
"📂$path entered"
```

`bat2sh --cli d1.ps1 --print` 实测输出（结构完整、裸字符串已转 `echo`）：

```bash
set -euo pipefail
if true; then  # TODO: try/catch 未等价转换
    if [[ ${x:-} ]]; then
        a=1
    elif [[ ${y:-} ]]; then
        a=2
    else
        a=3
    fi
else  # TODO: catch 块
a=0
fi
path="/tmp"
echo "📂${path} entered"
```

`bash -n`：**通过（SYNTAX_OK）**。对照 v1.7.0：同一输入产出孤立 `else`/`fi`，`bash -n` 失败并被整体降级。
