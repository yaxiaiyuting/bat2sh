## 1. 选取标准

沿用 `poc-samples.md` §1 的 C1–C5，并按本阶段新增两条：

| # | 标准 | 理由 |
| :-- | :--- | :--- |
| C1 | **无交互** | `guest-exec` 无 stdin 通道；`pause` / `set /p` 会挂住（语料的 **53.7%** 因此不可直接用） |
| C2 | **行为明确** | 便于人工核对"指纹是否可信" |
| C3 | **非破坏性** | 不 `format`/`diskpart`/改注册表/删系统文件。即便有回滚，也不该引入不可控噪声 |
| C4 | **许可干净** | 用户自有脚本可入仓引用；`bat-master`/`非常批处理` **无许可 ⇒ 只引用路径，不入仓** |
| C5 | **有界运行时间** | 不选可能挂到超时的（`start /w notepad`、`cmd /k`、无限循环）。批量时间里"一个挂住"就是 120 s |
| **C6** | **文件名无空格** | **实测硬约束**：QGA 的 `guest-exec` 会给参数里的 `"` 加反斜杠转义，而 `cmd.exe` 不认 `\"` ⇒ **含空格路径根本无法执行**。清单里统一用 ASCII 短名（`s01.bat` …），原名记入指纹 |
| **C7** | **basename 唯一** | guest 内统一落在 `C:\poc\samples\`；语料里有多个同名 `2.bat`，会互相覆盖 |

### 1.1 语料扫描（218 个 `.bat`/`.cmd`）

| 过滤 | 剩余 |
| :--- | ---: |
| 全部 `.bat`/`.cmd`（`bat-master` + `非常批处理` + 用户自有） | **218** |
| — 排除含 `pause` / `set /p`（**C1**） | 117 → 101 |
| — 排除含 `format`/`diskpart`/`reg add|delete`/`sc`/`net user`/`wmic`/`del /f`/`taskkill` 等（**C3**） | 52 → **62** |
| — 再按 **C5/C6/C7** 人工筛（挂起风险、含空格名、同名冲突） | **16** |

> 62 个通过机器筛选的候选里，**只有 16 个**适合进批量。被排除的主因是**挂起风险**（`cmd /k`、`start /w notepad`、无限 `goto` 循环）而不是安全性 —— 这本身就是一条关于语料的结论：**"非交互"不等于"可无人值守运行"**。

| 维度 | 覆盖 |
| :--- | :--- |
| **文件行为** | s01 s04 s05 s06 s07 s08 s11（7） |
| **目录行为** | s03 s05 s07（3） |

## 3. 执行方式

```bash
cd research/behavior-tracking
python3 tools/batch.py --samples batch-samples.txt --output results/batch
```

每个样本走**完整的** `collect.py` 流程（回滚 → 网络姿态 → 冷启动 → 基线 → 上传 → 执行 → 采集 → 停机），
`batch.py` 只负责编排、**失败不阻塞**、以及批量级验证。

参数与判据见 `batch-result.md`。

## 4. 执行前必须解决的三个采集器缺陷

选取过程中（而不是跑完之后）暴露出三个**会让批量结论失真**的问题，已在批量执行**之前**修复：

| # | 缺陷 | 后果 | 修复 |
| :-- | :--- | :--- | :--- |
| 1 | `guest-exec` 的 cwd 是 **`C:\Windows\System32`** | 语料几乎全用**相对路径** ⇒ 写入落在 System32，而清单范围是 `C:\poc`，**文件行为完全不可见**。想看见就得对 System32 做 SHA256 清单，代价不可接受 | `collect.py --workdir`（默认 `C:\poc\samples`），用 `cd /d … &&` 切换 |
| 2 | 清单只收 `-File` | `md`/`mkdir` 类样本表现为"什么都没做" —— **安静的假阴性**（s03、s12 正是这类） | `vm.dirs()` 单独列目录；**刻意不进 J1 哈希**，保持判据可比 |
| 3 | `cmdline_for()` 对含空格路径加引号 | 实测 **QGA 会给 `"` 加反斜杠转义**，`cmd.exe` 不认 `\"` ⇒ 含空格路径**根本跑不了**（旧代码会静默 `rc=1`，看起来像"样本失败"） | 去掉引号 + 含空格时**硬失败**；清单统一用 ASCII 短名（C6） |

> **方法论**：这三条如果留到"跑完再看结果"，会得到一份**16/16 通过、但指纹大面积空白**的报告 —— 而空白会被误读成"这些样本没有行为"。**先验证采集器能看见，再验证样本有什么**。
